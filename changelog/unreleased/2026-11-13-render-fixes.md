- Rendering fixes: a clip inside a rounded clip keeps the outer clip's rounded corners (a square list no longer fills a card's corners), and a clip cut off by the one around it keeps its own corners; a scene's clip table entry is now 48 bytes with a parent index (`Scene.CLIP_STRIDE`, `Scene.CLIP_PARENT`, `Scene.clipParent`). The CPU renderer draws a modal scrim at scales from 2.15 on; the GPU renderer stays usable after a target size the device refuses and gives up images beyond `imageMemory` in scenes without images too; a glyph atlas with a page side that is no multiple of 4 stores every glyph that fits; JPEG files with chroma two samples wide or less decode as libjpeg decodes them; and on Windows the native libraries load from folders whose names lie outside the system's code page, such as a user profile named in Japanese.
