- Added `Language` to the code editor: it wraps a `Highlighter` and adds the ranges of comments and doc comments, which `Comments.scan` finds a bounded number of lines at a time, and the parsing of doc comments into `DocComment`. `codeEditor(...)` takes a `Language` where it takes a `Highlighter`; `Language.of(Sql.of())` wraps a highlighter without comments. A literal `null` for the highlighter now needs a cast, `(Highlighter) null`.
