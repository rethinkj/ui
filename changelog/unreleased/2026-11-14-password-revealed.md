- A password that is shown stays out of tree dumps, selectors and script errors. `El.revealed(boolean)` on a masked field draws its string on the screen (glyphs, carets, hit testing, selection), copies and cuts, and goes by words as an ordinary field, and `App.inputArea().password()` is false while it is set; but `Text.string()` is still the mask, so the dump shows one `•` per grapheme with caret, anchor and composition in it, and adds the new state `revealed` after `password`, which a selector can name (`press role=textbox revealed`). The kit's `TextField.revealable` now keeps the field masked and sets `revealed` while the password shows, where it used to build an ordinary field: a script that selected a shown password by its text (`text="hunter2"`) now selects it by key or role, and a stored tree of a shown password changes to the mask with `password revealed`.
