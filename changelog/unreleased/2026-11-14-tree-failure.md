- `Tree.Model.failure(node)` says why the children of an open node could not be read: return `Tree.failure("Cannot read the tables: connection refused").action("Try again", handler)` instead of null, and the row below the node shows the message with an icon in the danger colour and the action at its end, in place of the loading row. The action is a stop for Tab after the tree, and Enter, Space and a press run it; the tree never tries again by itself. In a tree dump the row is `role=treeitem invalid` with the message as its label and as `error="…"`, and the action is `role=button`.
