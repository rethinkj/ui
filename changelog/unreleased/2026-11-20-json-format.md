- `Json.format` of the module `rethinkj-ui-json` formats JSON, such as a minified value from a database, before the code editor shows it: four spaces a level, and numbers, escapes and the order of members as written. It returns the new record `Formatted` of core, which has the formatted text or, for invalid JSON, the first problem with its place and kind, which an app shows as a `CodeEditor.Diagnostic` with the message of the new `Texts.formatProblem`. A value nested however deep is safe to format; one whose formatted text would be longer than 64 Mi characters gives `TOO_LARGE`.
