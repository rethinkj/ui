- Added what tables need to core: `El.onPress((clicks, modifiers) -> …)` is told the modifiers held at the press; `El.onPointerDown` runs as the button goes down, without taking the press or drag from an ancestor; `Drag.x()` and `Drag.y()` say where the pointer is in the dragged element's content, its scroll included; `El.fixedX()` keeps an element in place while its scroll area scrolls sideways; `El.rows(count, rowHeight, (index, from, to) -> row)` builds rows for the part in view sideways and builds them anew when scrolling sideways goes beyond it; `El.reveal(key, x, y, width, height)` keeps a rectangle of a scroll area in view whenever its key changes; `El.onRowsBuilt` tells the app which rows a list built when they change; and `El.current(boolean)` marks the current item of a set, `current` in the tree dump and in selectors. `Drag` has two more components, so code that constructs one changes.
