- `App.tray(tray, onError)` and `App.removeTray()` show, update, or remove a system tray icon with a tooltip and context menu (buttons, checkboxes, separators, submenus, and disabled entries) on Windows 11 and Linux (AppIndicator/GTK 3), posting entry handlers and errors to the app's thread. Scripts write the active tray menu to `<name>.tray.txt` on `snap` and click entries with `tray click "<label>"`; a test can set its own `Trays` with `App.trays`.
