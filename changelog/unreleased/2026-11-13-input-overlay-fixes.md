- Fixed in core's input, focus and overlays: a press, a secondary press and the pressed look of Enter or Space end when their element leaves, so an element that comes back with the same key no longer takes them over; `onAnyKeyDown`, `onAnyPointerDown` and `onPressOutside` run in the rows of a list for every input of a frame and no longer for elements that are leaving; input after a handler that threw goes to a view built from what it changed; Tab into a list passes `skipTab()` elements; an `autofocus` element that is clipped away passes the focus on to the next that asks; a secondary press in a text field inside a `keepFocus()` element focuses the field; an overlay the view makes invisible blocks nothing, one under an invisible anchor takes no focus, and one whose anchor lies wholly outside the window does not show; a `keepFocus()` overlay gives the focus back to the last place outside it after several Tabs in one frame; `onShownFor` now times overlays that `whenHoveredFor` or `whenFocusVisibleFor` attach and those in the rows of a list; a press keeps a `whenHoveredFor` look away also when the pointer came in the same frame. The script step `wheel` is documented as not moving the pointer.
