- **Breaking:** `CodeEditor.LineComments` is gone: a highlighter gives Control+/ its comment by overriding `Highlighter.lineComment()`, which is null by default. A highlighter can also mark the brackets of the code with `Spans.bracket(at)` and opt in with `Highlighter.marksBrackets()`; the code editor then pairs only those, so in `SELECT f(')')` the `)` in the string no longer matches the `(`. `Sql` does both, in both dialects. `El.matchingBracket(caret)` finds a pair in any text, from the field's cached highlighting.
