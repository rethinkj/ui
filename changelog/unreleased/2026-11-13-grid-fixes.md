- The data grid writes edits to the rows and columns they were made in: an open editor follows its row by key through `changes(...)` when the app sorts or refreshes the rows, and closes without writing when the row is gone; hiding or moving a column carries the selection and an open editor along instead of leaving them on a neighbour; a paste into a `GridTable` whose handler sorts writes each row it took. Delete no longer hands a typed column a value its format refuses, a long list of choices keeps an unchanged NULL on Enter, errors show on the cells of new rows and go with the value that undo or redo takes back, a lone empty cell on the last line copies as `""` so that it pastes back, and a filter of equality without a value of the column's type passes nothing and cannot be applied from the popover.
