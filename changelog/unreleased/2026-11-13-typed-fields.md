- `Format<T>` writes and reads typed values (`INTEGER`, `LONG`, `BIG_INTEGER`, `DECIMAL`, `DATE`, `TIME`, `DATE_TIME`, `OFFSET_DATE_TIME`, `BOOLEAN`, `TEXT`, `choice(values, label)` and `of(text, parse, message)`, with `.optional()` and `.where(test, message)`) without the system's locale, and `ValueField.valueField(t, format, value, draft, onChange)` is a text field for such a value that keeps a text that is no value yet as a `ValueField.Draft` with the format's message, which `Form.field` shows; `El.errorMessage` carries the message and a tree dump writes it as `error="…"`. The data grid's cell editors check their types through the same formats, unchanged.
