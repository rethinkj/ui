- Added `DataGrid.dataGrid` to `rethinkj-ui-kit`, a grid for query results: a header that stays above rows built only as far as they show, so a million rows cost what a screenful costs, alternating rows, hover, a selection that looks different while the grid has the focus, NULL as a muted marker, columns aligned and monospaced as the app says, resizing by dragging a header's edge, and sorting by pressing a header, with a marker. The app owns rows, selection, widths and sort order; the grid reports changes to them. Up, Down, Page Up, Page Down, Home and End move the selection. The theme has a new token group, `Theme.Grid`, for row height, minimum column width, resize handle and the grid's backgrounds; `Theme` records made with the constructor need it as their last argument.
