- Added `rethinkj-ui-natives-linux-x64`, which carries SDL 3.4.20 and wgpu-native 29.0.1.1 for Linux on x64. `rethinkj-ui-core` unpacks them into `$XDG_CACHE_HOME/rethinkj-ui/natives` (by default `~/.cache/rethinkj-ui/natives`) and loads them, as on Windows. Its SDL is built from source by the machine that builds the JAR and needs that machine's glibc or a newer one (2.38 for a JAR built on Ubuntu 24.04). Linux cannot load libraries from a file system mounted `noexec`; move the cache with `-Drethinkj.ui.natives.cache=<folder>`. When a library fails to load on Linux, the error now gives the dynamic linker's reason, such as a missing glibc version.
