- `ConditionBuilder` edits a tree of conditions: fields, operators and text values in AND/OR clauses that nest, with a value input that follows each field's type—including calendar pickers for `DATE` and `DATE_TIME` fields. It is controlled, hands the app a new tree on every edit, marks invalid values and reversed ranges, and `ConditionBuilder.applicable(...)` returns the tree without switched-off, incomplete, invalid or reversed-range conditions.
