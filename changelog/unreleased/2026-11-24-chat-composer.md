- Added `Chat.composer` to the kit for chat input: a growing multi-line field in a card (Enter sends when non-blank and not composing with an input method, Shift+Enter inserts a new line) above an action bar with start/end slots, removable attachment chips, file drop support (`onFiles`), and a send button that turns into a stop button while the agent works. Also fixed core key dispatch so an input method composition consumes keys (except Tab) before element key handlers run.
