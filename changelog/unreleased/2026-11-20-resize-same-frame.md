- `El.onResize` handlers now run in the frame whose layout gave the new size, and the view is built again before that frame ends, so a toolbar or a breadcrumb shows what fits a new width in the first frame instead of one frame later, and dragging a window's edge no longer flickers them. A data grid's `fitColumns` likewise shows the fitted widths in the frame that first has loaded rows. A custom runner that calls `frame()` gets the settled view from that same call.
