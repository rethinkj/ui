- Added masked text fields for passwords: `El.text(value).editable(onEdit).masked()` (or `masked(boolean)`, set on every build, so an app shows the password by building the field without it) shows one `Text.MASK` bullet per grapheme, or the character of `.maskCharacter(c)`. The string stays the app's and edits as in any field, but copy and cut do nothing, word keys and a double press take it as one word, and only the mask is shaped, dumped (with the state `password`), matched by `text="…"` and quoted in script errors; `Text.string()` returns the mask. `App.InputArea` gained `password`, and `Window.textInputArea` a `password` parameter, which asks the system for a hidden password's input (on Wayland with SDL 3.4). `El.keepFocusOnPress()` lets a press on an element leave the focus where it is. The kit gained `TextField.passwordField(theme, value, placeholder, onChange)` and `TextField.revealable(theme, field, revealed, onToggle)`, a button inside the field's frame that shows and hides the password while the caret stays in the field.
