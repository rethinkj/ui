- Added icons. The new artifact `rethinkj-ui-icons` carries Fluent UI System Icons (MIT), whose icons are drawn anew for 12, 16, 20 and more pixels; `Font.icons()` loads it. In the kit, `Icon.icon(theme, symbol[, variant[, size]])` shows one of 94 named `Symbol`s (database, server, table, key, chevrons, sort arrows, close, warning and more) at the theme's new `size().icon()` (16) or another size, in a text or status colour, in a box exactly that size that lines up with the text beside it. Icons sit on whole pixels at every scale, so they stay sharp in a box scrolled or moved by a fraction. The tree's marks are now chevrons from the icon font, so the tree needs `rethinkj-ui-icons`, and `Tree.CLOSED` and `Tree.OPEN` are `Symbol`s instead of strings. The tree dump and selectors write a character of a private use area, such as an icon, as `\u{E0EB}`.
