- The code editor formats its whole text with Ctrl+Alt+L, the new `CodeEditor.Command.FORMAT`, which a menu runs with `CodeEditor.run`: as one step for Ctrl+Z, with the cursor at the same token, or, for a text that is not valid, with its problem shown as an error diagnostic at the cursor. A language brings its formatter with the new default method `Highlighter.formatter()`: `Json` returns `Json::format`, and with a highlighter without one, such as `Sql`, the command does nothing.
