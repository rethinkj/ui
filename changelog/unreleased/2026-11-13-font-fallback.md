- Text falls back to other fonts for the characters its font lacks, instead of drawing empty boxes. `Font.withFallback(Font...)` names the fonts to try, in order; `Font.withSystemFonts()` then tries the fonts installed on the system, found by scanning the system's font folders once, on the first character that needs them. `App.systemFonts(boolean)` turns system fonts on for an app's text: off by default, so that scripts, `Headless` and tests look the same on every machine, and on in a `WindowLoop` unless `WindowLoop.systemFonts(false)`. A line may now mix fonts and scripts: each grapheme cluster goes to the first font that has it, each run is shaped in its own script and direction, so Arabic and Hebrew letters join and read right to left within their run (lines are not reordered yet), and `GlyphRun.font(int)` names the font of each glyph. Emoji are drawn in the text colour where a font has outlines for them; colour emoji are not supported yet.
