- `El.autofocus()` makes an element take the keyboard focus in the build of the view that adds it, such as an editor that a key lays over a grid's cell, and inside an overlay names the element its opening focuses instead of the first focusable one, such as a dialog's second field. `El.autofocus(key)` also takes the focus whenever a build gives the element another key, such as the first field with an error after each Save. A focus that has lost its element prefers an `autofocus` element around it.
