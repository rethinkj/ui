- A window's first frame comes sooner: the GPU context links wgpu-native's functions while wgpu looks for the adapter, not before, which saves about 25 ms on Windows. `GpuPresenter.prepare()` documents that `main` should not call it when it runs a script instead of opening a window, and the Agent Chat example calls it first thing in `main`. Its first frame on Windows comes about 85 ms sooner without the AOT cache and about 45 ms sooner with it.
