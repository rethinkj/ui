- `Markdown.Options.copied(Button.Copied)` lets a code block's copy button confirm a copy without a `Markdown.State`, and `Chat.agent` passes its `copied` on to its code blocks. The button now has an opaque fill over long lines, and a non-wrapping `El.fitLines()` field with scrollbars is higher by the bar's strip only while a line is too wide, so code blocks that fit have equal room above and below.
