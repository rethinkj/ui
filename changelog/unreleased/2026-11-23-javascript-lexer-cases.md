- Fixed: in `JavaScript` and `TypeScript`, a regular expression right after an `if`, `while`, `for` or `with` header (`if (ready) /[/*]/.test(input)`) no longer reads as division and can no longer start a false comment that hides the next doc comment. Division after `total ! / count`, after `of` used as a name and after a keyword that follows a `.` at the end of the previous line is no longer colored as a regular expression, a combining mark no longer splits a name into a keyword, and a quoted `}` in a JSDoc type or `]` in a parameter default no longer ends it early.
