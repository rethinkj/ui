- Added the first components to `rethinkj-ui-kit`: `Label.label` (normal, muted, monospaced, heading), `Button.button` (primary, secondary, ghost), `Toggle.toggle` and `Checkbox.checkbox`, each a static function that returns an `El` with hover and pressed looks, a pointer cursor, keyboard focus, Enter and Space, a role and a label; a null handler disables it. They take their colours, sizes, fonts and springs from a `Theme`, an immutable record of semantic tokens passed as the first argument, with a neutral default in `Theme.DARK` and `Theme.LIGHT` that apps copy and change with its `with` methods. The default fonts need `rethinkj-ui-fonts`, and an app sets the ring's colour with `app.focusRing(theme.border().focus())`.
