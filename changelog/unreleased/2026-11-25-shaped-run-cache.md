- A view that shows more than 1,024 lines or labels in one font no longer shapes all of them again on every rebuild: a font keeps every shaped run that the last two frames shaping text used, up to 16,384, instead of only the 1,024 most recent. Typing next to a sent 2,000-line message in a chat costs about 14 ms per key instead of 59 ms, and shaping a long plain text allocates about a fifth of what it did.
