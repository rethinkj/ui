- `TabGroups` now supports single-window usage via `new TabGroups<>(tabs)` without a window opener (omitting tear-off and window menu items), adds **Close**, **Close others**, and **Close to the right** to the tab context menu (respecting `Tabs.Tab.closable`, `onCloseTab`, and optional batch `onCloseTabs`, with German texts in `GermanTexts`), allows apps to append custom tab menu items with `tabMenu((group, tab) -> ...)`, and adds `dockAll(from, to)` to merge a group into any open target group.
