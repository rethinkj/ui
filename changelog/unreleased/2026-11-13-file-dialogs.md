- `App.fileDialog(FileDialog, onChoice, onError)` shows the system's dialog to open one or more files, save a file or choose a folder, with a title, filters, a start folder and a suggested name, and hands the paths (empty when cancelled) and the chosen filter to the app as a posted task. `App.messageBox(MessageBox, onButton, onError)` shows a message box of the system, and `SystemDialogs.reportFailure(name, start)` shows why an app's window could not start in one. Scripts open no dialogs: the step `dialog` answers them, and a dialog without an answer fails the script with a message naming its title and filters; a test can set its own `Dialogs` with `App.dialogs`.
