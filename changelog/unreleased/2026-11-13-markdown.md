- Added: `Markdown.markdown(theme, document, options)` in the kit shows a Markdown document as a scroll area that builds only the blocks in view: headings, paragraphs with bold, italic, inline code, struck-out text and links that Tab reaches, code blocks with highlighting and a copy button, quotes, lists, task lists, tables and thematic breaks, selectable and copyable, in the new `Theme.Prose` tokens.
