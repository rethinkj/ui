- Typing while a `Tree` has the focus selects the next node shown whose label starts with the typed text, or else the first that contains it, as file managers do; characters typed within a second form one search, and the same character again cycles. Core's new `El.onTypeAhead(handler)` gives any list the text typed so far, ended by a pause of `App.TYPE_AHEAD` seconds of the app's clock, Escape or a move of the focus.
