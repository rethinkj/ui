- `ValueField` checks a value from outside as it checks typed text: null in a required field, or 20 in a field of 1 to 10, is `Draft.error()` and keeps `Editing.valid()` false, so Save no longer passes with a required field empty. The field shows that error only once the user has edited it or the app asks with `Draft.showError()` or `Editing.showErrors()` (for a Save pressed too early), so that a form over a new record does not open in red; `Draft.showsError()` says whether it does.
