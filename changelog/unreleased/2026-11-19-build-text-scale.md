- `WindowState` carries the window's `scale`, and `Text.scale(float)` is public, so that a view measures text while it is built at the scale layout uses. Kit components that size parts by their text (Breadcrumb, DataGrid, Tree, Properties, Completion, Form, Markdown) now get the same widths as layout at 125 %, 150 % and 200 %. Breaking: `new WindowState(active, maximized)` takes the scale as a third argument.
