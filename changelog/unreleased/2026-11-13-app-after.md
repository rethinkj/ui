- `App.after(seconds, action)` runs an action on the app's thread once the app's clock has moved on by that much, so that an app can change its state later without input or another thread: a delay, a timeout. It runs as a posted task does, in the first frame that begins at or after its time, after the input and the tasks that came before that frame, and the view is built again before the next input. `App.nextChange()` includes it, so a window wakes for it; in a script `advance` and `frame` run it, and `await` does not wait for it.
