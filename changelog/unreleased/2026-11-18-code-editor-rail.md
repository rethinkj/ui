- **Breaking:** `CodeEditor.State.error(from, to)`, `noError()`, `errorFrom()` and `errorTo()` are gone: `diagnostics(text, list)` takes `CodeEditor.Diagnostic`s with a severity (`ERROR`, `WARNING`) and a message, which show only while the editor's value is `text`, underlined in the severity's color and with a marker in the gutter whose tooltip is the message. `markers(list)` puts `CodeEditor.Marker`s there too, such as ▶ "Run statement" with an action, in the new `Icon.Variant.ACCENT`. The gutter lies on a rail, a marked block (`block`) tints the rail instead of the code, so `Theme.Code.block` is now that tint, and indentation shows guides (`Spans.guide`, the new `Theme.Code.guide`, which the full constructor of `Theme.Code` takes last). `El.Gutter.cell` now takes an `El.Gutter.Line` with the line's index, start, end and whether the caret is on it, and `El.gutter(cells, rail)` lays an element behind the gutter.
