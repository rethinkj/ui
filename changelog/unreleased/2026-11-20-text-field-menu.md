- A right-click in a kit text field, text area, password field or code editor, the Menu key or Shift+F10 opens a menu with Cut, Copy, Paste and Select all; a code editor given the app adds Find and Replace. Items that would do nothing are disabled, and a hidden password has no Cut and Copy. A field with its own `onSecondaryPress` keeps it, but a right-click on a field no longer reaches a context menu of an element around it. Core's `El.fieldMenu` gives any editable field such a menu.
