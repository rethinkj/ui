- `El.Block` now supports `.pinned(true)` to keep a block at the left edge of a non-wrapping multi-line field's content box with the content box's width while the text scrolls sideways, without scrolling the field horizontally when a control inside the block takes focus; `CodeEditor.Block` marks are pinned by default while code vision rows and rendered doc comments continue scrolling with the code. The `El.Block` record gains a `pinned` component while keeping its 4- and 5-argument constructors.
