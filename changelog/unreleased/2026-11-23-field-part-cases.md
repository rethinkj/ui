- A menu or other overlay opened from an element in a multi-line field's block, line-end element or hint, or from a row of a virtual list, now takes the focus when it opens and gives it back when it closes, as other overlays do, without `autofocus`. A look that changes the width of an inlay hint moves the text after it, and one that changes the width of a line-end element moves the elements after it on its line, into view or out of it. Two blocks at the same line or two hints at the same offset with the same explicit key now throw an `IllegalStateException`.
