- **Breaking:** `Breadcrumb.breadcrumb(state, crumbs)` takes a list of `Breadcrumb.Crumb` in place of strings and an index handler: `Breadcrumb.crumb(text, onPress)` with its own press, null for a crumb that only shows (muted, no longer disabled), `.icon(symbol)` for an icon before its text, and `.children(supplier)`, which turns the chevron after it into a button that opens a menu of the places inside, as a file manager's address bar has it (`role=button label="Inside public"`, `expanded` while open). Where the path does not fit, the middle goes into the ellipsis first, then the first crumb, and only then is the current place shortened with an ellipsis and a tooltip of its whole name. The ellipsis is a ghost icon button with `Symbol.MORE_HORIZONTAL` and says `expanded` while its menu is open; chevrons are quieter, in `border().strong()`.
