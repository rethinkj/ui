- Markdown task list checkboxes take input with `Markdown.Options.onTask`: a press, or Space while focused, hands the app a `Markdown.Task` whose `applyTo(source)` returns the source with that `[ ]` or `[x]` switched, to store and parse again with `document.next(source)`. `MarkdownDocument.Item` has the box's position in the source as `taskOffset`. A task's box now stays on its first line when the item holds a nested list.
