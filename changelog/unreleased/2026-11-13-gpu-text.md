- The GPU renderer draws text, so windows with `GpuPresenter` show it. Glyphs are drawn as `CpuRenderer` draws them, one texel per physical pixel with the same coverage correction, clip and blending, in the same draw call as the boxes, so the two overlap in tree order. The atlas pages go to the GPU as the layers of one texture, and after a page's first upload only the region that changed in it is uploaded again; a frame whose text needs no new glyphs uploads nothing. `GpuPresenter.atlasUploads()` counts the uploads. A presenter should be the only renderer that draws an app's scenes, since it takes the atlas's changes.
