- `DataGrid.Options.onRowsInView((first, last) -> …)`, and `El.onRowsInView` for any virtual list, tell an app when the first or last row wholly in view changes, so that a status line such as "Rows 201–223" or paging buttons follow scrolling, by a single row too, at one rebuild per change. `onRowsBuilt` handlers that are due together, including those of several lists, now run as one input with a single rebuild.
