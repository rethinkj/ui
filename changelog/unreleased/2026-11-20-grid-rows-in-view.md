- `DataGrid.Options.onRowsInView((first, last) -> …)`, and `El.onRowsInView` for any virtual list, tell an app when the first or last row wholly in view changes, so that a status line such as "Rows 201–223" or paging buttons follow scrolling, by a single row too, at one rebuild per change. A list with both handlers tells the rows it built (`loading`, `onRowsBuilt`) together with the rows in view, as one input with one rebuild.
