- `app.focus(el)` takes an element that is not focusable too, such as a sidebar or a tab's content, and moves the focus into it: to the element there that had the focus last, else to the first one that can take it, an `autofocus` one first. A handler can change what the element holds and focus it in the same call. Fixed: input queued for an app that `invalidate()` marked, such as an `after(0)` action, ran against the old tree; it now gets the view built anew.
