- A hover look (`El.whenHovered`, `El.whenHoveredFor`) in the rows of a virtual list (`El.rows`) no longer builds the view again when it moves to another row: the list builds only the row that loses the look and the one that gains it. Scrolling a data grid of a million rows with the pointer resting over its rows no longer calls the view function in every frame, and such a frame takes about a third of the time it did. An `El.onHoverFor` handler that runs still builds the view again.
