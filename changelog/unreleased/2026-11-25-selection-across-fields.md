- Added `El.selectionScope()`: the read-only text fields inside such an element form one selection, so a drag or Shift+click selects across them and Control+C copies the selected text of all of them, with a line break between fields. `Markdown.markdown` and `Markdown.fragment` use it, so a selection reaches across a document's blocks; mark a list of fragments, such as chat messages, to select across them.
