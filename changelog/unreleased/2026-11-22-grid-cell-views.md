- Added custom cell views and hover/selected row actions to `DataGrid.Column`: `column.view(row -> el)` shows any element (such as a `Badge`, `Progress.bar` or centered `Checkbox`) in place of a loaded row's text and icon while `cell` continues to supply text for copying, sorting, filtering, tooltips, column fitting and tree dumps; `column.actions(row -> el)` places an element (such as small icon buttons) at the cell's right end, shown while the row is hovered, selected or holds keyboard focus. Presses on interactive controls inside a view or actions act on the control without starting a cell edit or selection drag.
