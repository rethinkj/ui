- When an app refuses the text of a `CodeEditor` command (duplicate, move or delete lines, toggle comment, format), the caret and the selection stay where they were instead of landing at the command's positions in the old text. `App.edit(field, from, to, text, caret, anchor)` is the new variant behind it: it selects from `anchor` to `caret` with the edit, and a refused edit restores both with the text.
