- `DataGrid.Selection.commitEdit()` hands the open cell editor's value on, as a press outside it does, and says whether it was taken. Call it before saving, running or closing so that nothing typed is lost; a refused value keeps its editor open with the message. Workbench and DataBrowser now take the editor's value before Commit and Control+S, and Workbench also before Run, closing a tab and asking about unsaved changes.
