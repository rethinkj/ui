# Security

Please report a vulnerability privately through [GitHub's vulnerability reporting](https://github.com/rethinkj/ui/security/advisories/new), not in a public issue or pull request. Include what is affected, how to reproduce it and what an attacker could do with it.

You get an answer within a few days. Once a fix is released, the advisory is published and credits you unless you ask otherwise.

The project has no stable release yet, so fixes go into the current `SNAPSHOT` only.
