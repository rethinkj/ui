# The settings window: every page in both themes at scales 1 and 2, the keys of the list of
# pages, rows that toggle, an expander, a number field, a slider and its callout, connections
# that filter down to the empty state, and the dialog with a form that adds one. New elements
# fade in and changed ones spring over a tenth of a second, so `advance 1` and another frame come
# before each snap.
