## Line by line

**State.** `Lights` has a single field, `boolean on`. Your state is a plain Java object (fields, lists, records — whatever your app needs). You do not need observables or data binding. Only event handlers update the state, always on the app thread.

**App.** `new App<>(new Lights(), Lights::view)` connects your state to your view function. [`App`](/api/com/rethinkj/ui/App.html) automatically manages UI internals like focus, hover state, scroll positions, animations, and text cursors.

**Headless script support.** `Script.handle(args, app)` checks for `--script <file> --out <folder>` in the command-line arguments. If present, it runs the script without opening a window, writes screenshots and element trees, and returns `true`. Otherwise, it returns `false` and the app opens a window. Including this line lets automated tests and AI agents drive your app. See [Testing and agents](/docs/testing).

**Window.** `Window.open` creates a desktop window, `GpuPresenter` renders to it using the GPU, and `WindowLoop.run` runs the event loop until the user closes the window. Both `Window` and `GpuPresenter` implement `AutoCloseable`.

**View.** `view(Lights state)` returns a fresh element tree from the current state. rethinkj UI calls it again whenever an event handler changes the state. Keep `view` read-only — never modify state inside it.

- `el()`, `row()`, and `col()` create layout containers, and `text(...)` creates text. Chain methods to set size, padding, background fill, corner radius, and children. See [Elements and layout](/docs/concepts/layout).
- `.key("lamp")` gives the element a stable ID. Keys let rethinkj UI track animations, focus, and scroll positions across rebuilds, and let scripts find elements with `#lamp`.
- `.motion(theme.motion().move())` smoothly animates the lamp's color change using a spring instead of snapping immediately. See [Motion](/docs/concepts/motion).
- `Card.card` and `toggle` are ready-made components from `rethinkj-ui-kit`. Each component is a static method returning an `El` that you can style further. Components automatically read colors and spacing from `Theme.CURRENT` (dark theme by default). See [Components](/docs/components) and [Themes](/docs/concepts/themes).
- `state::toggleLamp` is an event handler method. When the user clicks the switch, `toggleLamp()` flips `on`, and the app rebuilds the view automatically.
