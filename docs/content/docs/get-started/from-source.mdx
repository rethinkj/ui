---
title: Build from source
description: Clone the repository, build rethinkj UI locally, and run the example apps.
---

You only need to build from source if you want to run the included example apps or contribute to rethinkj UI. To use rethinkj UI in your own project, add the Maven or Gradle dependencies instead (see [Installation](/docs/get-started)).

## Requirements

| Requirement | Details |
| --- | --- |
| Platform | Windows 11+ or Linux (x64) |
| JDK | Java 25 (any distribution) |
| Maven | 3.9 or later |
| Internet | Needed on the first build to download native libraries (cached afterward, even after `mvn clean`) |

The first build also compiles some native libraries from source, so you need a C/C++ build toolchain:

<Tabs items={['Linux', 'Windows']}>
<Tab value="Linux">

You need `cmake`, `make`, a C/C++ compiler, `pkg-config`, `tar` with `xz`, and the X11/Wayland development headers required by SDL3. See [Platforms and native libraries](/docs/reference/platforms#what-a-build-needs) for the exact `apt` command. Building the native libraries takes about one minute on the first run.

</Tab>
<Tab value="Windows">

Install Visual Studio 2022+ (or Visual Studio Build Tools) with the **Desktop development with C++** workload (default components include x64 tools, Windows SDK, and C++ CMake tools). Nothing needs to be added to `PATH`. Building the native libraries takes 1–3 minutes on the first run.

</Tab>
</Tabs>

## Build the repository

```sh
git clone https://github.com/rethinkj/ui.git
cd ui
mvn verify
```

`mvn verify` compiles all modules and runs the test suite (no windows are opened during tests).

If you do not have a C/C++ toolchain installed, you can skip the native libraries (tests that require them will be skipped):

On Linux:

```sh
mvn verify -P -natives-linux-x64
```

On Windows:

```sh
mvn verify -P -natives-windows-x64
```

If a native library fails to build or load, see [Platforms and native libraries](/docs/reference/platforms).

## Run the examples

From the repository root, run `LightSwitch` (default) or any other example with `-Dexample`:

```sh
mvn -q -pl examples -am compile exec:exec
mvn -q -pl examples -am compile exec:exec -Dexample=Showcase
```

Available `-Dexample` values: `LightSwitch`, `Workbench`, `DataBrowser`, `Showcase`, `Documents`, `Manual`, `Settings`, `ConnectionDialog`, and `Notes`. See [Examples](/docs/examples) for screenshots and details of each app.

To run an example headless with a script instead of opening a window, pass `-Dargs`:

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=LightSwitch -Dargs="--script examples/src/test/resources/scripts/light-switch.txt --out target/light-switch"
```

Paths are relative to the directory where you run Maven. Each `snap` writes a `.png` and a `.tree.txt` file. See [Scripts](/docs/testing/scripts).
