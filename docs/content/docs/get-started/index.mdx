rethinkj UI is a library for desktop apps in Java 25 on Windows 11 or later and Linux, both on x64. You need a JDK 25 and Maven 3.9 or later or Gradle 9.1 or later. There is no release yet: every push to `main` publishes SNAPSHOTs to Maven Central's snapshot repository. A SNAPSHOT changes with each push, the API with it, and Central removes SNAPSHOTs after 90 days.

## Add the dependencies

You need the snapshot repository, the kit (it brings core with it), the fonts, the icons and the native libraries of your platform at run time, and `java` started with `--enable-native-access=ALL-UNNAMED`.

<Tabs items={['Maven', 'Gradle']}>
<Tab value="Maven">

```xml title="pom.xml"
<repositories>
  <repository>
    <id>central-snapshots</id>
    <url>https://central.sonatype.com/repository/maven-snapshots/</url>
    <releases><enabled>false</enabled></releases>
    <snapshots><enabled>true</enabled></snapshots>
  </repository>
</repositories>

<dependencies>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <artifactId>rethinkj-ui-kit</artifactId>
    <version>0.1.0-SNAPSHOT</version>
  </dependency>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <artifactId>rethinkj-ui-fonts</artifactId>
    <version>0.1.0-SNAPSHOT</version>
    <scope>runtime</scope>
  </dependency>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <artifactId>rethinkj-ui-icons</artifactId>
    <version>0.1.0-SNAPSHOT</version>
    <scope>runtime</scope>
  </dependency>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <!-- or rethinkj-ui-natives-windows-x64 -->
    <artifactId>rethinkj-ui-natives-linux-x64</artifactId>
    <version>0.1.0-SNAPSHOT</version>
    <scope>runtime</scope>
  </dependency>
</dependencies>
```

The [whole pom](#a-whole-project) below picks the natives by the OS that builds and runs the app with `exec:exec` and the JVM flag:

```sh
mvn compile exec:exec                                                  # in a window
mvn -q compile exec:exec -Dargs="--script lights.txt --out target/lights"  # under a script
```

</Tab>
<Tab value="Gradle">

With the Kotlin DSL:

```kotlin title="settings.gradle.kts"
rootProject.name = "lights"
```

```kotlin title="build.gradle.kts"
plugins {
    application
}

java {
    toolchain {
        languageVersion = JavaLanguageVersion.of(25)
    }
}

repositories {
    maven("https://central.sonatype.com/repository/maven-snapshots/") {
        mavenContent { snapshotsOnly() }
    }
    mavenCentral()
}

val rethinkjUi = "0.1.0-SNAPSHOT"
val natives = if (System.getProperty("os.name").startsWith("Windows")) "windows-x64" else "linux-x64"

dependencies {
    implementation("com.rethinkj.ui:rethinkj-ui-kit:$rethinkjUi")
    runtimeOnly("com.rethinkj.ui:rethinkj-ui-fonts:$rethinkjUi")
    runtimeOnly("com.rethinkj.ui:rethinkj-ui-icons:$rethinkjUi")
    runtimeOnly("com.rethinkj.ui:rethinkj-ui-natives-$natives:$rethinkjUi")
}

application {
    mainClass = "com.example.Lights"
    applicationDefaultJvmArgs = listOf("--enable-native-access=ALL-UNNAMED")
}
```

```sh
gradle run                                                # in a window
gradle run --args="--script lights.txt --out build/lights"  # under a script
```

Run `gradle wrapper` once to add `./gradlew` to the project, so that others build it without installing Gradle.

## A whole project

```text
lights/
├── pom.xml                  (or settings.gradle.kts and build.gradle.kts)
├── lights.txt
└── src/main/java/com/example/Lights.java
```

The whole pom, to copy:

```xml title="pom.xml"
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
    xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
    xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>

  <groupId>com.example</groupId>
  <artifactId>lights</artifactId>
  <version>1.0-SNAPSHOT</version>

  <properties>
    <maven.compiler.release>25</maven.compiler.release>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    <rethinkj.ui.version>0.1.0-SNAPSHOT</rethinkj.ui.version>
    <main.class>com.example.Lights</main.class>
    <args></args>
  </properties>

  <repositories>
    <repository>
      <id>central-snapshots</id>
      <url>https://central.sonatype.com/repository/maven-snapshots/</url>
      <releases><enabled>false</enabled></releases>
      <snapshots><enabled>true</enabled></snapshots>
    </repository>
  </repositories>

  <dependencies>
    <dependency>
      <groupId>com.rethinkj.ui</groupId>
      <artifactId>rethinkj-ui-kit</artifactId>
      <version>${rethinkj.ui.version}</version>
    </dependency>
    <dependency>
      <groupId>com.rethinkj.ui</groupId>
      <artifactId>rethinkj-ui-fonts</artifactId>
      <version>${rethinkj.ui.version}</version>
      <scope>runtime</scope>
    </dependency>
    <dependency>
      <groupId>com.rethinkj.ui</groupId>
      <artifactId>rethinkj-ui-icons</artifactId>
      <version>${rethinkj.ui.version}</version>
      <scope>runtime</scope>
    </dependency>
  </dependencies>

  <build>
    <plugins>
      <plugin>
        <groupId>org.codehaus.mojo</groupId>
        <artifactId>exec-maven-plugin</artifactId>
        <version>3.6.4</version>
        <configuration>
          <executable>java</executable>
          <commandlineArgs>--enable-native-access=ALL-UNNAMED -classpath %classpath ${main.class} ${args}</commandlineArgs>
        </configuration>
      </plugin>
    </plugins>
  </build>

  <profiles>
    <profile>
      <id>natives-linux-x64</id>
      <activation>
        <os><name>Linux</name><arch>amd64</arch></os>
      </activation>
      <dependencies>
        <dependency>
          <groupId>com.rethinkj.ui</groupId>
          <artifactId>rethinkj-ui-natives-linux-x64</artifactId>
          <version>${rethinkj.ui.version}</version>
          <scope>runtime</scope>
        </dependency>
      </dependencies>
    </profile>
    <profile>
      <id>natives-windows-x64</id>
      <activation>
        <os><family>windows</family><arch>amd64</arch></os>
      </activation>
      <dependencies>
        <dependency>
          <groupId>com.rethinkj.ui</groupId>
          <artifactId>rethinkj-ui-natives-windows-x64</artifactId>
          <version>${rethinkj.ui.version}</version>
          <scope>runtime</scope>
        </dependency>
      </dependencies>
    </profile>
  </profiles>
</project>
```

- The kit brings core with it. Fonts, icons and the native libraries hold no classes, so they are runtime dependencies.
- The profiles pick the native libraries of the machine that builds. An app built once for both platforms lists both natives JARs without the profiles; each loads only on its own platform.
- `exec:exec` starts the `java` on the `PATH`, which must be a JDK 25, with native access enabled and the runtime class path. `-Dargs` passes arguments to `main`, and `-Dmain.class` runs another class.

## Run it

Run it in a window with `mvn compile exec:exec` or `gradle run`. Under a script it runs without a window. This script presses the switch and snaps before and after:

```text snippet="lights-script" title="lights.txt"
```

```sh
mvn -q compile exec:exec -Dargs="--script lights.txt --out target/lights"
gradle run --args="--script lights.txt --out build/lights"
```

It writes `off.png`, `off.tree.txt`, `on.png` and `on.tree.txt` to the `--out` folder and prints their paths. The commands are the same on Windows. [Testing and agents](/docs/testing) explains scripts and trees.

## The artifacts

All share the group `com.rethinkj.ui` and the version `0.1.0-SNAPSHOT`. `core` and `kit` come with a sources JAR, which IDEs pick up.

| Artifact | What it is | Needed |
| --- | --- | --- |
| `rethinkj-ui-core` | Elements, layout, text, input, rendering, windows, scripts | Always |
| `rethinkj-ui-kit` | The theme and the components | For the components |
| `rethinkj-ui-fonts` | Inter and JetBrains Mono, the default fonts | For text with the default fonts |
| `rethinkj-ui-icons` | Fluent UI System Icons, the icon font | For icons, the tree's marks, the grid's sort arrows |
| `rethinkj-ui-natives-linux-x64`, `rethinkj-ui-natives-windows-x64` | SDL3, wgpu-native, FreeType and HarfBuzz, and on Windows the DirectX Shader Compiler | At run time, for the platform it runs on. The Linux libraries need glibc 2.38 or later, as on Ubuntu 24.04. |

## Native libraries

Native code is called through the Foreign Function and Memory API, so `java` needs `--enable-native-access=ALL-UNNAMED`. On the module path, use `--enable-native-access=com.rethinkj.ui` and add the natives module with `--add-modules com.rethinkj.ui.natives.linux.x64` (or `windows.x64`), and the fonts and icons modules with `--add-modules com.rethinkj.ui.fonts,com.rethinkj.ui.icons`.

On first use, the libraries are unpacked from the natives JAR into a per-user cache: `%LOCALAPPDATA%\rethinkj-ui\natives\` on Windows and `$XDG_CACHE_HOME/rethinkj-ui/natives/` (by default `~/.cache`) on Linux. Two system properties change that:

| Property | Effect |
| --- | --- |
| `rethinkj.ui.natives.dir` | Load the libraries from this folder, which holds them with their `manifest.txt` as the JAR has them. Nothing is unpacked. See [Ship your app](/docs/get-started/ship). |
| `rethinkj.ui.natives.cache` | Unpack into this folder instead of the per-user cache. |
