rethinkj UI builds desktop apps in Java 25 for Windows 11+ and Linux (x64).

**Requirements:**
- JDK 25
- Maven 3.9+ or Gradle 9.1+

> **Early preview:** There is no stable release yet. Snapshots (`0.1.0-SNAPSHOT`) are published to Maven Central Snapshots on every update to `main`. The API may change, and Maven Central removes old snapshots after 90 days.

## 1. Add the dependencies

To use rethinkj UI in your project, add:
1. The Maven Central Snapshots repository
2. `rethinkj-ui-kit` (which automatically includes `rethinkj-ui-core`)
3. Runtime dependencies for the default fonts, icons, and native libraries for your operating system
4. The JVM flag `--enable-native-access=ALL-UNNAMED`

<Tabs items={['Maven', 'Gradle']}>
<Tab value="Maven">

```xml title="pom.xml"
<repositories>
  <repository>
    <id>central-snapshots</id>
    <url>https://central.sonatype.com/repository/maven-snapshots/</url>
    <releases><enabled>false</enabled></releases>
    <snapshots><enabled>true</enabled></snapshots>
  </repository>
</repositories>

<dependencies>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <artifactId>rethinkj-ui-kit</artifactId>
    <version>0.1.0-SNAPSHOT</version>
  </dependency>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <artifactId>rethinkj-ui-fonts</artifactId>
    <version>0.1.0-SNAPSHOT</version>
    <scope>runtime</scope>
  </dependency>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <artifactId>rethinkj-ui-icons</artifactId>
    <version>0.1.0-SNAPSHOT</version>
    <scope>runtime</scope>
  </dependency>
  <dependency>
    <groupId>com.rethinkj.ui</groupId>
    <!-- Use rethinkj-ui-natives-windows-x64 on Windows -->
    <artifactId>rethinkj-ui-natives-linux-x64</artifactId>
    <version>0.1.0-SNAPSHOT</version>
    <scope>runtime</scope>
  </dependency>
</dependencies>
```

Use the [complete `pom.xml`](#a-whole-project) below to automatically pick the right native library for your OS and run the app in a window, or headless with a script:

```sh
mvn compile exec:exec
mvn -q compile exec:exec -Dargs="--script lights.txt --out target/lights"
```

</Tab>
<Tab value="Gradle">

Using Gradle Kotlin DSL:

```kotlin title="settings.gradle.kts"
rootProject.name = "lights"
```

```kotlin title="build.gradle.kts"
plugins {
    application
}

java {
    toolchain {
        languageVersion = JavaLanguageVersion.of(25)
    }
}

repositories {
    maven("https://central.sonatype.com/repository/maven-snapshots/") {
        mavenContent { snapshotsOnly() }
    }
    mavenCentral()
}

val rethinkjUi = "0.1.0-SNAPSHOT"
val natives = if (System.getProperty("os.name").startsWith("Windows")) "windows-x64" else "linux-x64"

dependencies {
    implementation("com.rethinkj.ui:rethinkj-ui-kit:$rethinkjUi")
    runtimeOnly("com.rethinkj.ui:rethinkj-ui-fonts:$rethinkjUi")
    runtimeOnly("com.rethinkj.ui:rethinkj-ui-icons:$rethinkjUi")
    runtimeOnly("com.rethinkj.ui:rethinkj-ui-natives-$natives:$rethinkjUi")
}

application {
    mainClass = "com.example.Lights"
    applicationDefaultJvmArgs = listOf("--enable-native-access=ALL-UNNAMED")
}
```

Run in a window, or headless with a script:

```sh
gradle run
gradle run --args="--script lights.txt --out build/lights"
```

Tip: Run `gradle wrapper` once to add `./gradlew` (on Windows: `.\gradlew`) so others can build the project without installing Gradle.

## A whole project

Create a folder with this structure:

```text
lights/
├── pom.xml                  (or settings.gradle.kts and build.gradle.kts)
├── lights.txt
└── src/main/java/com/example/Lights.java
```

Complete `pom.xml` ready to copy:

```xml title="pom.xml"
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
    xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
    xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>

  <groupId>com.example</groupId>
  <artifactId>lights</artifactId>
  <version>1.0-SNAPSHOT</version>

  <properties>
    <maven.compiler.release>25</maven.compiler.release>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    <rethinkj.ui.version>0.1.0-SNAPSHOT</rethinkj.ui.version>
    <main.class>com.example.Lights</main.class>
    <args></args>
  </properties>

  <repositories>
    <repository>
      <id>central-snapshots</id>
      <url>https://central.sonatype.com/repository/maven-snapshots/</url>
      <releases><enabled>false</enabled></releases>
      <snapshots><enabled>true</enabled></snapshots>
    </repository>
  </repositories>

  <dependencies>
    <dependency>
      <groupId>com.rethinkj.ui</groupId>
      <artifactId>rethinkj-ui-kit</artifactId>
      <version>${rethinkj.ui.version}</version>
    </dependency>
    <dependency>
      <groupId>com.rethinkj.ui</groupId>
      <artifactId>rethinkj-ui-fonts</artifactId>
      <version>${rethinkj.ui.version}</version>
      <scope>runtime</scope>
    </dependency>
    <dependency>
      <groupId>com.rethinkj.ui</groupId>
      <artifactId>rethinkj-ui-icons</artifactId>
      <version>${rethinkj.ui.version}</version>
      <scope>runtime</scope>
    </dependency>
  </dependencies>

  <build>
    <plugins>
      <plugin>
        <groupId>org.codehaus.mojo</groupId>
        <artifactId>exec-maven-plugin</artifactId>
        <version>3.6.4</version>
        <configuration>
          <executable>java</executable>
          <commandlineArgs>--enable-native-access=ALL-UNNAMED -classpath %classpath ${main.class} ${args}</commandlineArgs>
        </configuration>
      </plugin>
    </plugins>
  </build>

  <profiles>
    <profile>
      <id>natives-linux-x64</id>
      <activation>
        <os><name>Linux</name><arch>amd64</arch></os>
      </activation>
      <dependencies>
        <dependency>
          <groupId>com.rethinkj.ui</groupId>
          <artifactId>rethinkj-ui-natives-linux-x64</artifactId>
          <version>${rethinkj.ui.version}</version>
          <scope>runtime</scope>
        </dependency>
      </dependencies>
    </profile>
    <profile>
      <id>natives-windows-x64</id>
      <activation>
        <os><family>windows</family><arch>amd64</arch></os>
      </activation>
      <dependencies>
        <dependency>
          <groupId>com.rethinkj.ui</groupId>
          <artifactId>rethinkj-ui-natives-windows-x64</artifactId>
          <version>${rethinkj.ui.version}</version>
          <scope>runtime</scope>
        </dependency>
      </dependencies>
    </profile>
  </profiles>
</project>
```

- **Profiles:** The Maven profiles automatically select the native library for your operating system. If you want one cross-platform build that runs on both Windows and Linux, include both native JARs directly as dependencies without profiles — each JAR only loads on its own OS.
- **Running:** `exec:exec` runs `java` from your `PATH` (JDK 25) with native access enabled. Pass program arguments with `-Dargs="..."` and change the main class with `-Dmain.class=...` (in PowerShell, quote it: `'-Dmain.class=...'`).

## 3. Run it

Start the app in a desktop window with Maven or Gradle:

```sh
mvn compile exec:exec
```

```sh
gradle run
```

Or run it headless (without opening a window) using a script. Create `lights.txt`:

```text snippet="lights-script" title="lights.txt"
```

Then run:

```sh
mvn -q compile exec:exec -Dargs="--script lights.txt --out target/lights"
gradle run --args="--script lights.txt --out build/lights"
```

This creates `off.png`, `off.tree.txt`, `on.png`, and `on.tree.txt` in the output folder and prints their paths. The commands work the same on Windows and Linux. Learn more in [Testing and agents](/docs/testing).

## Artifacts

All artifacts use group ID `com.rethinkj.ui` and version `0.1.0-SNAPSHOT`.

| Artifact | Purpose | Required |
| --- | --- | --- |
| `rethinkj-ui-core` | Core elements, layout, text, input, rendering, windows, and scripts | Always |
| `rethinkj-ui-kit` | Ready-made UI components and themes (includes `core`) | When using kit components |
| `rethinkj-ui-editor` | The code editor (includes `kit`) | When using `CodeEditor` |
| `rethinkj-ui-fonts` | Default fonts (Inter and JetBrains Mono) | For default text rendering |
| `rethinkj-ui-icons` | Default icon font (Fluent UI System Icons) | For icons, trees, and sort arrows |
| `rethinkj-ui-natives-linux-x64`, `rethinkj-ui-natives-windows-x64` | Native libraries (SDL3, wgpu-native, FreeType, HarfBuzz, plus DXC on Windows) | At runtime (see [Platforms](/docs/reference/platforms) for Linux glibc requirements) |

## Native libraries and JVM flags

Because rethinkj UI calls native libraries through Java's Foreign Function & Memory API, you must pass `--enable-native-access=ALL-UNNAMED` when running on the classpath.

If you use the Java module path instead, pass:
- `--enable-native-access=com.rethinkj.ui`
- `--add-modules com.rethinkj.ui.natives.linux.x64` (or `com.rethinkj.ui.natives.windows.x64`), which also pulls in the fonts and icons modules. If you do not include a natives module, add `--add-modules com.rethinkj.ui.fonts,com.rethinkj.ui.icons` explicitly.

On first launch, native libraries are extracted to a per-user cache folder:
- **Windows:** `%LOCALAPPDATA%\rethinkj-ui\natives\`
- **Linux:** `$XDG_CACHE_HOME/rethinkj-ui/natives/` (defaults to `~/.cache/rethinkj-ui/natives/`)

You can override this behavior with system properties:

| System property | Effect |
| --- | --- |
| `rethinkj.ui.natives.dir` | Load native libraries directly from this folder (must include `manifest.txt`). Nothing is extracted. See [Ship your app](/docs/get-started/ship). |
| `rethinkj.ui.natives.cache` | Extract native libraries to this folder instead of the default cache. |
