---
title: Checkbox
description: Checkbox with a label for boolean options in forms and lists.
---

`Checkbox.checkbox` renders a checkbox and label in a row; clicking anywhere on the row toggles it. Use checkboxes for form options that take effect when saved, or for multi-select lists. For settings that apply immediately, use [Toggle](/docs/components/toggle).

Javadoc: [`Checkbox`](/api/com/rethinkj/ui/kit/Checkbox.html).

<Shot src="kit/gallery-{theme}-2x" rows="checkbox off,checkbox on" alt="A checkbox unchecked and checked, in each state" />

## Example

```java snippet="checkbox"
```

| Method | Description |
| --- | --- |
| `checkbox(checked, text, onToggle)` | Checkbox with label |
| `checkbox(checked, onToggle)` | Checkbox alone (add `.label(...)` for accessibility and scripts) |

Passing a `null` handler disables the checkbox.

## Keyboard

**Tab** focuses the checkbox; **Space** and **Enter** toggle it. Clicking with the mouse keeps keyboard focus where it was.

## With a Prop

`checkbox(prop, text)` binds directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.
