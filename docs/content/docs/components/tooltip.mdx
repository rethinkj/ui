---
title: Tooltip
description: Hover and keyboard-focus tooltips for text, shortcuts, errors, truncated text, or custom content.
---

`Tooltip.tooltip` displays a floating hint when the user hovers over an element (after a short delay) or focuses it via keyboard. Moving quickly between adjacent tooltipped items (such as toolbar buttons) shows subsequent tooltips immediately.

Tooltips are display-only and take no input. For interactive floating content, use [Popover](/docs/components/popover).

Javadoc: [`Tooltip`](/api/com/rethinkj/ui/kit/Tooltip.html).

To show the panel yourself, without hover or focus, such as a message at the text cursor, add `Tooltip.panel(text, options)` as an overlay of the element. The code editor shows the diagnostic at the cursor this way.

## Show only when truncated

`Tooltip.whenShortened(anchor, text)` displays a tooltip only when text inside `anchor` is actually truncated with `…` (`El.ellipsis()`). Built-in buttons, tabs, and data grid cells use this automatically.
