---
title: Tooltip
description: A short text, or any content, below an element after the pointer rests on it, or the keyboard focuses it.
---

`Tooltip.tooltip` shows a short text below its anchor once the pointer has rested on it for the theme's delay (half a second). It hides when the pointer leaves or presses. It also shows when the keyboard gives the anchor the focus, until the focus leaves or a key goes down. Once one tooltip has shown, the next anchor the pointer reaches within that delay shows its own at once, as along a toolbar. Use it to name icon buttons and to show text that is cut off. It holds no state, and it takes no input: for content that the user interacts with, use a [Popover](/docs/components/popover).

Javadoc: [`Tooltip`](/api/com/rethinkj/ui/kit/Tooltip.html).

## Example

`Tooltip.tooltip(anchor, text)` returns the anchor. `Tooltip.options()` adds the key combination of the anchor's action on keycaps, a muted description below the text, and another side to show on. Text wraps where it would be wider than `Theme.Sizes.tooltip`.

Where the tooltip would cover its anchor, it goes beside it. `Button.icon` already has a tooltip with its label, and a button's `shortcut` option shows on keycaps in it.

## Any content

`Tooltip.tooltip(anchor, content)` takes a supplier of any element in place of the text, such as a short [Markdown](/docs/components/markdown) document of what an update brings. It is called once the tooltip is due and for each frame it shows; null shows none. Give the content its size:

```java snippet="tooltip-content"
```

<Shot src="examples/docs/tooltip-content/shown-{theme}" alt="An update icon button with a tooltip below it that shows a Markdown document: a heading Version 2.4 and three items" />

A tooltip takes no input (`El.inert()`): presses go to what lies beneath it, Tab passes its links by, and it goes as the pointer leaves the anchor. Content longer than the size it is given is cut off, so keep it short, such as the newest version only; what is to be scrolled or pressed belongs in a [Popover](/docs/components/popover).

## Only where the text is cut

`Tooltip.whenShortened(anchor, text)` shows only while a text of the anchor, or of an element inside it, ends in an ellipsis because it does not fit (`El.ellipsis()`): the whole name of a column, a tab or a button in a narrow window. Where the text fits, it shows nothing. The kit's buttons and the data grid's cells and headers have one. A `tooltip` of the view's own on the same anchor replaces it.

For a panel of your own, `El.whenShortened()` on an overlay shows it only while a text of its anchor is shortened. `Text.shortened()` says whether one text element was shortened, after layout ([Text](/docs/concepts/text)).
