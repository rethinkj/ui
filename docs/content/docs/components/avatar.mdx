---
title: Avatar
description: Circular badge displaying initials or an icon with a color derived from the name.
---

`Avatar.avatar` displays a circular mark with initials or an icon on one of nine background colors chosen automatically from the name's hash — so the same name always gets the same color. Useful for servers, connections, and users.

Javadoc: [`Avatar`](/api/com/rethinkj/ui/kit/Avatar.html).

<Shot src="examples/docs/parts/view-{theme}" crop="prod-eu|localhost" alt="Two avatars: PE for prod-eu on a green, and a server icon for localhost on a pink" />

## Example

```java snippet="avatar"
```

| Method | Description |
| --- | --- |
| `avatar(name)` | Shows initials from the first two words (e.g., `prod-eu` → `PE`) |
| `avatar(name, symbol, size)` | Shows an icon instead of initials at a custom size |
