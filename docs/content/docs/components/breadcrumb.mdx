---
title: Breadcrumb
description: Path navigation bar with child dropdown menus and automatic overflow collapsing.
---

`Breadcrumb.breadcrumb` displays a hierarchical path (such as server › database › schema › table) with optional icons. Clickable items act as links, and the final item represents the current location. Items with children show a chevron that opens a dropdown menu of sub-items.

Javadoc: [`Breadcrumb`](/api/com/rethinkj/ui/kit/Breadcrumb.html), [`Breadcrumb.Crumb`](/api/com/rethinkj/ui/kit/Breadcrumb.Crumb.html), [`Breadcrumb.State`](/api/com/rethinkj/ui/kit/Breadcrumb.State.html).

## Example

```java snippet="breadcrumb"
```

Keep a `Breadcrumb.State` instance in your app state.

Create crumbs with `Breadcrumb.crumb(text, onPress)` (pass `null` for a non-clickable crumb). Chain `.icon(symbol)` for an icon and `.children(supplier)` to add a chevron dropdown whose items are built lazily when opened.

## Overflow behavior

When the path is too wide to fit, middle crumbs automatically collapse into an ellipsis (`…`) menu, followed by the first crumb if needed, and finally the current crumb truncates with a tooltip showing its full name.

<Shot src="examples/docs/details/hidden-{theme}" crop="role=navigation|role=menu" alt="A narrow breadcrumb whose crumbs before orders went into an ellipsis, with its menu open" />

## Keyboard

One Tab stop; **Left/Right** arrows, **Home**, and **End** move between crumbs and dropdown buttons. **Enter** activates a crumb, and **ArrowDown** opens a dropdown menu. The Tab stop stays on the same crumb even when the ellipsis appears or disappears. If that crumb collapses into the ellipsis, the Tab stop moves to the last visited stop that is still visible (a crumb, a chevron, or the ellipsis). Otherwise, it moves to the first one.
