---
title: Breadcrumb
description: A path of crumbs with chevrons between them that open the places inside, giving way to a menu when there is no room.
---

`Breadcrumb.breadcrumb` shows a path, such as server, database, schema and table, as crumbs with an icon each. Every crumb with a press is a link; the last is the current place. The chevron after a crumb with children opens a menu of the places inside it, as a file manager's address bar does.

Javadoc: [`Breadcrumb`](/api/com/rethinkj/ui/kit/Breadcrumb.html), [`Breadcrumb.Crumb`](/api/com/rethinkj/ui/kit/Breadcrumb.Crumb.html), [`Breadcrumb.State`](/api/com/rethinkj/ui/kit/Breadcrumb.State.html).

## Example

```java snippet="breadcrumb"
```

`state.crumbs` is a `Breadcrumb.State` in the app's state.

`Breadcrumb.crumb(text, onPress)` makes a crumb; `onPress` null makes one that only shows. `.icon(symbol)` puts an icon before its text, and `.children(supplier)` gives it a chevron that opens a menu of the supplier's items, which it asks for only while the menu is open.

## When the path does not fit

The crumbs after the first go into a menu behind an ellipsis, from the start on. Where that is not enough, the first crumb goes too. Only then is the current place shortened, with an ellipsis and its whole name in a tooltip. After a change of width the breadcrumb settles one frame later.

## Keyboard

One stop for Tab; the arrows, Home and End move between crumbs, chevrons with a menu and the ellipsis; Enter presses, and Arrow Down opens a menu.
