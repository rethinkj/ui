---

`Breadcrumb.breadcrumb` shows a path, such as server, database, schema and table, with chevrons between the parts. Every part but the last is a link. Where the path does not fit, its start goes into a menu behind an ellipsis.

Javadoc: [`Breadcrumb`](/api/com/rethinkj/ui/kit/Breadcrumb.html), [`Breadcrumb.State`](/api/com/rethinkj/ui/kit/Breadcrumb.State.html).

## Example

```java snippet="breadcrumb"
```

`s.crumbs` is a `Breadcrumb.State` in the app's state.

`Breadcrumb.breadcrumb(t, state, parts, onSelect)`: `onSelect` gets the index of the part pressed. It shows as many parts at the end as fit beside the ellipsis. After a change of width it settles one frame later.

## Keyboard

One stop for Tab; the arrows, Home and End move between parts; Enter presses.
