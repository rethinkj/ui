title: Breadcrumb
description: A path of parts with chevrons between them, where the start gives way to a menu when there is no room.
---

`Breadcrumb.breadcrumb` shows a path, such as server, database, schema and table, with chevrons between the parts. Every part but the last is a link. Where the path does not fit, its start goes into a menu behind an ellipsis.

<Shot src="kit/parts-detail-{theme}-2x" alt="A breadcrumb above a toolbar" />

## Example

```java snippet="breadcrumb"
```

`Breadcrumb.breadcrumb(t, state, parts, onSelect)`: the app keeps a `Breadcrumb.State`; `onSelect` gets the index of the part pressed. It keeps as many trailing parts as fit beside the ellipsis and settles a frame after a change of width.

## Keyboard

One stop for Tab; the arrows, Home and End move between parts; Enter presses.
