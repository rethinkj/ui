---
title: Rail
description: Vertical strip of icon buttons along a window edge for toggling tool windows and running commands.
---

`Rail.rail` renders a narrow vertical band of icon-only buttons along the left or right edge of a window (`Side.LEFT` or `Side.RIGHT`), with a top group, an optional bottom group pinned to the bottom, and optional separators. Pressing a closed toggle item calls `onSelect` with its index; by default, pressing the open item closes it by passing `-1`. Command actions (`Rail.action`) run their own handler without affecting the active panel.

Use `Rail` for edge-docked tool windows and compact icon selectors. For labeled sidebar navigation, use [NavList](/docs/components/nav-list); for document switching, use [Tabs](/docs/components/tabs); for a horizontal row of actions, use [Toolbar](/docs/components/toolbar).

Javadoc: [`Rail`](/api/com/rethinkj/ui/kit/Rail.html), [`Rail.Item`](/api/com/rethinkj/ui/kit/Rail.Item.html), [`Rail.Action`](/api/com/rethinkj/ui/kit/Rail.Action.html), [`Rail.Options`](/api/com/rethinkj/ui/kit/Rail.Options.html), [`Rail.State`](/api/com/rethinkj/ui/kit/Rail.State.html), [`Rail.Dot`](/api/com/rethinkj/ui/kit/Rail.Dot.html), [`Rail.Count`](/api/com/rethinkj/ui/kit/Rail.Count.html), [`Rail.Size`](/api/com/rethinkj/ui/kit/Rail.Size.html), [`Rail.Surface`](/api/com/rethinkj/ui/kit/Rail.Surface.html).

Store one `Rail.State` per rail in your app state. Item indexes count only toggle items (`Rail.Item`) across `top` followed by `bottom` — separators and actions are not counted. When you only need a top group, omit the `bottom` list (`Rail.rail(state, label, side, entries, open, onSelect)`). Passing `null` for `onSelect` disables all toggle items while leaving actions governed by their own handlers.

## Entries

| Helper | Description |
| --- | --- |
| `Rail.item(icon, label)` | Icon toggle button that opens or closes a panel |
| `Rail.action(icon, label, onPress)` | Icon command button independent of panel selection (`null` handler disables it) |
| `Rail.separator()` | Horizontal hairline separating groups of entries |
| `.shortcut(modifiers, key)` | Displays a key combination on keycaps in the tooltip (display only — bind the shortcut in your app) |
| `.description(text)` | Secondary text below the label in the tooltip (followed by `— <status>` when a dot or count is also set) |
| `.dot(kind, text)` | Colored status dot (`Badge.Kind`) at the button's top right, dimmed when disabled; nonempty `text` appears in the tooltip and tree dump |
| `.count([kind,] text)` | Compact count pill (`"3"`, `"99+"`) at the button's top right, defaulting to `Badge.Kind.NEUTRAL` and dimmed when disabled; visually replaces any dot when nonempty |
| `.contextMenu(items)` | Secondary-press context menu on an enabled entry (also opened with the Menu key or Shift+F10); managed by `Rail.State.contextMenu()` |
| `.key(name)` | Stable key for scripts (`#<name>`) and for keeping the roving Tab stop and open context menu across dynamic entry changes |
| `.disabled(true)` | Disables a single entry and skips it during keyboard navigation |
| `.busy(true)` | Shows a spinner on an enabled entry and ignores presses while keeping keyboard focus and any context menu |
| `.progress(fraction)` | Replaces the busy spinner with a determinate progress ring (`0`–`1`, clamped; `NaN` restores the spinner) |

When both a dot and a count are set on an entry, a nonempty count pill replaces the dot visually while nonempty dot text still takes precedence in the tooltip and the button's `value`.

## Options and typed values

| Option | Description |
| --- | --- |
| `closable(false)` | Keeps the open item selected when pressed again instead of passing `-1` (for persistent selectors such as the provider filter in the [AgentChat model picker](/docs/examples/agent-chat)) |
| `size(Rail.Size.REGULAR)` | Compact 24 px buttons (`Rail.Size.LARGE` is the default 32 px) for rails embedded inside popovers or cards |
| `surface(Rail.Surface)` | Background fill: `WINDOW` (default), `BAND` (for rails inside a card or popover), or `TRANSPARENT` (lets a parent glow or wash show through) |
| `indicator(true)` | Draws a vertical accent bar along the rail's outer edge beside the open item |

To select typed values instead of integer indexes (such as enum constants), use `Rail.rail(state, label, side, values, open, value -> item, onSelect)` (with an optional trailing `Rail.Options`). Equal values are deduplicated to their first occurrence, a `null` or missing `open` value leaves the rail closed, and closing the open item passes `null` to `onSelect`.

## Placement, styling, and overflow

The inner hairline and tooltips always face inward — to the right of a `Side.LEFT` rail and to the left of a `Side.RIGHT` rail. `Rail.width()` (or `Rail.width(Rail.Size)`) returns the rail's total width in the current theme (button, padding, and hairline), useful when aligning other window chrome with the rail.

To continue a project color wash from a [TitleBar](/docs/components/title-bar) down through the rail, attach `TitleBar.glow(...)` to the window root, clear the title bar's fill with `.fill(Colors.TRANSPARENT)`, and pass `Rail.options().surface(Rail.Surface.TRANSPARENT)`. See [Extending the tint across the title bar and rail](/docs/components/title-bar#extending-the-tint-across-the-title-bar-and-rail).

When a rail runs out of height, it scrolls with the wheel and follows keyboard focus without a scrollbar. While entries lie past the top or bottom edge, the rail shows a subtle fade on solid surfaces (`WINDOW`, `BAND`) or a divider hairline on `TRANSPARENT` and custom backgrounds so clipped entries stay discoverable.

## Keyboard

The rail is a single Tab stop that remembers the last focused button. **Up/Down** wrap through enabled buttons across separators and groups, **Home/End** jump to the first and last, **Enter/Space** activate the focused button, and **Menu** or **Shift+F10** open the focused entry's context menu. Pointer clicks leave keyboard focus where it was.
