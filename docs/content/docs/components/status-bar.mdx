---
title: StatusBar
description: Bottom window bar for connection status, messages, cursor position, and quick menus.
---

`StatusBar.statusBar` renders a horizontal bar along the bottom of a window with left-aligned items, an optional center message, and right-aligned items. When the window narrows, the message truncates first. Once less than the width of a control is left for it, the message and the separator before it hide. Next, left items truncate, while right items keep their size. Truncated items show their full text in a tooltip.

For a bar at the bottom of a single card, use `Card.footer` ([Card](/docs/components/card)).

Javadoc: [`StatusBar`](/api/com/rethinkj/ui/kit/StatusBar.html).

## Example

```java snippet="status-bar"
```

| Part helper | Description |
| --- | --- |
| `StatusBar.text(text)` | Static muted text |
| `StatusBar.item([tone,] icon, text, onPress)` | Item with optional `Badge.Kind` tint, icon, and click handler |
| `StatusBar.status(state, text, onPress)` | Status indicator (`OK`, `IDLE`, `BUSY` spinner, `WARNING`, `ERROR`) |
| `StatusBar.group(label, parts...)` | Groups related items without a separator between them |
| `StatusBar.menu(part, state, items)` | Adds a dropdown chevron and attaches a menu (pass `state::toggle` as handler) |
| `StatusBar.height()` | Returns the bar height (useful to position toasts above it) |

`null` items and empty groups are ignored automatically.

## Below cards

Cards on the window background, such as `Split.cards` ([Split](/docs/components/split)), need a gap above the status bar. Without it, their edges and shadows touch the bar's top border. Use `theme.space().m()` below the cards to match the gap beside and between them: `margin(0, m, m, m)`.

## Keyboard

Clickable items are focusable with Tab and keep keyboard focus where it was when clicked. Menu items open with **Enter**, **Space**, or **Arrow keys**.
