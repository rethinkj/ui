---
title: ComboBox
description: A choice made by typing, a free text with suggestions, and choices with icons, images or details.
---

`ComboBox.comboBox` looks like a [Select](/docs/components/select) when closed. Typing opens a field with the choices below it, filtered by fuzzy matching. Use it for many choices, or for ones the user knows by name: a schema among dozens, a language. `ComboBox.free` is a text field with suggestions, for a host or a database name: every edit is the value. `ComboBox.items` chooses among items with an icon, an image or an element of their own, and a detail.

`s.schema` and `s.product` are indexes, `s.host` a string, and `s.schemaBox`, `s.hostBox` and `s.productBox` are `ComboBox.State`s, all in the app's state.

| Call | |
| --- | --- |
| `comboBox(t, choices, selected, state, onSelect)` | One of the choices, by index |
| `free(t, value, suggestions, state, onChange)` | Any text. Suggestions open as the user types, none highlighted, so Enter keeps what was typed |
| `items(t, items, selected, state, onSelect)` | Items: `ComboBox.item(text).icon(symbol)`, `.image(image)`, `.leading(theme -> element)`, `.detail(text)` |

A null handler disables it. It is the control height unless the view sets one, so it fits a grid's cell. Pass the same list on every build, so that the box keeps what its filter found.

## Values instead of indexes

`comboBox(t, values, selected, text, state, onSelect)` and `items(t, values, selected, value -> item, state, onSelect)` choose among values of any type, such as records, and hand the value to the handler. The value is found as on [Select](/docs/components/select#values-instead-of-indexes).

The texts or items may be made anew on every build. While they come out equal to the last build's (for items: equal values, texts and details), the filter keeps what it found. The element before an item's text is not compared, so it should follow from the value.

## Keyboard

| Keys | Action |
| --- | --- |
| A letter or digit, Alt+Down, Alt+Up, a press | Open |
| Up, Down, Page Up, Page Down, Home, End | Move the highlight |
| Enter | Choose; the focus stays on the combo box |
| Escape, Tab, Shift+Tab, a press outside | Close; the choice stays as it was |

## With a Prop

`comboBox(t, values, prop, text, state)`, `items(t, values, prop, item, state)` and `free(t, prop, suggestions, state)` take a [`Prop`](/docs/concepts/editing#components-that-take-a-prop), such as a field of an `Editing`, in place of the value and its handler.
