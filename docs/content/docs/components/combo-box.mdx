title: ComboBox
description: Searchable dropdown with fuzzy filtering, free-text suggestions, and rich items with icons or details.
---

`ComboBox.comboBox` shows the current choice and a chevron when closed, and opens a searchable dropdown with fuzzy filtering when clicked or typed into. It looks like a [Select](/docs/components/select) in every state, also while you type into it, so the two sit side by side in a form or a toolbar. Use it when there are many choices or when users know the name they want.

- `ComboBox.free` is an editable text field with autocomplete suggestions (any typed text is accepted).
- `ComboBox.items` displays choices with icons, images, custom leading elements, and secondary detail text.

Javadoc: [`ComboBox`](/api/com/rethinkj/ui/kit/ComboBox.html), [`ComboBox.State`](/api/com/rethinkj/ui/kit/ComboBox.State.html).

Store a `ComboBox.State` in your app state for each combo box.

| Method | Description |
| --- | --- |
| `comboBox(choices, selected, comboBoxState, onSelect)` | Pick one option by index |
| `comboBox(entries, current, comboBoxState, onClear)` | Choices from a `FilterList.Entries` (fixed, on demand, or background) with groups, disabled entries, and an optional clear button |
| `free(value, suggestions, comboBoxState, onChange)` | Free-text input with optional suggestion list |
| `items(items, selected, comboBoxState, onSelect)` | Rich items built with `ComboBox.item(text).icon(symbol)`, `.image(image)`, `.leading(...)`, `.detail(text)` |

Passing a `null` handler (or `null` entries) disables the combo box. Reuse the same choices list when unchanged so filter results stay cached.

## Entries and clear button

Use `comboBox(entries, current, comboBoxState, onClear)` when choices come from a [`FilterList.Entries`](/api/com/rethinkj/ui/kit/FilterList.Entries.html): `Entries.of` for a fixed list, `Entries.by` for choices found for the typed text, or `Entries.background` for searching on another thread (showing a `Loading…` row and cancelling earlier searches as the text changes or the list closes). Group headings, disabled entries (`onChoose == null`), and check marks (`Entry.checked(true)`) work as in [CommandPalette](/docs/components/command-palette).

`current` is shown in the closed box even if it is not among the entries found for the typed text (`null` or `""` for none). When `onClear` is non-null, a clear button (`×`, labeled from `Texts.clear()`) appears inside the closed box before the chevron while `current` is non-empty and the box is enabled; pressing it runs `onClear` without opening the list, and **Tab** reaches it after the box.

## Keyboard

| Key | Action |
| --- | --- |
| Typing, Alt+Down, Alt+Up, click | Open dropdown |
| Up, Down, Page Up, Page Down, Home, End | Move highlight |
| Enter | Select highlighted option (keeps focus on the combo box) |
| Escape, Tab, Shift+Tab, click outside | Close without changing selection |

## With a Prop

`comboBox(values, prop, text, comboBoxState)`, `items(values, prop, item, comboBoxState)`, and `free(prop, suggestions, comboBoxState)` bind directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.
