`Card.card` creates a rounded panel container with padding and spacing to frame sections of your window. `Card.flush` removes outer padding so components like toolbars, data grids, and footers sit edge-to-edge. For grouped settings rows, use [Group](/docs/components/group).

Javadoc: [`Card`](/api/com/rethinkj/ui/kit/Card.html).

| Method | Description |
| --- | --- |
| `card(content...)`, `card(variant, content...)` | Padded column (`space().xl()` padding, `space().l()` gap) |
| `header(title, description, actions...)` | Card heading, optional muted description, and right-aligned actions |
| `flush(parts...)` | Edge-to-edge card without padding, clipped to rounded corners |
| `toolbar(title, secondary, actions...)` | Top bar for a flush card with heading, secondary text, and actions |
| `footer(start, end...)` | Bottom bar for a flush card with a subtle top border |
| `filters(bar)` | Optional filter bar below a toolbar (`null` is omitted) |
| `inset(list)` | Adds inner padding around a list like a tree or nav list |
| `pressable(card, label, selected, onPress)` | Makes an entire card clickable (accent border when `selected`) |
| `footerHeight()` | Returns the footer height (useful to offset toasts above it) |

| Variant | Description |
| --- | --- |
| `OUTLINED` | Panel surface with border and subtle shadow (default) |
| `FILLED` | Flat panel without border or shadow |
| `ELEVATED` | Panel with border and stronger shadow |

`null` children are ignored, so conditional expressions like `changed ? callout(...) : null` work cleanly.

If a card is too narrow for its footer, `start` shrinks first. Next, text items at the end are shortened with an ellipsis, while buttons and other controls at the end keep their size and stay inside the card. If a text item at the end has `shrink(0)`, it keeps its size.
