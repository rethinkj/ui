`Progress` provides indicators for ongoing work: determinate bars, labeled bars with percentage/detail text, indeterminate sweeping bars, thin 2 px card-edge lines, compact rings, and spinners. For loading buttons, use `Button.options().state(BUSY)` ([Button](/docs/components/button)) instead, with `.progress(fraction)` for a ring.

Javadoc: [`Progress`](/api/com/rethinkj/ui/kit/Progress.html).

## Example

```java snippet="progress"
```

| Method | Description |
| --- | --- |
| `bar(fraction[, state])` | Horizontal progress bar (`fraction` clamped to `0.0`–`1.0`) |
| `labeled(label, fraction, detail[, state])` | Bar with title above and right-aligned detail (defaults to percentage) |
| `indeterminate()` | Animated bar when progress percentage is unknown |
| `line([fraction])` | Thin 2 px full-width bar for the top of a card |
| `ring(fraction)` | 16 px ring that fills clockwise from the top, for places too small for a bar |
| `spinner([size])` | Animated circular spinner (default 16 px) |

`Progress.State`: `NORMAL` (accent), `ERROR` (danger, marked `invalid`), `DONE` (success), `PAUSED` (muted).

Tip: Give an `indeterminate()` bar and the `bar(fraction)` that replaces it the same `.key(...)` for a smooth transition.
