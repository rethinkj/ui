`Progress` shows how far something is: a bar with a known fraction, a labeled bar with a name and a percentage, a running bar while the fraction is not known, a thin line along a card's edge, and a spinner for small places such as a busy button. For a button that runs something, use `Button.options().state(BUSY)` ([Button](/docs/components/button)), which shows the spinner itself.

Javadoc: [`Progress`](/api/com/rethinkj/ui/kit/Progress.html).

## Example

```java snippet="progress"
```

| Call | |
| --- | --- |
| `bar(fraction[, state])` | A track with the part done in the state's color, the accent by default; `fraction` from 0 to 1, clamped |
| `labeled(label, fraction, detail[, state])` | The name over the bar and the detail (the percentage when null) at the right |
| `indeterminate()` | A piece that sweeps along the track, while the fraction is not known |
| `line([fraction])` | Two pixels high, full width, no track: along the top of a card's content |
| `spinner([size])` | A ring with a light that goes round, icon-sized unless given |

| `Progress.State` | |
| --- | --- |
| `NORMAL` | The accent |
| `ERROR` | The danger color; `invalid` in the tree |
| `DONE` | The success color |
| `PAUSED` | Muted |

Give a running bar and the bar that replaces it once the fraction is known the same key, and the bar moves on from where the running piece was. Running bars and spinners move with the app's clock, so a script advances it.
