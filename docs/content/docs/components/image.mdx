---
title: Image
description: Display a decoded image with rounded corners, or a placeholder while loading.
---

`com.rethinkj.ui.kit.Image.image` displays a decoded `com.rethinkj.ui.Image` with rounded corners and an alt label. If the image is `null` (for example, while loading in the background or after an error), it displays a styled placeholder with an icon and label.

Because both `core` and `kit` have an `Image` class, qualify one of them when using both in the same file. See [Images](/docs/concepts/images) for decoding and sizing.

Javadoc: [`Image`](/api/com/rethinkj/ui/kit/Image.html).

`Image.image(image, alt)` renders at the image's logical size (shrinking to fit its container if narrower), or renders a placeholder when `image` is `null`.
