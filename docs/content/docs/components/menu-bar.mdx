title: MenuBar
description: Desktop menu bar (File, Edit, View) with Alt/F10 activation, mnemonics, and global shortcuts.
---

`MenuBar.menuBar` renders a horizontal row of top-level menus (File, Edit, View, …) that open [Menu](/docs/components/menu) dropdowns below them. It supports mouse hover switching, **Alt** and **F10** keyboard navigation, mnemonics (like **Alt+F**), and all menu item keyboard shortcuts.

Place it inside your window's [TitleBar](/docs/components/title-bar): `TitleBar.titleBar(icon, title, List.of(menuBar), null, List.of())`. For a small set of actions, use a [Toolbar](/docs/components/toolbar) or dropdown button instead.

Javadoc: [`MenuBar`](/api/com/rethinkj/ui/kit/MenuBar.html), [`MenuBar.State`](/api/com/rethinkj/ui/kit/MenuBar.State.html).

## Example

```java snippet="menu-bar"
```

- Define each top-level menu with `Menu.submenu("&File", items)`. The `&` marks the Alt mnemonic letter (`&&` displays a literal `&`).
- Store a `MenuBar.State` in your app state.
- Attach `MenuBar.keys(menuBarState, menus)` and `MenuBar.keysUp(...)` on your root element to enable Alt/F10 activation, mnemonics, and item shortcuts (combine with other key handlers using `Predicate.or`).

## Interaction

- Click a title to open or close its menu; while open, hovering another title switches directly to that menu.
- Press and release **Alt** (or press **F10**) to focus the menu bar, navigate with **Left/Right/Home/End**, open with **Enter/Space/ArrowDown**, or press a mnemonic letter.
- **Alt+\<letter\>** opens that menu from anywhere in the window.
- Inside an open menu, **Left/Right** moves between top-level menus, and **Escape** closes one level at a time and restores focus to your previous element (such as an editor).

Note: Duplicate shortcuts or a shortcut colliding with an Alt mnemonic throw an exception when building the view.
