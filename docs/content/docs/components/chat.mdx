`Chat` provides the building blocks of a chat transcript and composer in the theme's tokens: right-aligned user message bubbles sized to their text up to `Theme.Chat.bubbleWidth()`, full-width agent answers rendered with `Markdown.fragment` or composed from parts, collapsible one-line tool call rows, a quiet working indicator with a spinner, and a growing multi-line composer with an action bar.

Javadoc: [`Chat`](/api/com/rethinkj/ui/kit/Chat.html), [`Chat.Options`](/api/com/rethinkj/ui/kit/Chat.Options.html), [`Chat.ComposerOptions`](/api/com/rethinkj/ui/kit/Chat.ComposerOptions.html), [`Chat.ToolState`](/api/com/rethinkj/ui/kit/Chat.ToolState.html).

| Method | Description |
| --- | --- |
| `user(text)` / `user(text, options)` | Right-aligned user bubble sized to its text up to `Theme.Chat.bubbleWidth()`, with optional quiet footer |
| `agent(document)` / `agent(document, options)` | Full-width agent answer rendered via `Markdown.fragment` |
| `agent(parts…)` / `agent(options, parts…)` | Full-width agent answer composed of arbitrary parts (`Chat.tool`, `Markdown.fragment`, `Chat.working`); `null` parts are skipped |
| `tool(icon, title, state, open, onToggle, details…)` | One-line collapsible tool call row with icon, title, state (`RUNNING`, `DONE`, `FAILED`), and any detail elements when open |
| `working()` / `working(text)` | Quiet status row with a spinner and `Texts.working()` (or custom text) for the bottom of an active message |
| `transcript(count, message, scroll, heights)` / `transcript(count, message, scroll, heights, onLoadOlder)` | Virtual scrollable transcript centered up to `Theme.Prose.measure()` that follows the newest message, shows a floating jump button while scrolled up, and optionally requests older messages at the top |
| `composer(text, onChange, onSend)` / `composer(text, onChange, onSend, options)` | Composer card with a growing multi-line field and an action bar below it |

## Options

Configure message footers and Markdown rendering with `Chat.options()`:

| Option | Description |
| --- | --- |
| `time(text)` | Muted timestamp shown in tabular figures under the message |
| `copy(clipboard)` | Adds a quiet copy button that writes the message text (or `Markdown.text(document)`) to `clipboard` |
| `copy(clipboard, text)` | Adds a quiet copy button that writes explicit `text` to `clipboard` (for composed `agent(options, parts…)` messages) |
| `copied(Button.Copied)` | Enables brief check-mark and tooltip confirmation on the copy button; keep one `Button.Copied` per message |
| `actions(El…)` | Adds extra quiet actions (such as ghost icon buttons) to the message footer |
| `markdown(Markdown.Options)` | Forwards custom `Markdown.Options` to `Markdown.fragment` in `agent(document, options)` |

## Tool calls

`Chat.tool` is controlled: keep each tool call's `open` boolean in your app state and pass a toggle handler in `onToggle` (or `null` to disable expanding). Closed by default, the row stays on one line with an optional leading icon, an ellipsized title, a state mark (`Progress.spinner()` while `RUNNING`, check mark when `DONE`, error icon when `FAILED`), and a chevron. When `open` is `true`, its detail elements—plain text, monospace output, a `CodeEditor`, or a `DiffView`—render in a panel below a divider.

## Transcript

`Chat.transcript` renders a virtual list of messages of any height centered in a readable column up to `Theme.Prose.measure()` wide. Keep a [`ScrollState`](/api/com/rethinkj/ui/ScrollState.html) and a [`RowHeights`](/api/com/rethinkj/ui/RowHeights.html) in your app state and pass the same instances on every build. While the user is at the bottom, appended messages and a growing last message (such as a streaming [`MarkdownDocument`](/api/com/rethinkj/ui/kit/MarkdownDocument.html) updated with `next`) stay pinned to the end. Scrolling up holds the current place and shows a floating `Jump to newest` button over the bottom until the user presses it or scrolls back to the end. A drag or Shift+click selects across the Markdown of messages (`Markdown.fragment`), including ones scrolled out of view, and Control+C copies it in order. Wrap the transcript with [`Find.find`](/docs/components/find) to find a text across all messages.

Pass an optional `onLoadOlder` callback to fetch earlier messages when the top of the list comes near the view (it can be called more than once for one look at the top, so ignore the calls while a page loads, and pass `null` once no older messages remain), and construct `RowHeights` with a stable key per message (`new RowHeights(estimate, key)`) so inserting older messages at index `0` keeps what is in view at the same place.

## Composer

`Chat.composer` is the input card at the bottom of a chat: a borderless multi-line field that grows with its text up to six lines before scrolling, above a row of removable attachment chips and an action bar with start slots, end slots (such as a `Select` for the model), and a send button that switches to a stop button while the agent works.

<Shot src="examples/docs/chat-composer/view-{theme}" alt="A chat composer card with a two-line prompt, an attach button, two removable file chips, a model select, and a primary send button" />


Plain `Enter` sends when the text is not blank and the agent is not working; `Shift+Enter` inserts a new line. While an input method is composing, `Enter` stays with the input method and does not send. Dropping files onto the card delivers their paths to `onFiles`.

Configure the composer with `Chat.composerOptions()`:

| Option | Description |
| --- | --- |
| `placeholder(text)` | Placeholder and accessible label of the field; defaults to `Texts.composerPlaceholder()` |
| `working(boolean, onStop)` | While `true`, turns the send button into a stop button that runs `onStop` and suppresses `Enter` |
| `attachments(names, onRemove)` | Removable file chips in a row above the action bar; `onRemove` receives the removed chip's index (or `null` for non-removable chips) |
| `start(El…)` | Elements placed at the start of the action bar, such as an attach button; `null` entries are skipped |
| `end(El…)` | Elements placed at the end of the action bar before the send/stop button, such as a `Select`; `null` entries are skipped |
| `onFiles(Consumer<List<Path>>)` | Receives file paths dropped onto the composer card via `El.onFileDrop` |

## Localization and theming

All built-in labels (`Transcript`, `Jump to newest`, `User message`, `Agent message`, `Copy message`, `Working…`, tool state names, `Write a message`, `Send`, `Stop`, and chip removal labels) come from `Texts.CURRENT`, with German translations in `GermanTexts`. User bubble fill and max width fraction live in `Theme.chat()` (`Theme.Chat.DARK` and `Theme.Chat.LIGHT`).
