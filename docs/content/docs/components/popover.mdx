---
title: Popover
description: Non-modal floating panel anchored to a button or element, dismissed by Escape or clicking outside.
---

`Popover.popover` displays floating content anchored to an element (such as a filter form or detail card) while `Popover.State` is open. Unlike [Dialog](/docs/components/dialog), it is non-modal and closes when the user presses **Escape** or clicks outside. Use `Popover.form` for a titled panel with action buttons.

For hover-only hints, use [Tooltip](/docs/components/tooltip).

Javadoc: [`Popover`](/api/com/rethinkj/ui/kit/Popover.html), [`Popover.State`](/api/com/rethinkj/ui/kit/Popover.State.html).

## Example

```java snippet="popover"
```

Store a `Popover.State` in your app state (`isOpen()`, `open()`, `close()`, `toggle()`).

| Method | Description |
| --- | --- |
| `Popover.popover(anchor, popoverState, label, content)` | Floating panel below `anchor` |
| `Popover.popover(anchor, popoverState, side, align, label, content)` | Custom side and alignment (`START`, `CENTER`, `END`, `STRETCH`) |
| `Popover.form(anchor, popoverState, title, content, buttons)` | Panel with heading, scrollable body (if tall), and bottom-right buttons |
| `Popover.panel(popoverState, label, content)` | Standalone overlay element to attach manually |

## Keyboard

Opening moves focus to the first focusable element inside the popover; **Escape** closes it and restores previous focus. **Tab** walks the popover right after its anchor; **Tab** or **Shift+Tab** out of it closes it and leaves the focus where it went.
