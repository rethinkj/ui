`TextField` provides standard themed text inputs:
- `textField` — Single-line text input
- `passwordField` and `revealable` — Masked password input with optional show/hide toggle
- `textArea` — Multi-line wrapping text input for notes and descriptions
- `codeArea` — Monospace multi-line input with indentation

Your app owns the string value and updates it via `onChange`. For syntax highlighting and line numbers, use [CodeEditor](/docs/components/code-editor). For typed values (decimals, dates, enums), use [ValueField](/docs/components/format). For bounded integers with step buttons, use [NumberField](/docs/components/number-field).

Javadoc: [`TextField`](/api/com/rethinkj/ui/kit/TextField.html).

## Example

```java snippet="text-field"
```

| Method | Description |
| --- | --- |
| `textField(value, placeholder, onChange)` | Single-line input (placeholder also serves as label unless `.label(...)` is set) |
| `textField(value, onChange)` | Single-line input without placeholder |
| `withIcon(field, symbol)` | Adds a leading icon inside the input (such as `Symbol.SEARCH`) |
| `invalid(field)` | Applies red danger border and `invalid` state |

Chain core text methods like `.readOnly()`, `.maxLength(n)`, `.w(px)`, `.wFull()`, `.key(...)`, and `.label(...)` onto `textField(...)` **before** wrapping it in `withIcon(...)` or `revealable(...)`.

Passing a `null` handler disables the field. Your handler can also reject or transform edits (for example, keeping only digits). See [Text fields and editors](/docs/concepts/text-fields) for cursors, selection, undo, and IME support.

## Typed values

For typed values, use `ValueField.valueField(format, value, draft, onChange)` with a matching format such as `Format.DECIMAL`, `Format.DATE`, or `Format.choice(...)` (see [Format and ValueField](/docs/components/format)).

## Passwords

`passwordField` masks characters with `•` and blocks copying/cutting. Wrap it in `revealable(field, revealed, onToggle)` to add a show/hide button (tree dumps always stay masked and add `revealed` when visible on screen).

## Text areas

```java snippet="text-area"
```

- `textArea`: Multi-line wrapping input for prose/notes.
- `codeArea`: Monospace multi-line input with horizontal scroll, Tab/Shift+Tab indentation, and auto-indent on Enter. **Ctrl+M** toggles whether Tab indents or moves focus, so press **Ctrl+M, then Tab** (or **Escape, then Tab**) to move focus out.
- Use `.lines(n)` to set height in lines.

## Keyboard

Standard navigation and editing shortcuts: Arrow keys, Home/End (with **Shift** to select, **Ctrl** by word), Backspace/Delete, **Ctrl+A/C/X/V/Z/Y**. Tabbing into a single-line field selects all text. In multi-line fields, **Enter** inserts a newline and **Ctrl+Enter** bubbles to app key handlers.

## With a Prop

`textField(prop[, placeholder])` and `passwordField(prop, placeholder)` bind directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.

## In a tree dump

`text` element with `role=textbox`, label, `placeholder="..."` when the field has a label other than its placeholder (as in a [Form](/docs/components/form)), quoted string, and active states (`disabled`, `readonly`, `password`, `revealed`, `invalid`). When focused, shows `focused caret <n>` (and `anchor <n>` if selected), plus `lines <first>-<last>/<count>` and `(line:col)` for multi-line fields:
