---
title: TextField
description: Single-line fields, password fields that can show their text, text areas and code areas.
---

`TextField.textField` is a single-line text field: a quiet frame with a strong line along the bottom; under the pointer a lighter fill and a strong frame; while focused, frame and line in the accent color. Text areas, selects, combo boxes and the framed code editor share this frame. The same class has `passwordField` and `revealable` for passwords, `textArea` for several lines of prose and `codeArea` for code. The string belongs to the app: every edit hands the new string to the handler, which stores it. For code with line numbers and highlighting, use a [CodeEditor](/docs/components/code-editor). For a typed value, such as a `BigDecimal` or a `LocalDate`, use a [ValueField](/docs/components/format). For a whole number with step buttons, use a [NumberField](/docs/components/number-field).

Javadoc: [`TextField`](/api/com/rethinkj/ui/kit/TextField.html).

`state.filter` and `state.table` are strings in the app's state.

| Call | |
| --- | --- |
| `textField(value, placeholder, onChange)` | A field of the theme's control height and field width. The placeholder is also its label, unless `.label(...)` sets one |
| `textField(value, onChange)` | Without a placeholder |
| `withIcon(field, symbol)` | A muted icon at the left inside the frame, such as `Symbol.SEARCH` for a filter |
| `invalid(field)` | The whole frame in the danger color, also under the pointer and while focused, and the `invalid` state |

`textField` returns the field itself, so core's field methods chain onto it. `withIcon` and `revealable` return a box around the field, so chain the field's methods onto it before wrapping it:

| | |
| --- | --- |
| `.readOnly()` | Selects and copies, takes no edits |
| `.maxLength(n)` | At most `n` code points, typed or pasted |
| `.w(pixels)`, `.wFull()` | Another width |
| `.key(...)`, `.label(...)` | Identity and label |

A null handler disables the field. The handler may refuse an edit (store nothing) or change it (keep only digits); the field shows the app's string. See [Text fields and editors](/docs/concepts/text-fields) for carets, selection, undo and input methods.

## Typed values

For a number, a date or an enum, `ValueField.valueField(Format.DECIMAL, state.amount, state.amountDraft, state::amount)` is this field over a value instead of a string. It hands on values and refuses input that can never become one. A text that is no value yet stays as a draft, with the format's message. See [Format and ValueField](/docs/components/format).

## Passwords

```java snippet="password-field"
```

`passwordField` masks the string: one `•` per character. Copy and cut do nothing, and the tree dump and every selector see only the mask. `revealable(field, revealed, onToggle)` adds a button at the right inside the frame that shows and hides the text; `revealed` is a boolean in the app's state. The button leaves the focus in the field. A shown password can be copied and moves by words as in an ordinary field. The tree dump still shows only the mask, and the field says `password revealed`.

## Text areas

```java snippet="text-area"
```

`textArea` is a multi-line field that wraps lines, for notes and descriptions. `codeArea` is one in the monospaced font that scrolls sideways, where Tab indents, Shift+Tab outdents, Enter keeps the line's indentation and a double press selects a word of code; Escape and then Tab, or Control+M, let Tab move the focus. `.lines(n)` sets the height in lines.

## Keyboard

Arrows, Home and End move the caret, with Shift to select and with Control by words. Backspace and Delete delete; Control+A, C, X, V, Z and Y select all, copy, cut, paste, undo and redo. In a multi-line field, Enter breaks the line, Page Up and Page Down scroll, and Control+Enter goes on to the app's key handlers. Tab into a single-line field selects its text.

## With a Prop

`textField(prop[, placeholder])` and `passwordField(prop, placeholder)` take a [`Prop`](/docs/concepts/editing#components-that-take-a-prop), such as a field of an `Editing`, in place of the value and its handler.
