`Properties.properties` shows names and values in two columns, the names muted, the values read-only fields that select and copy. With a clipboard, a copy button shows under the pointer. Use it for the details of a table, a connection or a file.

Javadoc: [`Properties`](/api/com/rethinkj/ui/kit/Properties.html).

`s.clipboard` is a `Clipboard`, such as `app.clipboard()`.

| | |
| --- | --- |
| `properties(t, properties, clipboard)` | One list; a null clipboard has no copy buttons |
| `groups(t, groups, clipboard)` | Groups with headings |
| `properties(t, properties, clipboard, copied)`, `groups(t, groups, clipboard, copied)` | The same, with copy buttons that confirm a copy, as a [copy button](/docs/components/button#copy-buttons) does. `copied` is a `Button.Copied` in the app's state; null for no confirmation |
| `Properties.property(name, value)`, `.mono()` | A row; `mono()` for identifiers |
| `Properties.group(title, properties)` | A group |

A value too long for its column wraps onto up to three lines, with the name beside its first line. A longer one ends in an ellipsis and shows whole in a tooltip. Selecting and the copy button take the whole value.

## Keyboard

Tab skips the values; a press selects text in them.
