`Properties.properties` displays key-value metadata in two columns: muted labels on the left and selectable, read-only values on the right. When given a `Clipboard`, hovering a row reveals a copy button. Useful for table details, connection info, or file metadata.

Javadoc: [`Properties`](/api/com/rethinkj/ui/kit/Properties.html).

## Example

```java snippet="properties"
```

| Method | Description |
| --- | --- |
| `properties(properties, clipboard[, copied])` | Single list (`null` clipboard hides copy buttons; optional `Button.Copied` enables [copy confirmation](/docs/components/button#copy-buttons)) |
| `groups(groups, clipboard[, copied])` | Multiple titled groups |
| `Properties.property(name, value)`, `.mono()` | Key-value row (`.mono()` uses monospace font for IDs/code) |
| `Properties.property(name, element[, text])` | Element value (`Badge`, link, status indicator); optional `text` enables copying and tree `value` |
| `Properties.group(title, properties)` | Named group of properties |

Long values wrap up to 3 lines, then truncate with `…` and show the full value in a tooltip (selecting or clicking Copy always copies the complete text).

## Element values

Pass an `El` to `Properties.property(name, element)` when a value needs a `Badge`, a link, or a status indicator. Short elements sit centered in a one-line row aligned with text values; taller elements grow the row downwards with the name beside the first line. Pass a third `text` argument when the row should keep a copy button and report `value` in a tree dump.
