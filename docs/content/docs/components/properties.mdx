---
title: Properties
description: Names and values in two columns, the values selectable and copyable, in groups with headings.
---

`Properties.properties` shows names and values in two columns, the names muted, the values read-only fields that select and copy. Values that do not fit end in an ellipsis, and those longer than a field's width (`size().field()`) show whole in a tooltip; with a clipboard, a copy button shows under the pointer. Use it for the details of a table, a connection or a file.

## Example

```java snippet="properties"
```

| | |
| --- | --- |
| `properties(t, properties, clipboard)` | One list; a null clipboard has no copy buttons |
| `groups(t, groups, clipboard)` | Groups with headings |
| `properties(t, properties, clipboard, copied)`, `groups(t, groups, clipboard, copied)` | The same, whose copy buttons confirm a copy with a check mark and the tooltip Copied for a moment: `copied` is a [`Button.Copied`](/docs/components/button#copy-buttons) the app keeps; null for no confirmation |
| `Properties.property(name, value)`, `.mono()` | A row; `mono()` for identifiers |
| `Properties.group(title, properties)` | A group |

Tab passes the values by; a press selects in them.
