`Markdown.markdown` shows a `MarkdownDocument` as a scrolling page: headings, paragraphs with emphasis and links, lists and task lists, quotes, code blocks with highlighting and a copy button, tables and images. The reader follows CommonMark with GitHub's tables, task lists, strikethrough and bare URLs, and never throws. Only the blocks in view are built, so long documents scroll smoothly.

```

`s.readme` is a `MarkdownDocument` in the app's state, read once with `Markdown.parse(source)`: parsing a long text takes a moment. `s.link` is a string the handler writes. `Markdown.markdown(t, document, options)` shows the document.

| Option | |
| --- | --- |
| `onLink(destination -> …)` | A link is pressed: a URL, or `#id` for a heading |
| `images(address -> image)` | The `Image` for an address as written, or null while there is none (a placeholder shows) |
| `languages(language -> highlighter)` | Highlighters for code blocks; `sql` uses `Sql` by default |
| `copy(clipboard)` | Where the code blocks' copy buttons and Control+C after Control+A copy to. A selection within one block of text copies to the app's clipboard |
| `state(Markdown.State)` | Keeps Control+A's selection of the whole document, and the confirmation of a code block's copy button |

`Markdown.rowOf(document, id)` is the row to scroll to for a heading (`app.scrollToRow`), `document.headings()` lists the headings with GitHub's anchors, and `Markdown.text(document)` is the plain text. Each block of text is a read-only field that selects and copies. HTML in the source shows as text.

## The document as data

A `MarkdownDocument` is a tree of records that an app can read, for an outline, a search or the statements of a runbook. `document.blocks()` are the top-level blocks. Two documents are equal only when they are the same object.

```

| Block | |
| --- | --- |
| `Heading(level, content, id)` | Levels 1 to 6; `id` is GitHub's anchor, unique in the document |
| `Paragraph(content)` | |
| `CodeBlock(language, code)` | The first word of a fence's info string, or ""; each line of the code ends in a line feed |
| `Quote(blocks)` | |
| `ListBlock(ordered, start, tight, items)` | Each `Item(task, blocks)`, `task` null for an ordinary item, false for `[ ]` and true for `[x]` |
| `Table(aligns, header, rows)` | An `Align` (`NONE`, `LEFT`, `CENTER`, `RIGHT`) per column; cells are lists of inline parts |
| `ThematicBreak()` | |

| Inline part | |
| --- | --- |
| `Text(text)` | Escapes and entities resolved; raw HTML is text too |
| `Emphasis(content)`, `Strong(content)`, `Strike(content)` | |
| `Code(code)` | Inline code |
| `Link(destination, title, content)` | The destination as written, `#id` for a heading; title "" for none |
| `Image(source, title, alt)` | |
| `SoftBreak()`, `HardBreak()` | A line break that shows as a space, and one that breaks the line |

`MarkdownDocument.plainText(content)` is the text of inline parts as it shows: soft breaks as spaces, images as their description. `document.headings()` lists the headings, those inside quotes and lists too, and `document.tree()` is the whole tree as text, one node per line. `new MarkdownDocument(blocks)` makes a document from blocks of the app's own.

## The state

`Markdown.State`, one per document in the app's state, keeps Control+A's selection of the whole document. `allSelected()` says whether the whole document is selected, and `selectAll(boolean)` selects it or clears the selection, for an Edit menu's Select all. A press anywhere in the document clears it.
