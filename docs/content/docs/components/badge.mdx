title: Badge

`Badge.badge` displays a short label inside a compact tinted pill — useful for column types, tags (`PK`), counts, or removable filters. Supports `NEUTRAL`, `ACCENT`, `SUCCESS`, `WARNING`, and `DANGER` styles (subtle by default, or solid with `strong()`). For status indicators in a bottom bar, use `StatusBar.status` ([StatusBar](/docs/components/status-bar)).

Javadoc: [`Badge`](/api/com/rethinkj/ui/kit/Badge.html), [`Badge.Options`](/api/com/rethinkj/ui/kit/Badge.Options.html).

## Example

```java snippet="badge"
```

| Method | Description |
| --- | --- |
| `badge(text)` | Neutral subtle badge |
| `badge(kind, text)` | `NEUTRAL`, `ACCENT`, `SUCCESS`, `WARNING`, or `DANGER` |
| `badge(text, Badge.options()…)` | Custom options |

| Option | Description |
| --- | --- |
| `kind(Kind)` | Sets the color style |
| `strong()` | Uses a solid fill instead of a subtle tint |
| `icon(Symbol)` | Shows an icon before the text |
| `toolbar()` | Uses toolbar height instead of compact row height |
| `onPress(Runnable)` | Makes the badge clickable (`role=button`, focusable with Tab) |
| `onRemove(Runnable)` | Adds a remove (`×`) button with `role=button` `label="Remove <text>"` |
