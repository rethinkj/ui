---
title: Form
description: Labelled fields, beside or above them, with help, errors and required marks, and buttons at the end.
---

`Form.form` lays out fields with their labels, beside them in a column as wide as the widest label or above them, with help text, error messages and a mark for required fields. Longer forms group their fields under headings, with one label column for all groups, and put fields that belong together, such as host and port, in one row. `Form.buttons` puts buttons at the end of a form, a card or a page. Use it for dialogs and connection settings; for rows of settings, use a [Group](/docs/components/group).

## Example

```java snippet="form"
```

| | |
| --- | --- |
| `Form.form(t, Labels.BESIDE \| ABOVE, fields...)` | The form |
| `Form.field(label, control)` | A field; the label names the control, or the first control inside it, when that is a text field or has no label yet (a select keeps its choice as its label) |
| `.help(text)` | Muted text below that wraps |
| `.error(text)` | Replaces the help in the danger colour and makes the control `invalid`; null for none. A [ValueField](/docs/components/format) whose text is no value shows its format's message without it; this one wins |
| `.required()` | A `*` after the label |
| `.grow()` | In a row, the field takes the room the others leave; its control's width is the least it has |
| `Form.row(fields...)` | Fields side by side, each a full field with its own label, help, error and mark; a row of one field is that field |
| `Form.group(title, entries...)` | Fields and rows under a heading (`role=group`, the heading `level=4`); a group holds no groups |
| `.description(text)` | Muted text under the group's heading that wraps |
| `.divided()` | A hairline between the group and what comes before it; without, room alone sets groups apart |
| `.level(n)` | The heading's level, 4 unless set (below a card's title, which is 3) |
| `Form.labelWidth(t, entries...)` | The width of the label column the entries need |
| `Form.form(t, labels, labelWidth, entries...)` | A form whose label column is at least that wide |
| `Form.buttons(t, buttons...)` | Buttons at the end, at the right |

`form` takes fields, rows and groups in any order (`Form.Entry` is their common type) and leaves out a null entry, a null field in a row or a group, and a row or group whose entries are all null.

With `Labels.BESIDE` the label column is as wide as the widest label in any group, so the controls of all groups start at one x; with `Labels.ABOVE` the groups only structure. Groups lie two steps of spacing further apart than fields (`space().xl()` beside, `xxl()` above), with a divider in the middle of that room where `divided()` asks for one.

In a row, the first field's label stands in the label column and each further one's before its control, `space().m()` after the control before it; with labels above, each field has its label above its control. Each field is as wide as its control, unless it grows, and its help or error lies under its control, as wide, wrapping; the controls stay on the row's first line, so an error under one does not move the other. Where the form is too narrow, the row wraps: a field that goes to the next line keeps its label before its control, at the start of that line, not in the label column.
