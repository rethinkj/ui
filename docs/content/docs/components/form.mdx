---
title: Form
description: Structured forms with side-by-side or stacked labels, groups, multi-field rows, helper text, errors, and warnings.
---

`Form.form` lays out labeled inputs with labels either beside (`Labels.BESIDE`) or above (`Labels.ABOVE`) each control, along with helper text, validation errors, warnings, and required indicators (`*`). Longer forms can organize fields into titled groups and multi-field rows (such as Host and Port side by side).

Use `Form` for dialogs and configuration forms. For toggle-style settings lists, use [Group](/docs/components/group).

Javadoc: [`Form`](/api/com/rethinkj/ui/kit/Form.html).

## Example

```java snippet="form"
```

| Method | Description |
| --- | --- |
| `Form.form(Labels.BESIDE \| ABOVE, entries...)` | Builds the form |
| `Form.field(label, control)` | Labeled field (automatically labels text fields and unlabeled controls) |
| `.help(text)` | Muted helper text below the control |
| `.error(text)` | Danger error text below the control (marks control `invalid`; overrides `ValueField` parse errors and warnings) |
| `.warning(text)` | Amber warning text with icon (keeps control valid; overridden if an error is present) |
| `.required()` | Displays `*` next to the label |
| `.grow()` | Allows a field inside `Form.row` to expand into remaining space |
| `Form.row(fields...)` | Places multiple fields side by side on one row (wraps automatically when narrow) |
| `Form.group(title, entries...)` | Groups fields under a heading (`role=group`, `level=4`) with optional `.description(text)`, `.divided()`, and `.level(n)` |
| `Form.labelWidth(entries...)`, `Form.form(labels, labelWidth, entries...)` | Aligns label columns across separate forms/cards |
| `Form.buttons(buttons...)` | Right-aligned action button row |

`null` entries (and empty rows/groups) are ignored automatically, making conditional fields easy (`showPort ? field(...) : null`).

Warnings display in amber where errors appear, without marking the field invalid or blocking Save:

<Shot src="kit/structure-form-warning-{theme}-2x" alt="A driver version with a warning in amber under it, a host with a warning under its row, and the port's error below it in red" />

## With a Prop

Controls bound to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) display validation and server errors automatically in `Form` just like `.error(text)`.
