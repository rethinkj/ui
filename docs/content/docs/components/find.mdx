`Find.find` gives a multi-line field a find bar, as editors have: it floats over the field's top right corner, marks every match in view, counts them, goes from match to match, replaces, and goes to a line. A [CodeEditor](/docs/components/code-editor) given the app has one already; use `Find.find` for other fields, such as a [text area](/docs/components/text-field#text-areas).

## Keyboard

| Keys | Action |
| --- | --- |
| Control+F | Open with the selection of one line, or the word at the caret, as the text to find |
| Control+H | Open with the replacement row (never in a read-only field) |
| Control+G | Go to a line: `42`, or `42:7` for a column |
| Enter, F3 / Shift+Enter, Shift+F3 | Next and previous match; F3 also with the bar closed |
| Alt+C, Alt+W, Alt+R, Alt+L | Match case, whole word, regular expression, find in selection |
| Enter in the replacement | Replace the current match and go on |
| Control+Alt+Enter | Replace all, as one step of the undo history |
| Escape | Close, leaving the last match selected and the focus in the field |

In a regular expression's replacement, `$1` and `${name}` refer to groups. Case folding follows Unicode's simple folding. A text of up to 200 000 characters (`Find.SYNC_CHARS`) is searched whole at once; a longer one on another thread, with the lines in view first. A regular expression that backtracks without end stops after a deadline.

`Find.open(state)`, `openReplace(state)`, `goToLine(state)`, `goToLine(state, "42")`, `next(state)` and `previous(state)` do the same from a menu.

## What the state says

The bar changes its `Find.State`; the app reads it, for a status line or to search the same way elsewhere, such as in the results of a query. The switches are set only from the bar and its keys.

| `Find.State` | |
| --- | --- |
| `isOpen()` | Whether the bar shows |
| `query()` | The text to find |
| `replacement()` | The text that replaces a match |
| `matchCase()`, `wholeWord()`, `regex()` | The switches Match case, Whole word and Regular expression |
| `inSelection()` | Whether the search keeps to the selection of several lines the bar opened with |
| `close()` | Closes the bar; the field keeps its selection |
