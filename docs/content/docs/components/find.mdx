title: Find
description: Floating find-and-replace bar for multi-line text fields with case, whole-word, regex, and go-to-line support.

`Find.find` attaches a floating find-and-replace bar to the top-right corner of a multi-line text field. It highlights matches, displays match counts, replaces text, and supports jumping to a line number.

[CodeEditor](/docs/components/code-editor) already includes a find bar when given `app`; use `Find.find` for other multi-line fields such as [text areas](/docs/components/text-field#text-areas), or for any [`El.selectionScope()`](/api/com/rethinkj/ui/El.html#selectionScope()) such as [`Markdown.markdown`](/docs/components/markdown) to search across all its read-only fields in order (without replacement, find in selection, or go to line).

Javadoc: [`Find`](/api/com/rethinkj/ui/kit/Find.html), [`Find.State`](/api/com/rethinkj/ui/kit/Find.State.html).

Store a `Find.State` in your app state. `Find.find(app, field, findState)` wraps the field's key, selection, and decorator handlers, so attach any custom handlers to `field` first. A field with shortcuts of its own, such as the code editor's line commands, passes them as a fourth argument, `Find.find(app, field, findState, isCommand)`: while the focus is in the bar, those keys do nothing instead of changing the text out of sight. `Find.next(text, needle, wholeWord, wordCharacters, from)` returns the next occurrence of a text, as the editor's **Ctrl+D** uses it.

You can also trigger find actions from a menu: `Find.open(findState)`, `openReplace(findState)`, `goToLine(findState)`, `goToLine(findState, "42")`, `next(findState)`, and `previous(findState)`.

When the bar jumps to a match, the match scrolls into view below the bar, even on the first line. While the bar is open, the field or selection scope can scroll above its first row by the bar's height ([`coveredTop`](/docs/concepts/text-fields#options)).

Regex replacements support capture groups (`$1`, `${name}`). Large documents are searched on a background thread, and runaway regular expressions time out safely.

## State API

Read `Find.State` to inspect the current search (`isOpen()`, `query()`, `replacement()`, `matchCase()`, `wholeWord()`, `regex()`) or call `close()` to dismiss the bar while keeping the editor's selection. See [`Find.State` Javadoc](/api/com/rethinkj/ui/kit/Find.State.html).

## Keyboard

| Key | Action |
| --- | --- |
| Ctrl+F | Open find bar (pre-filled with current selection or word at cursor) |
| Ctrl+H | Open find & replace (editable fields only) |
| Ctrl+G | Go to line (`42` or `42:7` for line and column) |
| Enter, F3 / Shift+Enter, Shift+F3 | Next / previous match (`F3` also works while closed) |
| Alt+C, Alt+W, Alt+R, Alt+L | Toggle Match case, Whole word, Regex, or Find in selection |
| Enter (in Replace field) | Replace current match and move to next |
| Ctrl+Alt+Enter | Replace all (as one undo step) |
| Escape | Close bar and return focus to the editor |
