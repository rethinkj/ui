---
title: Callout
description: Highlighted info, warning, danger, or success banner with optional action buttons.
---

`Callout.callout` displays a highlighted notice for information, warnings, errors, or success messages, with a title, optional body text, and optional action buttons. For temporary auto-dismissing notifications, use [Toast](/docs/components/toast). For empty views, use [EmptyState](/docs/components/empty-state).

Javadoc: [`Callout`](/api/com/rethinkj/ui/kit/Callout.html).

<Shot src="examples/docs/status/view-{theme}" crop="role=note" alt="A warning callout, Restart needed, with its text and a Restart button" />

## Example

```java snippet="callout"
```

Call `Callout.callout(kind, title, text, actions...)` with `Kind.INFO`, `WARNING`, `DANGER`, or `SUCCESS` (`text` may be `null`). Colors come from `theme.callout()`.

Action buttons sit to the right of the text when there is enough space, and automatically wrap below the text in narrow containers.
