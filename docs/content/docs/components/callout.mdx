---

`Callout.callout` is a note that stands out from the content around it: information, a warning or a danger, with a title, a text and optional buttons, such as "Restart needed" with Restart. For a message that goes by itself, use a [Toast](/docs/components/toast); for a page with nothing to show, an [EmptyState](/docs/components/empty-state).

<Shot src="kit/structure-choices-{theme}-2x" alt="Among other choices, a warning callout with a Restart button" />

## Example

```java snippet="callout"
```

`Callout.callout(t, kind, title, text, actions...)`, with `Kind.INFO` (the strong border and an info icon), `WARNING` or `DANGER`.
