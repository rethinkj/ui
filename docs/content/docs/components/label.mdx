`Label.label` creates a text element using one of the active theme's typography styles and colors. Use it for all standard UI text. For custom fonts or sizes, use `El.text` ([Text and fonts](/docs/concepts/text)).

Javadoc: [`Label`](/api/com/rethinkj/ui/kit/Label.html).

## Example

```java snippet="label"
```

| Variant | Use for |
| --- | --- |
| `NORMAL` | Standard UI text (default) |
| `MUTED` | Hints, captions, secondary values |
| `MONO` | Code, SQL identifiers, aligned numbers (JetBrains Mono) |
| `HEADING` | Card headings |
| `SECTION` | Section headings on a page |
| `TITLE` | Page titles |
| `STRONG` | Emphasized titles (e.g., popover headings) |
| `SMALL` | Compact 12 px muted text (status bar details, match counts) |

Chain `.wrapText()` for multi-line wrapping or `.ellipsis()` for truncation.
