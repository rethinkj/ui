`Label.label` is a text element in one of the theme's type styles and text colours. Use it for every piece of text the kit does not draw itself. For text of your own font and size, use the core's `El.text` ([Text and fonts](/docs/concepts/text)).

## Example

```java snippet="label"
```

| Variant | |
| --- | --- |
| `NORMAL` | The text of the interface (the default) |
| `MUTED` | Secondary text: hints, captions, values beside their names |
| `MONO` | Code, identifiers and values that line up, in JetBrains Mono |
| `HEADING` | The title of a section |
| `TITLE` | The title of a page, above its sections |
| `STRONG` | A title inside a section, such as a card's |

The result is a text element: chain `.wrapText()` for text that wraps, `.ellipsis()` for text that is cut off.
