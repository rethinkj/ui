title: CommandPalette
description: Searchable command launcher (Ctrl+Shift+P) with fuzzy matching, prefix sources, and multi-step prompts.

`CommandPalette.palette` is a floating command launcher at the top of the window. Users type to fuzzy-search commands from your menus, or type a prefix (such as `@`) to search custom items like tables or files. Commands can also prompt for follow-up input or live-previewed choices.

For picking a value inside a form, use [ComboBox](/docs/components/combo-box).

Javadoc: [`CommandPalette`](/api/com/rethinkj/ui/kit/CommandPalette.html), [`CommandPalette.State`](/api/com/rethinkj/ui/kit/CommandPalette.State.html).

## Example

```java snippet="command-palette"
```

- Store one `CommandPalette.State` in your app state.
- `CommandPalette.commands(menus)` automatically turns `Menu.Item` lists (including menu bar menus) into searchable commands (`Query: Run`, `File: Export › CSV`) with their icons, shortcuts, and handlers. Add custom commands with `FilterList.entry(text, onChoose)`.
- `CommandPalette.Source(prefix, placeholder, entries)` adds a prefixed search mode (e.g., `@` for tables). Prefixes cannot be empty or `>`.
- `CommandPalette.keys(paletteState)` binds **Ctrl+Shift+P** and **F1** to open the palette. Call `state.palette.open("@")` to open directly into a source (for example on Ctrl+P).
- When the search box is empty, the 5 most recently used commands appear under **Recently used**.
- Set `entry.key(...)` to keep highlight tracking stable across list updates, `entry.keepsOpen(true)` for entries that load more results without closing, and `state.palette.onClose(...)` to clean up when dismissed.

## Entry sources and fuzzy matching

Sources use `FilterList.Entries` (also used by [ComboBox](/docs/components/combo-box)):

| Factory | Behavior |
| --- | --- |
| `Entries.of(list)` | Filters using `Fuzzy`, sorting best matches first (reuse the same list instance when unchanged to keep cached results) |
| `Entries.inOrder(list)` | Same as `of`, preserving original order among equal-scoring matches |
| `Entries.by(text -> list)` | Custom synchronous filter function |
| `Entries.background(app, name, text -> list)` | Async background search showing `"Loading…"` while running and cancelling stale queries |

You can also use `Fuzzy` directly in your own search UI. Characters must match in order, with bonuses for word boundaries (after spaces, `_`, `.`, `-`, or camelCase) and consecutive letters. Case-sensitive only when the query contains an uppercase letter:

```java snippet="fuzzy"
```

| Method | Description |
| --- | --- |
| `Fuzzy.score(query, text)` | Match score (higher is better), or `Fuzzy.NO_MATCH` (`Integer.MIN_VALUE`) |
| `Fuzzy.positions(query, text)` | Matched character indexes for highlighting, or `null` if no match |
| `Fuzzy.matcher(query)` | Allocation-free reusable [`Matcher`](/api/com/rethinkj/ui/kit/Fuzzy.Matcher.html) for scoring many strings on one thread |

## Multi-step commands

Inside a command's handler, call `state.palette.ask(stage)` to transition into a follow-up step instead of closing:

| Stage | Description |
| --- | --- |
| `Stage.choose(placeholder, entries, highlight)` | Pick from a second list |
| `.preview(onHighlight, onCancel)` | Live preview as the user navigates options (reverts on Escape) |
| `Stage.input(placeholder, text, onEnter)` | Prompt for text input (e.g., Rename) |

## Keyboard

| Key | Action |
| --- | --- |
| Ctrl+Shift+P, F1 | Open palette (with `keys(paletteState)`) |
| Up, Down, Page Up, Page Down, Home, End | Move highlight |
| Enter | Run highlighted command |
| Escape, click outside | Close, cancel any preview, and restore focus |
