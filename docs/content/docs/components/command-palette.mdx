title: CommandPalette
description: A searchable list of every command, and of other things after a prefix, opened with Control+Shift+P.
---

`CommandPalette.palette` is an overlay at the top of the window with a field over a list. Type to find any command of the app's menus by fuzzy matching, or, after a prefix such as `@`, a table or anything else the app lists. A command can ask for more before it acts, such as a theme previewed as the highlight moves. Use it in apps with many commands. For choosing a value in a form, use a [ComboBox](/docs/components/combo-box).

It opens `size().paletteTop()` (72) below the window's top, `size().palette()` (560) wide, with a field `size().paletteField()` (32) high over at most 12 rows of `size().paletteRow()` (28); with fewer it is only as high as they are, and in a window too short for it the list shows fewer rows and scrolls.

## Example

```

- `s.palette` is a `CommandPalette.State` in the app's state.
- `CommandPalette.commands(menus)` turns `Menu.Item`s, a menu bar's titles too, into commands named by their path (`Query: Run`, `File: Export › CSV`), with their icons, shortcuts and handlers. Add your own with `FilterList.entry(text, onChoose)`.
- A `CommandPalette.Source(prefix, what, entries)` lists other things after its prefix.
- `CommandPalette.keys(state)` opens the palette with Control+Shift+P and F1; `state.open("@")` opens it at a source, as for Control+P.
- While nothing is typed, the last five commands chosen come first, under "Recently used". `state.recent()` lists their texts, the last first, and `state.text()` is what is typed.

## Lists and fuzzy matching

What a source lists is a `FilterList.Entries`, which a [ComboBox](/docs/components/combo-box) takes too:

| | |
| --- | --- |
| `Entries.of(list)` | The kit filters the list with `Fuzzy`. While nothing is typed, all entries show in their order; then the matches, best first within their groups, the shorter text first among equal matches. Pass the same list object while it does not change, so that the result is kept |
| `Entries.inOrder(list)` | The same, but equal matches keep their order, as commands want |
| `Entries.by(text -> list)` | The app finds the entries for the typed text, on the app's thread on every build; they show in the order given |
| `Entries.background(app, name, text -> list)` | The same on another thread. The last entries stay, with a row "Loading…", until the answer comes; a new text cancels the search before it |

`Fuzzy` is the kit's matching, for an app's own search. The query's characters must occur in the text in order. A match scores higher at the starts of words (after a space, `_`, `.` or `-`, and at a camelCase capital) and for characters next to each other, lower for gaps: `"ot"` ranks `orders_total` before `customer_note`. Case counts only when the query has a capital letter.

```

| | |
| --- | --- |
| `Fuzzy.score(query, text)` | The score, higher for a better match, or `Fuzzy.NO_MATCH` (`Integer.MIN_VALUE`) |
| `Fuzzy.positions(query, text)` | The indexes of the characters the best match takes, one per character of the query, to highlight them; null when it does not match |
| `Fuzzy.matcher(query)` | A `Matcher` for scoring many texts without allocating. Use it on one thread |
| `matcher.score(text)`, `matcher.positions(text)` | As above |
| `matcher.matches(text)` | Whether the query's characters occur in the text in order |
| `matcher.isEmpty()` | Whether the query is empty; every text matches an empty query with the score 0 |

## Asking for more

A command's handler may call `state.ask(stage)` instead of letting the palette close:

| | |
| --- | --- |
| `Stage.choose(placeholder, entries, highlight)` | A list to choose from |
| `.preview(onHighlight, onCancel)` | Called as the highlight moves, and undone on Escape: a theme previewed live |
| `Stage.input(placeholder, text, onEnter)` | A text to type, as for Rename |

## Keyboard

| Keys | Action |
| --- | --- |
| Control+Shift+P, F1 | Open (with `keys(state)`) |
| Up, Down, Page Up, Page Down, Home, End | Move the highlight |
| Enter | Choose |
| Escape, a press outside | Close, undo a preview, and give the focus back |

Keys it does not take go on to the root, so the app's shortcuts still work.
