---
title: Icon
description: Render Fluent UI System Icons, custom font glyphs, or images as icons.
---

`Icon.icon` renders an `Icon` — a `Symbol` from the bundled Fluent UI System Icons font (`rethinkj-ui-icons`), a glyph from your own font (`Icon.glyph`), or an image (`Icon.image`) — sized at 16×16 px by default. Buttons, tabs, menus, toolbars, and grids all accept any `Icon`.

Javadoc: [`Icon`](/api/com/rethinkj/ui/kit/Icon.html), [`Symbol`](/api/com/rethinkj/ui/kit/Symbol.html).

## Example

```java snippet="icon"
```

| Method | Description |
| --- | --- |
| `icon(icon)` | Primary text color, `size().icon()` (16 px) |
| `icon(icon, variant)` | `NORMAL`, `MUTED`, `DISABLED`, `DANGER`, `WARNING`, `SUCCESS`, or `ACCENT` |
| `icon(icon, variant, size)` | Custom pixel size |

`Symbol` uses uppercase Fluent icon names (`TABLE`, `KEY`, `SEARCH`, `CHEVRON_RIGHT`, etc.). Always add a `.label(...)` to icon-only clickable elements.

## Your own icons

Every component that takes an icon accepts any `Icon`, not only a `Symbol`:

- `Icon.glyph(font, codePoint, label)` — one glyph of your own font, sized to a square of the icon's size and colored by the component's variant or tone, just as a `Symbol` is.
- `Icon.image(image, label)` — an `Image` fitted into the icon's square (`Image.Fit.CONTAIN`). A picture keeps its own colors and dims to 40 % opacity while disabled.
