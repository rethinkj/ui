---
title: Icon
description: Render Fluent UI System Icons in standard or status colors.
---

`Icon.icon` renders a `Symbol` from the bundled Fluent UI System Icons font (`rethinkj-ui-icons`), sized at 16×16 px by default. Buttons, tabs, menus, and grids also accept `Symbol` directly.

Javadoc: [`Icon`](/api/com/rethinkj/ui/kit/Icon.html), [`Symbol`](/api/com/rethinkj/ui/kit/Symbol.html).

<Shot src="kit/icons-{theme}-2x" alt="A sheet of every symbol at 16 and 20 pixels with their names" />

## Example

```java snippet="icon"
```

| Method | Description |
| --- | --- |
| `icon(symbol)` | Primary text color, `size().icon()` (16 px) |
| `icon(symbol, variant)` | `NORMAL`, `MUTED`, `DISABLED`, `DANGER`, `WARNING`, `SUCCESS`, or `ACCENT` |
| `icon(symbol, variant, size)` | Custom pixel size |

`Symbol` uses uppercase Fluent icon names (`TABLE`, `KEY`, `SEARCH`, `CHEVRON_RIGHT`, etc.). Always add a `.label(...)` to icon-only clickable elements.
