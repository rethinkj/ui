title: Toolbar
description: Responsive action bar of buttons, toggles, split buttons, and groups that moves overflowing items into a More menu.
---

`Toolbar.toolbar` arranges icon buttons, labeled buttons, toggles, split buttons, groups, and spacers in a single horizontal row. When the toolbar narrows, trailing items automatically move into a **More** overflow menu. For a simple card title bar with a few buttons, `Card.toolbar` ([Card](/docs/components/card)) is simpler.

Javadoc: [`Toolbar`](/api/com/rethinkj/ui/kit/Toolbar.html), [`Toolbar.Item`](/api/com/rethinkj/ui/kit/Toolbar.Item.html).

Store a `Toolbar.State` in your app state.

| Item helper | Description |
| --- | --- |
| `Toolbar.button(icon, label, onPress)` | Icon button with tooltip |
| `Toolbar.text([variant,] icon, text, onPress)` | Labeled button |
| `Toolbar.toggle(icon, label, on, onToggle)` | Toggle button (appears as a checked item in the More menu) |
| `Toolbar.split(variant, icon, text, onPress, menu, items)` | Split button (appears as a submenu in the More menu) |
| `Toolbar.group(items...)` | Visually grouped tools (separated by dividers in the More menu) |
| `Toolbar.spacer()` | Flexible space pushing following items to the right |

Chain `.options(Button.options()...)` on buttons or split buttons to set busy/disabled states, danger tone, or shortcut tooltips ([Button options](/docs/components/button#options)).

## Keyboard

One Tab stop. **Left/Right** arrows move between items (wrapping around), **Home/End** jump to first/last, and **Enter/Space** activate. Clicking leaves keyboard focus where it was.
