title: EmptyState

---

`EmptyState.emptyState` fills the place of a list, a grid or a page that has nothing to show, and says why and what to do: "No tables match" with Clear filter. Center it in the empty area.

Javadoc: [`EmptyState`](/api/com/rethinkj/ui/kit/EmptyState.html).

<Shot src="examples/docs/status/view-{theme}" crop="role=status" alt="An empty state: a search icon, No tables match, Try another filter and a Clear filter button" />

## Example

```java snippet="empty-state"
```

`EmptyState.emptyState(symbol, title, text, action)`; the text and the action may be null. Title and text wrap where the room is narrow, as in a side panel, each line centered.
