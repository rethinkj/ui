title: EmptyState
description: Centered placeholder with an icon, title, message, and optional action button when there is no content.
---

`EmptyState.emptyState` displays a helpful placeholder when a list, grid, or page has nothing to show (for example, `"No tables match"` with a **Clear filter** button).

Javadoc: [`EmptyState`](/api/com/rethinkj/ui/kit/EmptyState.html).

<Shot src="examples/docs/status/view-{theme}" crop="role=status" alt="An empty state: a search icon, No tables match, Try another filter and a Clear filter button" />

## Example

```java snippet="empty-state"
```

Call `EmptyState.emptyState(symbol, title, text, action)` (`text` and `action` may be `null`). Title and text wrap and center automatically in narrow containers.
