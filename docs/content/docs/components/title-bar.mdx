---
title: TitleBar
description: Custom title bar for frameless windows with app icon, title, menu bar, search box, actions, and window buttons.
---

`TitleBar.titleBar` renders a custom title bar for frameless windows (`Window.options().frameless()`), including app icon, title, optional start/center/end slots (for a [MenuBar](/docs/components/menu-bar), search box, and action buttons), and native-behaving minimize, maximize/restore, and close buttons. Dragging, double-clicking to maximize, and Windows 11 snap layouts work automatically.

Javadoc: [`TitleBar`](/api/com/rethinkj/ui/kit/TitleBar.html).

## Example

```java snippet="title-bar"
```

| Method | Description |
| --- | --- |
| `titleBar(icon, title, end...)` | Icon, title, and right-side actions |
| `titleBar(icon, title, start, center, end)` | Full layout with left slot (e.g. `MenuBar`), centered slot (`null` if none), and right slot |
| `search(placeholder, shortcut, onPress)` | Centered search button (e.g., to open a [CommandPalette](/docs/components/command-palette)) |

Use `AppIcon.appIcon(16, color, symbol)` to match your window icon. `TitleBar` reads `WindowState.CURRENT` automatically to toggle Maximize/Restore and dim when inactive. For custom title bar layouts, see `El.windowPart` in [Windows, icons and dialogs](/docs/concepts/platform).
