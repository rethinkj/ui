`NumberField.numberField` is a text field for a whole number with Decrease and Increase buttons inside its frame. Use it for counts and sizes with a small step, such as a fetch size or a tab width. For a value one adjusts by feel, use a [Slider](/docs/components/slider).

## Example

```java snippet="number-field"
```

`NumberField.numberField(t, label, value, min, max, step, onChange)`, or without the label in a [Form](/docs/components/form) field or a [Group](/docs/components/group) row, which give the field theirs. Typing hands on every whole number, also outside the range, which then shows as `invalid`; an edit that leaves no number is refused. The buttons keep the focus in the field and are disabled at the ends.

## Keyboard

Up and Down step, Page Up and Page Down by ten steps, within the range.

## In a tree dump

The field is a text element with `role=spinbutton` and its number; the buttons are `role=button` `label="Decrease"` and `"Increase"`:

```text file="examples/src/test/resources/golden/docs/choices/view.tree.txt" start="role=spinbutton label=\"Fetch size\"" count="6"
```

The label is the `spinbutton`'s, so a script finds it with `press role=spinbutton label="Fetch size"`. A `.label(...)` on the result would label the box around field and buttons instead.

## With a Prop

`numberField(t, prop, min, max, step)` takes a `Prop` in place of the value and its handler, such as a field of an [Editing](/docs/concepts/editing) of a record: it writes the prop back, shows its field's error, and is disabled when the prop cannot be written.
