`NumberField.numberField` is a text field for a whole number with Decrease and Increase buttons inside its frame. Use it for counts and sizes with a small step, such as a fetch size or a tab width. For a value one adjusts by feel, use a [Slider](/docs/components/slider).

`s.fetchSize` is an `int` in the app's state.

`NumberField.numberField(t, label, value, min, max, step, onChange)`. Leave out the label in a [Form](/docs/components/form) field or a [Group](/docs/components/group) row, which label the field. Typing hands on every whole number, also one outside the range, which then shows as `invalid`. An edit that leaves no number is refused. The buttons keep the focus in the field and are disabled at the ends of the range.

## Keyboard

Up and Down step; Page Up and Page Down step by ten, within the range.

## With a Prop

`numberField(t, prop, min, max, step)` takes a [`Prop`](/docs/concepts/editing#components-that-take-a-prop), such as a field of an `Editing`, in place of the value and its handler.

## In a tree dump
