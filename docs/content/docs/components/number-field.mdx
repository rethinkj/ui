`NumberField.numberField` is a numeric input field for whole numbers (`int`) with built-in Decrease and Increase buttons. Use it for bounded numeric settings like fetch size or tab width. For dragging across a range, use [Slider](/docs/components/slider).

Javadoc: [`NumberField`](/api/com/rethinkj/ui/kit/NumberField.html).

```java snippet="number-field"
```

Call `NumberField.numberField(label, value, min, max, step, onChange)` (omit `label` inside [Form](/docs/components/form) or [Group](/docs/components/group), which label it automatically). Numbers outside `[min, max]` display as `invalid` with `"<min> to <max>"`. Step buttons disable automatically at the bounds and keep focus in the field.

## Allowing partial input (`Draft`)

To allow users to temporarily clear the field or type a leading `-` (when `min < 0`), pass a `ValueField.Draft` from your state: `numberField(label, value, min, max, step, draft, onChange)`. Invalid drafts show as `invalid` while your state keeps the last valid integer.

## Keyboard

**Up** / **Down** step by `step`; **Page Up** / **Page Down** step by `10 * step` within `[min, max]`.

## With a Prop

`numberField(prop, min, max, step)` binds to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record (which handles partial drafts automatically).
