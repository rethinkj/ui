title: TabGroups
description: Multi-window tab manager supporting drag reordering, tearing tabs off into new windows, and docking them back.
---

`TabGroups` manages tabs across multiple windows, just like a web browser or IDE: users can reorder tabs, drag a tab out into a new floating window, and drop it onto any other window's tab bar. Store one `TabGroups` in your shared app state and render each window with `groups.tabs(...)`.

For single-window tabs without tear-off support, use [Tabs](/docs/components/tabs).

Javadoc: [`TabGroups`](/api/com/rethinkj/ui/kit/TabGroups.html).

## Callbacks and programmatic control

| Method | Description |
| --- | --- |
| `onWindowClose(group -> …)` | Action when closing a detached window: `dockAll` (default) or `closeAll` |
| `onCloseTab((group, index) -> …)` | Custom close handler (e.g., to confirm unsaved changes before calling `close`) |
| `onClosed(tab -> …)` | Notification after a tab is closed |

You can also manipulate tabs from code with `select`, `add`, `close`, `move`, `dock`, `toNewWindow`, `dockAll`, `closeAll`, and `groupOf(tab)`. See [`TabGroups` Javadoc](/api/com/rethinkj/ui/kit/TabGroups.html).

## Focus and state across windows

`TabGroups` remembers keyboard focus per tab automatically. To preserve text cursors, undo history, or scroll positions when moving a tab to another window, store `FieldState` or `ScrollState` inside each tab's own model object (see [Several windows](/docs/concepts/windows)).

## User interaction

- Drag a tab along a bar to reorder, drag it outside to tear off into a new window, or drop it onto another window's tab bar to dock it. Press **Escape** to cancel a drag.
- Right-click any tab for **Move to new window** and **Move back to main window** (essential on Linux Wayland, where apps cannot position floating windows).
