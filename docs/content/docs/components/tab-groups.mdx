---
title: TabGroups
description: Tabs in several windows that move, tear off into a window of their own and dock again.
---

`TabGroups` keeps an app's tabs in groups, one per window, as browsers and editors do: the user moves tabs along a bar, drags one out into a new window that follows the pointer, and drops it on a bar of any window. The app keeps one `TabGroups` in its state and builds each window's tabs with `groups.tabs(...)`; everything the user does goes through it. For tabs in one window, plain [Tabs](/docs/components/tabs) are enough.

Javadoc: [`TabGroups`](/api/com/rethinkj/ui/kit/TabGroups.html).

## The rest of the API

| | |
| --- | --- |
| `onWindowClose(group -> …)` | What closing a group's window does: `dockAll` (the default) or `closeAll` |
| `onCloseTab((group, index) -> …)` | What closing a tab by its cross, Control+W or Control+F4 does; `close` unless set. A handler that asks about unsaved changes calls `close` once the user agrees |
| `onClosed(tab -> …)` | Called for each closed tab |

`select`, `add`, `close`, `move`, `dock`, `toNewWindow`, `dockAll` and `closeAll` do from code what the user does. They and the questions, such as `groupOf(tab)`, are on [`TabGroups`](/api/com/rethinkj/ui/kit/TabGroups.html) and [`TabGroups.Group`](/api/com/rethinkj/ui/kit/TabGroups.Group.html).

## The state

Content is built only for each group's active tab, inside an element of its own for each tab (`#content-<n>` in a tree dump), so that the focus is remembered per tab: `app.focus(panel)` and switching tabs go back to where the focus was in that tab, or to its `defaultFocus()` element if it has not had the focus yet. State the kit keeps by an element's identity, such as a field's caret and undo history or a scroll offset, stays with the window that showed it. To take it along with the tab, keep it in the tab's own state (`FieldState`, `ScrollState`). See [Several windows](/docs/concepts/windows).

## What the user can do

- Drag a tab along its bar to move it, out of the bar to tear it off into a window that follows the pointer, and over any bar to dock it there, before the tab the marker shows.
- Drag a window's only tab to move the whole window.
- Escape, or a release that gets lost, puts a torn tab back where it was.
- The tab's menu has Move to new window and, in a group's window, Move back to main window. On Wayland, where apps cannot place windows, these are the way to do it.
