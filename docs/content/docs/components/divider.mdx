---
title: Divider
description: Horizontal or vertical separator line with an optional centered label.
---

`Divider.divider` draws a thin horizontal line across a column (with an optional centered label such as `"or"`). `Divider.vertical` draws a vertical separator between button groups in a row.

Javadoc: [`Divider`](/api/com/rethinkj/ui/kit/Divider.html).
