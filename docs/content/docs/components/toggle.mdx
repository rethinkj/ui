---
title: Toggle
description: A switch for a setting that applies at once, with its text beside it.
---

`Toggle.toggle` is a switch and its text in a row; a press anywhere on the row flips it. Use it for settings that take effect at once, such as Autocommit. For a choice that applies only when a form is saved, a [Checkbox](/docs/components/checkbox) reads better; for a switch in a settings list, use `Group.switchRow` ([Group](/docs/components/group)).

## Example

```java snippet="toggle"
```

| Call | |
| --- | --- |
| `toggle(t, on, text, onToggle)` | The switch and its text |
| `toggle(t, on, onToggle)` | The switch alone; give it a `.label(...)` |

`on` is the app's state, which `onToggle` flips. A null handler disables it. The row is as wide as switch and text, so its press area and focus ring are too.

## Keyboard

Tab reaches it; Space and Enter flip it. A press leaves the focus where it was.
