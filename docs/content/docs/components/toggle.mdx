---
title: Toggle
description: On/off switch with label for settings that take effect immediately.
---

`Toggle.toggle` renders an on/off switch and label in a row; clicking anywhere on the row toggles it. Use toggles for settings that apply immediately (such as Autocommit). For form options applied on Save, use [Checkbox](/docs/components/checkbox). For full-width settings rows, use `Group.switchRow` ([Group](/docs/components/group)).

Javadoc: [`Toggle`](/api/com/rethinkj/ui/kit/Toggle.html).

## Example

```java snippet="toggle"
```

| Method | Description |
| --- | --- |
| `toggle(on, text, onToggle)` | Switch with label |
| `toggle(on, onToggle)` | Switch alone (add `.label(...)` for accessibility and scripts) |

Passing a `null` handler disables the toggle.

## Keyboard

**Tab** focuses the toggle; **Space** and **Enter** flip it. Clicking with the mouse keeps keyboard focus where it was.

## With a Prop

`toggle(prop, text)` binds directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.
