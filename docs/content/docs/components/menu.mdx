`Menu` displays action items in a floating overlay: below a button (`Menu.dropdown`), at the mouse cursor (`Menu.contextMenu`), or standalone (`Menu.menu`). Items support icons, checkmarks, keyboard shortcuts, and nested submenus.

For top-level File/Edit/View menus, use [MenuBar](/docs/components/menu-bar). For picking a value in a form, use [Select](/docs/components/select).

Javadoc: [`Menu`](/api/com/rethinkj/ui/kit/Menu.html), [`Menu.Item`](/api/com/rethinkj/ui/kit/Menu.Item.html), [`Menu.State`](/api/com/rethinkj/ui/kit/Menu.State.html).

## Context menu

```java snippet="context-menu"
```

`Menu.contextMenu(target, menuState, items)` opens on right-click, or on the **Menu** key / **Shift+F10** when focused inside `target` (positioned near the `current` or `selected` item). If `target` already handles right-click (for example, to select a row first), call `state.context.openAt(x, y)` inside your handler. A text field inside `target` opens [its own menu](/docs/components/text-field#context-menu) instead, unless it is inside a virtual list row.

## Items

| Method | Description |
| --- | --- |
| `Menu.item(label, onChoose)` | Action item (`null` handler disables it) |
| `.shortcut(Key.CONTROL, "N")` | Binds and displays a platform-formatted shortcut (`Ctrl+N`) |
| `.alsoShortcut(Key.CONTROL, "PageDown")` | Binds an additional hidden shortcut |
| `.shortcut("Ctrl+Enter")` | Displays shortcut text without binding it |
| `.icon(Symbol)` | Icon before the label |
| `.checked(boolean)` | Checkmark in the icon slot (or at the right if `.leading(...)` is used) |
| `.danger()` | Red danger styling for destructive actions like Delete |
| `.leading(() -> element)` | Custom leading element (up to 16×16 px, e.g., color swatch or avatar) |
| `Menu.separator()` | Horizontal divider line |
| `Menu.submenu(label, items)` | Nested submenu opening beside the item |

If an item's text is too wide for the window, it truncates with an ellipsis. A tooltip shows the full text after you hover over the item, or immediately when you highlight it with the keyboard. In a tree dump, the item's label is still the full text.

`Menu.Item` is a record (`isSeparator()`, `isEnabled()`), and `Menu.shortcutText(key)` formats a `Key` for display.

## State API

Keep one [`Menu.State`](/api/com/rethinkj/ui/kit/Menu.State.html) per menu: `isOpen()`, `open()`, `openAt(x, y)`, `close()`, `toggle()`, `active(level)`, and `submenu(level)`.

## Keyboard

| Key | Action |
| --- | --- |
| Up, Down, Home, End | Move highlight (skips separators) |
| Enter, Space | Activate item |
| Right, Left | Open / close submenu |
| Escape | Close submenu, then menu |
| Tab | Close menu |
| Typing a letter/digit | Jump to next item starting with that character |

In headless scripts, advance past the fade-in animation (`advance 0.3`) before clicking a menu item or taking a snapshot.
