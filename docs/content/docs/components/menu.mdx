`Menu` shows items in an overlay: below a button with `Menu.dropdown`, at the pointer with `Menu.contextMenu`, or alone with `Menu.menu`. Items have text, an icon or a check mark, a shortcut shown at the right, and submenus to any depth. For the File, Edit and View menus of a window, use a [MenuBar](/docs/components/menu-bar); for one value among choices, a [Select](/docs/components/select).

Javadoc: [`Menu`](/api/com/rethinkj/ui/kit/Menu.html), [`Menu.Item`](/api/com/rethinkj/ui/kit/Menu.Item.html), [`Menu.State`](/api/com/rethinkj/ui/kit/Menu.State.html).


`state.context` is a `Menu.State` in the app's state.

`Menu.contextMenu(target, menuState, items)` opens the menu on a secondary press on the target, or on the Menu key and Shift+F10 while the focus is inside it. The keys open it at the bottom left of the focused element's first descendant that is `current`, else `selected`, such as a grid's cursor cell or a tree's selected row, else of the focused element; that point is kept within the focused element's bounds. If the target already has an `onSecondaryPress` handler (a row that selects itself first), call `state.context.openAt(x, y)` there.

## Items

| | |
| --- | --- |
| `Menu.item(label, onChoose)` | An item; a null handler disables it |
| `.shortcut(Key.CONTROL, "N")` | A key combination that runs it, shown as the platform writes it (`Ctrl+N`) |
| `.alsoShortcut(Key.CONTROL, "PageDown")` | A further key combination that runs it; only the first one shows |
| `.shortcut("Ctrl+Enter")` | A text that only shows |
| `.icon(Symbol)` | An icon before the text |
| `.checked(boolean)` | A check mark in the icon's place, or at the item's end where it has a leading element |
| `.danger()` | The text and icon in the theme's danger color, for an action that destroys something, such as Delete |
| `.leading(() -> element)` | Any small element before the text in place of the icon, at most 16 pixels square: a color's swatch, an avatar |
| `Menu.separator()` | A line |
| `Menu.submenu(label, items)` | A submenu, opening beside the item |

An [`Item`](/api/com/rethinkj/ui/kit/Menu.Item.html) is a record, so an app can read its items back, as a palette or a help page of shortcuts does. `isSeparator()` says whether it is a line, and `isEnabled()` whether it can be chosen or opens a submenu that has items. `Menu.shortcutText(key)` writes a `Key` as the platform does, such as `Ctrl+Shift+N`, for a tooltip or a hint of the app's own.

A submenu of colors with a swatch before each hue's name, the chosen one checked at its end, as a [ComboBox](/docs/components/combo-box) checks its current item. A [CommandPalette](/docs/components/command-palette) of these items shows the same:

`Menu.shortcuts(items)` is a key handler for the root. It runs the enabled item of a key combination, in submenus too, when no element on the focus path took the key, whether the menu is open or not. Two items with one combination throw an exception when the view is built.

## The state

The app keeps one [`Menu.State`](/api/com/rethinkj/ui/kit/Menu.State.html) per menu. `isOpen()`, `open()`, `openAt(x, y)`, `close()` and `toggle()` open and close it; `active(level)` and `submenu(level)` are the highlighted item and the item whose submenu is open, at each level.

## Keyboard

The menu takes the focus as it opens and gives it back as it closes. Enter, Space and Down on a dropdown's button open the menu with its first enabled item highlighted, and Up with the last. A press with the pointer highlights none.

| Keys | Action |
| --- | --- |
| Up, Down, Home, End | Move the highlight, past separators |
| Enter, Space | Choose |
| Right, Left | Open and close a submenu |
| Escape | Close a submenu, then the menu |
| Tab | Close the menu |
| A letter or digit | The next item that starts with it |

The item a key highlights stays in view. The pointer highlights the item it rests on and opens its submenu after the theme's delay. Menus fade in and out, so a script advances the clock past the fade (`advance 0.3`) before it presses an item or takes a snap.
