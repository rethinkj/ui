`Radio.radioGroup` displays mutually exclusive choices stacked vertically so users can compare all options at once. For a compact horizontal switcher of 2–3 modes, use [Segmented](/docs/components/segmented). For many choices, use [Select](/docs/components/select).

Javadoc: [`Radio`](/api/com/rethinkj/ui/kit/Radio.html).

## Swatches

`Radio.swatches` displays visual options (such as colors or icons up to 16×16 px) in a wrapping row with tooltips. [HuePicker](/docs/components/hue-picker) is built on this:

```java snippet="swatches"
```

| Method | Description |
| --- | --- |
| `swatches(options, selected, onSelect)` | Choose by index (`Radio.option(name, () -> element)`) |
| `swatches(values, selected, value -> option, onSelect)` | Choose by typed value (`null` is allowed as an option) |
| `swatches(values, prop, value -> option)` | Bind to a `Prop` |

## Keyboard

One Tab stop. **Arrow keys** move selection (wrapping around), **Home/End** jump to first/last, and **Space** selects the first option when none is selected.

## With a Prop

`radioGroup(values, prop, text)` binds directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.
