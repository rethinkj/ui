`Radio.radioGroup` shows a few choices one above the other, one of them chosen. Use it when the choices need to be read side by side, such as line endings or indentation. For a compact choice of two or three views, use [Segmented](/docs/components/segmented); for many choices, a [Select](/docs/components/select).

Javadoc: [`Radio`](/api/com/rethinkj/ui/kit/Radio.html).

## Swatches

`Radio.swatches` is the same group for choices that show an element instead of a text, such as colors or icons. Each `Radio.option(name, theme -> element)` is a square in a row that wraps, with the name in a tooltip and as the radio's label. [HuePicker](/docs/components/hue-picker) is one made of the theme's hues.

```java snippet="swatches"
```

| Call | |
| --- | --- |
| `swatches(theme, options, selected, onSelect)` | By index |
| `swatches(theme, values, selected, value -> option, onSelect)` | By value; null among the values is a choice like any other, such as no color |
| `swatches(theme, values, prop, value -> option)` | A `Prop` |

Keep the element at most 16 pixels square, the size of a checkbox. The chosen option has a round ring around it. The keyboard's focus is a rounded square around the chosen option, or the first while none is chosen.

## Keyboard

The group is one stop for Tab. The arrows choose the next and the previous choice, around the ends. Home and End choose the first and the last. Space chooses the first while none is chosen.

## With a Prop

`radioGroup(theme, values, prop, text)` takes a [`Prop`](/docs/concepts/editing#components-that-take-a-prop), such as a field of an `Editing`, in place of the value and its handler.
