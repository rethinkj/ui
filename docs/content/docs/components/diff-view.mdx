title: DiffView
description: Two versions of a text side by side or unified, with changed lines and words tinted, unchanged lines collapsed, and F7 to go from change to change.
---

`DiffView` shows how two versions of a text differ, in the code editor's look. The app supplies both strings, such as a file and its version in the app's repository; the framework holds no version control. It lives in `rethinkj-ui-editor`, package `com.rethinkj.ui.editor`, beside [CodeEditor](/docs/components/code-editor).

Javadoc: [`DiffView`](/api/com/rethinkj/ui/editor/DiffView.html), [`Diff`](/api/com/rethinkj/ui/editor/Diff.html).

- Added lines are tinted green and removed lines red. Side by side, lines that replace others are tinted blue on both sides; unified, they show as removed lines above added ones. The changed words inside them are stronger. The gutter's change lane and the scrollbar mark each change.
- Unchanged lines more than three away from a change collapse into a row that expands on a press.
- **F7** goes to the next change and **Shift+F7** to the one before. `DiffView.State.nextChange()` and `previousChange()` do the same from a button.
- Both sides are read-only. `Diff.lines(oldText, newText)` gives the changes without a view.
