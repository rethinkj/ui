`Select.select` is a button with the current choice and a chevron. A press opens a [Menu](/docs/components/menu) of the choices below it, with the current one checked. Use it for a few choices that one reads, such as a driver, an encoding or an isolation level. For more than a screenful, or where the user knows what to type, use a [ComboBox](/docs/components/combo-box). For two or three choices always in view, use [Radio](/docs/components/radio) or [Segmented](/docs/components/segmented).

Javadoc: [`Select`](/api/com/rethinkj/ui/kit/Select.html).

`state.driver` is the index of the current choice and `state.driverMenu` a `Menu.State`, both in the app's state.

`Select.select(theme, choices, selected, menuState, onSelect)` takes the choices as texts, the index of the current one, the `Menu.State` and a handler that gets the new index. A null handler disables it. It has the width and frame of a text field. A long choice ends in an ellipsis; the control's label keeps the whole text.

## Values instead of indexes

`Select.select(theme, values, selected, text, menuState, onSelect)` chooses among values of any type, such as an enum's constants or records. The function `text` gives each value its text:

These rules hold for every component that chooses among values: Select, [ComboBox](/docs/components/combo-box), [Radio](/docs/components/radio), [Segmented](/docs/components/segmented) and [NavList](/docs/components/nav-list).

- The selected value is found with `equals`. Null is a value like any other when the list contains it.
- A value that is not in the list, or null when the list has no null, selects nothing.
- Equal values show once, and the arrow keys go from the selected value to the next one that differs.
- The handler gets the value. A null handler disables the component.
- For an enum, pass `List.of(E.values())`.

The tree dump is the same as with indexes.

## Keyboard

| Keys | Action |
| --- | --- |
| Enter, Space, Alt+Down, Alt+Up | Open; in the menu, the menu's keys apply |
| Down, Up (closed) | Choose the next or the previous choice |
| Home, End (closed) | Choose the first or the last |
| A letter or digit (closed) | Choose the next choice that starts with it |

## With a Prop

`select(theme, values, prop, text, menuState)` takes a [`Prop`](/docs/concepts/editing#components-that-take-a-prop), such as a field of an `Editing`, in place of the value and its handler.
