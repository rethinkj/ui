---
title: Select
description: Dropdown button that opens a menu for picking one option from a short list.
---

`Select.select` displays the current choice in a button that opens a [Menu](/docs/components/menu) of options below it. It looks like a secondary [Button](/docs/components/button) and stays pressed in while its list is open, so it sits in a toolbar beside buttons and [Segmented](/docs/components/segmented). Use it for short lists (such as driver, encoding, or isolation level). For large or searchable lists, use [ComboBox](/docs/components/combo-box). For 2–3 always-visible options, use [Radio](/docs/components/radio) or [Segmented](/docs/components/segmented).

Selecting the current option closes the menu without calling `onSelect`.

Javadoc: [`Select`](/api/com/rethinkj/ui/kit/Select.html).

Store the selected index and a `Menu.State` in your app state. Call `Select.select(choices, selected, menuState, onSelect)` (`null` handler disables it). Call `menuState.opens(Side.TOP)` to prefer opening the list above the button (falling back to the opposite side where it does not fit).

- Matching uses `equals` (`null` is allowed if present in `values`).
- Values not in `values` leave nothing selected.
- For enums, pass `List.of(MyEnum.values())`.

## Keyboard

| Key | Action |
| --- | --- |
| Enter, Space, Alt+Down, Alt+Up | Open dropdown menu |
| Down, Up, Home, End (while closed) | Change selection directly |
| Typing a letter/digit (while closed) | Jump to next matching option |

## With a Prop

`select(values, prop, text, menuState)` binds directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.
