`NavList.navList` is a list of items with an icon and a count, under headings, with one item selected and an accent mark at its left. Use it for the pages of a settings window or the sections of an app's sidebar. For nested data, use a [Tree](/docs/components/tree); for tabs over content, [Tabs](/docs/components/tabs).

## Example

```java snippet="nav-list"
```

| | |
| --- | --- |
| `navList(t, items, selected, onSelect)` | A list of `NavList.Item`s |
| `navList(t, count, index -> item, selected, onSelect)` | A virtual list for many items, building only those in view |
| `NavList.item([icon,] label)`, `.count(text)` | An item and its count |
| `NavList.heading(label)` | A heading, skipped by the keys |

In a card, wrap it in `Card.inset(t, list)`.

## Keyboard

One stop for Tab; Up, Down, Home, End, Page Up and Page Down move the selection, skipping headings.
