`NavList.navList` is a list of items with an icon and a count, under headings. One item is selected, with an accent mark at its left, its icon in the accent and its text a little heavier; a count sits in a quiet badge, and a heading is a small caption over its group. Use it for the pages of a settings window or the sections of an app's sidebar. For nested data, use a [Tree](/docs/components/tree); for tabs over content, [Tabs](/docs/components/tabs).

Javadoc: [`NavList`](/api/com/rethinkj/ui/kit/NavList.html).

`state.page` is the index of the selected item in the list, headings counted, in the app's state.

| | |
| --- | --- |
| `navList(entries, selected, onSelect)` | A list of `NavList.Entry`s: items and headings |
| `navList(count, index -> entry, selected, onSelect)` | A virtual list for many entries, which builds only those in view |
| `NavList.item([icon,] label)`, `.count(text)` | An item and its count |
| `.indent(levels)` | An item set in by steps, as the headings of an outline under theirs |
| `.key(name)` | The item's key in the tree dump, `#name`, in place of `item-<index>` |
| `.disabled(true)` | An item that cannot be selected, skipped by the keys |
| `NavList.heading(label)` | A heading, skipped by the keys |

Items and headings are both a `NavList.Entry`, so a list that mixes them is a `List<NavList.Entry>`.

In a card, wrap it in `Card.inset(list)`.

## Values instead of indexes

`navList(values, selected, value -> item, onSelect)` lists values of any type. With a function from a value to its group, `navList(values, selected, value -> item, value -> group, onSelect)` puts a heading wherever the group changes, and none for a null group. The value is found as on [Select](/docs/components/select#values-instead-of-indexes).

## Keyboard

One stop for Tab. Up, Down, Home, End, Page Up and Page Down move the selection, skipping headings and disabled items.

## In a tree dump

`role=listbox` with its label, `disabled` without an `onSelect`. Items are `role=option` with `selected` or `disabled` and `pos`, and the key `item-<index>`, counting headings, unless the item has a key of its own. A heading is a row without a role, keyed `item-<index>`:
