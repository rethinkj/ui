`NavList.navList` is a list of items with an icon and a count, under headings. One item is selected, with an accent mark at its left. Use it for the pages of a settings window or the sections of an app's sidebar. For nested data, use a [Tree](/docs/components/tree); for tabs over content, [Tabs](/docs/components/tabs).

Javadoc: [`NavList`](/api/com/rethinkj/ui/kit/NavList.html).

`state.page` is the index of the selected item in the list, headings counted, in the app's state.

| | |
| --- | --- |
| `navList(theme, items, selected, onSelect)` | A list of `NavList.Item`s |
| `navList(theme, count, index -> item, selected, onSelect)` | A virtual list for many items, which builds only those in view |
| `NavList.item([icon,] label)`, `.count(text)` | An item and its count |
| `NavList.heading(label)` | A heading, skipped by the keys |

In a card, wrap it in `Card.inset(theme, list)`.

## Values instead of indexes

`navList(theme, values, selected, value -> item, onSelect)` lists values of any type. With a function from a value to its group, `navList(theme, values, selected, value -> item, value -> group, onSelect)` puts a heading wherever the group changes, and none for a null group. The value is found as on [Select](/docs/components/select#values-instead-of-indexes).

## Keyboard

One stop for Tab. Up, Down, Home, End, Page Up and Page Down move the selection, skipping headings.
