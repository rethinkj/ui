`NavList.navList` displays a vertical list of selectable navigation items with optional icons, count badges, indentation, and section headings. Use it for app sidebars and settings pages.

For hierarchical expandable data, use [Tree](/docs/components/tree). For horizontal tabs, use [Tabs](/docs/components/tabs).

Javadoc: [`NavList`](/api/com/rethinkj/ui/kit/NavList.html).

| Method | Description |
| --- | --- |
| `navList(entries, selected, onSelect)` | List of `NavList.Entry` items and headings (`selected` index includes headings) |
| `navList(count, index -> entry, selected, onSelect)` | Virtualized list for large navigation lists |
| `outline(entries, current, onPress)` | Table of contents that marks the `current` heading and tells every press, also one on the current item, so a press goes back to its heading |
| `NavList.item([icon,] label)` | Navigation item with optional `.detail(text)`, `.count(text)`, `.trailing(element)`, `.actions(buttons...)`, `.indent(levels)`, `.key(name)`, and `.disabled(true)` |
| `NavList.heading(label)` | Non-selectable section heading with optional `.count(text)` and `.open(open, onToggle)` |

Inside a card, wrap the list with `Card.inset(list)`.

## Second line, trailing elements, and collapsible groups

Items can carry a quiet second line (`.detail(text)`), a trailing element after the count (`.trailing(element)`, such as a time the app formats and a status icon), and action buttons at the far right (`.actions(buttons...)`) that show only while the item is selected or under the pointer; pressing one does not select the item. Headings can show a quiet count (`.count(text)`) and open and close the group below them (`.open(open, onToggle)`): the app keeps which groups are open and leaves a closed group's items out of the entries.

All rows share one height, so that the virtual form stays virtual: two lines high when any item has a detail, or in the virtual form when its first item has one.

## Keyboard

The list is one Tab stop: **Up**, **Down**, **Home**, **End**, **Page Up**, and **Page Down** move selection, skipping headings and disabled items. Collapsible headings are focusable buttons; **Enter** or **Space** while focused runs `onToggle`.

## In a tree dump

`role=listbox` (`disabled` if `onSelect` is `null`). Items are `role=option` with `selected`/`disabled`, `pos`, and key `#item-<index>` (unless `.key(...)` is set), with any detail text, trailing element, and action buttons as children. Plain headings have no role; collapsible headings are `role=button` with `expanded` or `expanded=false`:
