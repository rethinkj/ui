`rethinkj-ui-kit` (package `com.rethinkj.ui.kit`) provides ready-made desktop components built on `core`, complemented by the optional `rethinkj-ui-editor` and `rethinkj-ui-diagram` modules. Every component is a static method returning an `El` that you can chain further (for example, `Button.button(PRIMARY, "Run", onRun).key("run")`).

Components automatically read styling from `Theme.CURRENT` ([Themes](/docs/concepts/themes)). Your app owns all state, and passing a `null` handler disables a control.

Javadoc: [`com.rethinkj.ui.kit`](/api/com/rethinkj/ui/kit/package-summary.html), [`com.rethinkj.ui.editor`](/api/com/rethinkj/ui/editor/package-summary.html), [`com.rethinkj.ui.diagram`](/api/com/rethinkj/ui/diagram/package-summary.html), [`com.rethinkj.ui.diagram.er`](/api/com/rethinkj/ui/diagram/er/package-summary.html), [`com.rethinkj.ui.diagram.git`](/api/com/rethinkj/ui/diagram/git/package-summary.html).
