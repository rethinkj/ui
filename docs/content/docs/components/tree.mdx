title: Tree
description: Nodes that open and close, such as servers, databases, schemas, tables and columns.
---

`Tree.tree` shows a hierarchy whose nodes open and close, with keyboard navigation, lazy loading and a virtual list of rows, so a tree of 100 000 visible nodes scrolls as smoothly as one of ten. The app implements `Tree.Model` over its own nodes and keeps which are open and which is selected. For a flat list of sections, use a [NavList](/docs/components/nav-list); for rows with columns, a [DataGrid](/docs/components/data-grid).

## The model

```java snippet="tree-model"
```

| Method | |
| --- | --- |
| `roots()` | The nodes at the top, in order |
| `children(node)` | The children, or null while they are not known: the tree shows a loading row |
| `isLeaf(node)` | A leaf has no mark and does not open |
| `label(node)` | The row's text, also its label in a tree dump |
| `icon(node)` | An element before the label, such as an icon; null by default |
| `loading(node)` | The text of the loading row; "Loading…" by default |

## The tree

```java snippet="tree"
```

`Tree.tree(theme, model, isOpen, selected, onSelect, onToggle, onActivate)`:

| Parameter | |
| --- | --- |
| `isOpen` | Whether a node is open; the app keeps the set |
| `selected`, `onSelect` | The selected node, and a handler told only of a change |
| `onToggle` | `(node, open) -> …`: the user opens or closes a node. Start loading its children here, off the app's thread, and change the state when they arrive. |
| `onActivate` | Enter or a double press on a node, such as opening a table |

A secondary press selects the row first and then runs the tree's own `onSecondaryPress`, so `Menu.contextMenu(t, tree, state, items)` acts on the row it opened on. The tree rows are rounded; in a card, wrap it in `Card.inset(t, tree)`. The tree follows the selection, and when nodes open it scrolls their children into view.

## Keyboard

| Keys | Action |
| --- | --- |
| Up, Down, Home, End, Page Up, Page Down | Move the selection |
| Right | Open, then go to the first child |
| Left | Close, then go to the parent |
| Enter | Activate |

A press selects, a press on the chevron selects and opens or closes, and a double press opens or closes and activates. The marks are icons and need `rethinkj-ui-icons`.

## In a tree dump

The tree is `role=tree`, a list of rows with `rows <first>-<last>/<count>`. Each row is `role=treeitem` with the node's label, the key `row-<index>`, and `expanded` or `expanded=false` (not on leaves), `level=<n>` and `pos=<n>/<siblings>`; the selected row is `selected`. Marks have the key `mark-<index>`.
