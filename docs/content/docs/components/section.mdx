---
title: Section and page
description: Scrollable page layout with a top-level title and structured sections.
---

`Section.page` creates a scrollable page with a title and padded layout, and `Section.section` groups content under a heading and optional description. Combine them with [Group](/docs/components/group) and [Card](/docs/components/card) to build settings pages, detail panels, and dashboards.

Javadoc: [`Section`](/api/com/rethinkj/ui/kit/Section.html).

<Shot src="examples/settings-2x-appearance" light="examples/settings-light-2x-appearance" alt="The Settings example: a page of sections with groups of rows" />

## Example

```java snippet="section"
```

| Method | Description |
| --- | --- |
| `page(title, sections...)` | Scrollable page with a level-1 title and generous padding |
| `section(title, description, content...)` | Section with a level-2 heading, optional description, and content |

`null` sections and content are ignored automatically.
