---
title: Completion
description: A list of completions at the caret of a text field, such as table and column names in a query.
---

`Completion.complete` gives a text field, usually a [CodeEditor](/docs/components/code-editor), a list of completions below its caret. The app's function gets the part of the word before the caret and returns the entries. The list opens as the user types, and Enter or Tab puts the chosen entry in place. For choosing among fixed values in a form, use a [ComboBox](/docs/components/combo-box).

- `editor` is the editable field. The caret is where its caret is, which `s.editor`, a `CodeEditor.State`, knows.
- `s.completion` is a `Completion.State` in the app's state.
- `new Completion.Entry(text, symbol, kind)` shows an optional icon and a muted kind at the right. The kit filters nothing: return the entries in the order to show.
- The function runs on every keystroke while the list is open. Keep it fast, or look things up off the app's thread and keep the answers in the state.

The list shows up to eight rows and scrolls to keep the highlighted entry in view.

## When it opens and closes

A letter, digit or `_` typed opens the list once the word has two characters and the caret stands right after it. Control+Space opens it with an empty word. A deletion keeps it open while the word is not empty; any other edit closes it. A press elsewhere and the wheel close it.

## Keyboard

| Keys | Action |
| --- | --- |
| Up, Down | Move the highlight, around the ends |
| Page Up, Page Down | Move it by eight |
| Enter, Tab | Put the highlighted entry in place, as one step of the undo history |
| Escape | Close |
| Left, Right, Home, End | Close and move the caret |

Keys it does not take reach the field's own handler, Control+Enter among them.
