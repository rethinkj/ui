title: Completion

`Completion.complete` attaches an autocomplete popup below the text cursor of a field (usually a [CodeEditor](/docs/components/code-editor)). Your callback receives the word prefix before the cursor and returns matching suggestions. Pressing **Enter** or **Tab** inserts the selected suggestion.

For picking from a fixed list in a form, use [ComboBox](/docs/components/combo-box).

Javadoc: [`Completion`](/api/com/rethinkj/ui/kit/Completion.html), [`Completion.State`](/api/com/rethinkj/ui/kit/Completion.State.html).

## Example

```java snippet="completion"
```

- Pass the editor element, its current cursor offset (`state.editor.caret()`), and a `Completion.State` stored in your app state.
- `new Completion.Entry(text, symbol, kind)` displays an optional icon and muted kind label. Suggestions appear in the exact order you return. Use the 4-argument constructor `new Completion.Entry(text, symbol, kind, insert)` when the inserted text differs from the display label (for example, adding quotes).
- **Async suggestions:** Keep synchronous callbacks fast. For slow lookups (like database metadata), use `Completion.completeInBackground(app, field, caret, completionState, name, suggest)` to run on a background thread and show a `"Loading…"` row until results arrive. You can also set `state.completion.loading(true)` manually if you manage background loading yourself.
- The callback receives only the current word. Inspect your full text at `caret` if you need preceding context (like `orders.`).

## Trigger behavior

- Typing letters, digits, `_`, or a character the highlighter adds to its words (`wordCharacters()`, such as `$`) opens the popup automatically once the word reaches 2 characters.
- Call `state.completion.openAfter(".")` to trigger immediately after specific characters (such as after a table name).
- **Ctrl+Space** opens completions manually at any position.
- Clicking outside, scrolling the wheel, or deleting the entire word closes the popup.

## Keyboard

| Key | Action |
| --- | --- |
| Up, Down | Move highlight (wraps around) |
| Page Up, Page Down | Move highlight by 8 items |
| Enter, Tab | Accept highlighted suggestion (replaces full word as one undo step) |
| Escape | Close popup |
| Left, Right, Home, End | Close popup and move cursor |
