title: Completion
description: A list of completions at the caret of a text field, such as table and column names in a query.
---

`Completion.complete` gives a text field, usually a [CodeEditor](/docs/components/code-editor), a list of completions below its caret. The app's function gets the part of the word before the caret and returns the entries; the list opens as the user types, and Enter or Tab puts the chosen entry in place. For choosing among fixed values in a form, use a [ComboBox](/docs/components/combo-box).

## When it opens and closes

A single letter, digit or `_` typed opens the list once the word has two characters and the caret stands right after it; Control+Space opens it with an empty word. A deletion keeps it open while the word is not empty; any other edit closes it. A press elsewhere and the wheel dismiss it.

## Keyboard

| Keys | Action |
| --- | --- |
| Up, Down | Move the highlight, around the ends |
| Page Up, Page Down | By eight |
| Enter, Tab | Put the highlighted entry in place, as one step of the undo history |
| Escape | Close |
| Left, Right, Home, End | Close and move the caret |

Keys it does not take reach the field's own handler, Control+Enter among them.
