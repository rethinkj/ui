`Group.group` renders an outlined card of settings rows separated by thin dividers. Each row has a title, optional icon and description, and a right-aligned control (such as a switch, link, expander, or dropdown).

Use `Group` for settings pages. For labeled data-entry forms, use [Form](/docs/components/form).

Javadoc: [`Group`](/api/com/rethinkj/ui/kit/Group.html).

| Row helper | Description |
| --- | --- |
| `row([icon,] title, description, control)` | Places any control on the right (labels unlabeled controls and displays control errors in place of the description) |
| `switchRow([icon,] title, description, on, onToggle)` | Full-row clickable toggle switch |
| `linkRow([icon,] title, description, value, onPress)` | Full-row clickable button with muted value and chevron |
| `expander([icon,] title, description, open, onToggle, content...)` | Collapsible row revealing indented child rows below |
| `box(content...)` | Custom content with standard row padding |

## In a tree dump

Switch rows are `role=switch` (`checked`), link rows are `role=button` (`value`), and expanders are `role=button` (`expanded` / `expanded=false`). Any row with a `null` handler is `disabled`:
