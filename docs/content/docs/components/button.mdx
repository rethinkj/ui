title: Button

`Button.button` is a button with text and an optional icon, in three variants: `PRIMARY` for the main action of a view, `SECONDARY` for the others, `GHOST` for quiet actions in toolbars. `Button.icon` is a square button with an icon alone, `Button.toggle` a button that stays on, and `Button.split` a main action with a menu of related ones. What a button is beyond its variant, text and handler goes into `Button.options()`: an icon, whether it is busy or off, and its tone, `DANGER` for an action that destroys something. A null handler, or `enabled(false)`, turns any of them off; a split button with a null handler is off in its main half only, and its chevron still opens the menu, while `enabled(false)` turns off both. For an on/off setting, use a [Toggle](/docs/components/toggle); for several actions in a row, a [Toolbar](/docs/components/toolbar).

## Options

```java snippet="button-options"
```

| Option | |
| --- | --- |
| `icon(symbol)` | An icon before the text, in the text's colour. Not for `Button.icon`, whose symbol is a parameter |
| `busy(boolean)` | While its action runs: a spinner in place of the icon, or over the text where there is none, so that the button keeps its width. It takes no press, and Enter and Space on it do nothing and go no further, but it keeps its colours, its place for Tab and the focus. A split button is busy in its main half; its chevron still opens the menu, whose items the app enables as it sees fit |
| `enabled(boolean)` | `false` turns the button off while the view keeps its handler, exactly as a null handler does: no focus, no pointer cursor, the disabled colours, presses go to its ancestors, `disabled` in the tree. `El.disabled(true)` on the returned element changes only the tree, not what the button does |
| `tone(Tone.DANGER)` | For an action that destroys something, in the colours of `Theme.Danger`: `PRIMARY` filled red with white text, for the confirmation in a dialog; `SECONDARY` red text and a red edge on the raised surface; `GHOST` red text alone, for a toolbar or a row. Its focus ring is red too. Off, it looks as any button that is off |

The options go to `button(t, variant, text, onPress, options)`, `icon(t, variant, symbol, label, onPress, options)` and `split(t, variant, text, onPress, menuState, items, options)`; the forms below are these with plain options.

## Variants and forms

| Call | |
| --- | --- |
| `button(t, variant, text, onPress)` | Text alone |
| `button(t, variant, icon, text, onPress)` | An icon before the text |
| `button(t, variant, icon, text, busy, onPress)` | While `busy`, a spinner in place of the icon, or over the text where there is no icon, so that the button keeps its width; it takes no press but keeps its place for Tab and the focus |
| `icon(t, variant, symbol, label, onPress)` | The icon alone; the label shows in a tooltip and the tree |
| `toggle(t, icon, text, on, onToggle)`, `toggleIcon(t, icon, label, on, onToggle)` | A button that stays on: the selection's tint and the icon in the accent while on |
| `split(t, variant, icon, text, onPress, menuState, items)` | A main action and a chevron that opens a [Menu](/docs/components/menu) |

| Variant | |
| --- | --- |
| `PRIMARY` | The accent fill; one per view |
| `SECONDARY` | The raised surface with an edge |
| `GHOST` | Shows its surface only under the pointer |

The result is an `El`: chain `.key("save")` or a width onto it.

## Focus and keyboard

A press leaves the keyboard focus where it was, in the editor or grid the button acts on; Tab reaches the button, and Enter and Space press it. The primary button draws its focus ring with a gap, so that the surface shows between fill and ring.

Enter and Space show the button pressed, as the pointer does: while the key is held, and at least `App.KEY_PRESS` (0.1 seconds) after it went down when it comes up sooner, so that a short tap shows too. This holds for every element with a press handler, not only buttons. A key that goes down and up in one frame, as a script's `key Enter`, shows nothing; `key Space down` and `key Space up` hold it between frames. On a split button's chevron, Arrow Down and Arrow Up open the menu with the first or the last enabled item highlighted.
