`Button` provides clickable actions in three visual styles:
- `PRIMARY` — Main action of a view (filled with accent color; use at most one per view).
- `SECONDARY` — Standard action (raised surface with border).
- `GHOST` — Subtle action for toolbars (shows background only on hover).

Additional forms include `Button.icon` (square icon-only button), `Button.toggle` (stays pressed/on), `Button.split` (main action plus dropdown menu), and `Button.menu` (opens a menu). Pass `Button.options()` to configure icons, busy/disabled states, danger tone, sizes, and shortcut tooltips. Passing a `null` handler disables the button (unless it is `BUSY`).

For an on/off setting, use [Toggle](/docs/components/toggle). For a row of actions with overflow handling, use [Toolbar](/docs/components/toolbar).

Javadoc: [`Button`](/api/com/rethinkj/ui/kit/Button.html), [`Button.Options`](/api/com/rethinkj/ui/kit/Button.Options.html).


| Option | Description |
| --- | --- |
| `icon(symbol)` | Shows an icon before the text (not used with `Button.icon`, which takes the symbol directly) |
| `state(READY)` | Normal clickable state (default) |
| `state(BUSY)` | Shows a spinner while an action runs. Ignores clicks, Enter, and Space, keeps its width and focus, and works even with a `null` handler |
| `state(DISABLED)` | Disables the button while keeping the handler in your view code (same behavior as a `null` handler) |
| `progress(fraction)` | While `BUSY`, shows a ring that fills from `0.0` to `1.0` instead of the spinner (for example, during a download) |
| `busyText(text)` | Text shown beside the spinner while `BUSY` (e.g., `"Saving…"`). Keeps the button width stable across ready/busy states |
| `tone(Tone.DANGER)` | Red styling for destructive actions (`PRIMARY` filled red, `SECONDARY` red text/border, `GHOST` red text) |
| `size(Size.SMALL)`, `size(Size.LARGE)` | Height `20` or `32` instead of default `24` (`SMALL` for compact rows, `LARGE` for empty-state calls to action) |
| `shortcut(modifiers, key)` | Displays keyboard shortcut keycaps in the tooltip (e.g., `shortcut(Key.CONTROL \| Key.SHIFT, "C")`). Display-only — bind the actual shortcut in your `onKey` handler |

Pass `options` to `button(...)`, `icon(...)`, `split(...)`, or `menu(...)`.

On a split button, a `null` handler or `BUSY` only affects the main button — the chevron still opens the menu. `DISABLED` disables both halves. A menu button disables itself if it has no enabled items.

## Variants and forms

| Method | Description |
| --- | --- |
| `button(variant, text, onPress)` | Text button |
| `button(variant, icon, text, onPress)` | Button with icon and text |
| `icon(variant, symbol, label, onPress)` | Square icon-only button (`label` appears in tooltip and tree) |
| `toggle(icon, text, on, onToggle)`, `toggleIcon(icon, label, on, onToggle)` | Toggle button with active tint when `on` is `true` |
| `split(variant, icon, text, onPress, menuState, items)` | Main action plus chevron opening a [Menu](/docs/components/menu) |
| `menu(variant, text, menuState, items)` | Button that opens a [Menu](/docs/components/menu) |

The returned value is an `El`, so you can chain `.key("save")`, `.w(...)`, or other layout methods.

## Copy buttons

`Button.copy(clipboard, text, label, copied)` creates a compact copy-to-clipboard icon button. Pass a shared `Button.Copied` instance from your state (or `null` to skip confirmation) to show a temporary checkmark and `"Copied"` tooltip after copying.

## Keyboard

**Tab** focuses the button; **Enter** and **Space** activate it. Mouse clicks keep keyboard focus where it was (useful for toolbar buttons acting on an editor or grid). On menu buttons and split-button chevrons, **ArrowDown** and **ArrowUp** open the menu.
