`Button.button` is a button with text and an optional icon, in three variants: `PRIMARY` for the main action of a view, `SECONDARY` for the others, `GHOST` for quiet actions in toolbars. `Button.icon` is a square button with an icon alone, `Button.toggle` a button that stays on, and `Button.split` a main action with a menu of related ones. `Button.options()` holds the rest: an icon, whether it is busy or disabled, and its tone, `DANGER` for an action that destroys something. A null handler disables any of them. For an on/off setting, use a [Toggle](/docs/components/toggle); for several actions in a row, a [Toolbar](/docs/components/toolbar).

Javadoc: [`Button`](/api/com/rethinkj/ui/kit/Button.html), [`Button.Options`](/api/com/rethinkj/ui/kit/Button.Options.html).

## Options

```java snippet="button-options"
```

| Option | |
| --- | --- |
| `icon(symbol)` | An icon before the text, in the text's color. Not for `Button.icon`, whose symbol is a parameter |
| `busy(boolean)` | While its action runs. A spinner replaces the icon, or covers the text where there is no icon, so the button keeps its width. It ignores presses, Enter and Space, but keeps its colors, its Tab stop and the focus |
| `enabled(boolean)` | `false` disables the button and keeps its handler, exactly as a null handler does: no focus, the disabled colors, `disabled` in the tree. `El.disabled(true)` on the result changes only the tree, not the button |
| `tone(Tone.DANGER)` | For an action that destroys something. `PRIMARY` is filled red, for the confirmation in a dialog; `SECONDARY` has red text and a red edge; `GHOST` red text alone, for a toolbar or a row |

The options go to `button(variant, text, onPress, options)`, `icon(variant, symbol, label, onPress, options)` and `split(variant, text, onPress, menuState, items, options)`. The forms below are these with plain options.

On a split button, a null handler or `busy` affects the main half only: its chevron still opens the menu. `enabled(false)` disables both halves.

## Variants and forms

| Call | |
| --- | --- |
| `button(variant, text, onPress)` | Text alone |
| `button(variant, icon, text, onPress)` | An icon before the text |
| `icon(variant, symbol, label, onPress)` | The icon alone; the label shows in a tooltip and the tree |
| `toggle(icon, text, on, onToggle)`, `toggleIcon(icon, label, on, onToggle)` | A button that stays on: the selection's tint and the icon in the accent while on |
| `split(variant, icon, text, onPress, menuState, items)` | A main action and a chevron that opens a [Menu](/docs/components/menu) |

| Variant | |
| --- | --- |
| `PRIMARY` | The accent fill; one per view |
| `SECONDARY` | The raised surface with an edge |
| `GHOST` | Shows its surface only under the pointer |

The result is an `El`: chain `.key("save")` or a width onto it.

## Copy buttons

`Button.copy(clipboard, text, label, copied)` is a quiet square button with the copy icon. It writes `text` to the clipboard and shows the label in the tree and in a tooltip: `label="Copy host"` beside a value, say. `copied` is a `Button.Copied` in the app's state, one for all its copy buttons. After a copy, the button shows a check mark and the tooltip Copied for `motion().confirm()` seconds, then goes back by itself. Pass null to show no confirmation. Two buttons with the same label and text confirm together. [Properties](/docs/components/properties) and the code blocks of [Markdown](/docs/components/markdown) use it.

## Keyboard

Tab reaches the button; Enter and Space press it and show it pressed while the key is held. A press with the pointer leaves the keyboard focus where it was, such as in the editor or grid the button acts on. On a split button's chevron, Down and Up open the menu with the first or the last enabled item highlighted.
