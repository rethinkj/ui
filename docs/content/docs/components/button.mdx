title: Button
description: Primary, secondary and ghost buttons, icon buttons, busy buttons, buttons that destroy, toggle buttons, split buttons and menu buttons, in three sizes.
---

`Button.button` is a button with text and an optional icon, in three variants: `PRIMARY` for the main action of a view, `SECONDARY` for the others, `GHOST` for quiet actions in toolbars. `Button.icon` is a square button with an icon alone, `Button.toggle` a button that stays on, `Button.split` a main action with a menu of related ones, and `Button.menu` a button that only opens a menu. `Button.options()` holds the rest: an icon, its state (ready, busy or off), the text it shows while busy, its tone, `DANGER` for an action that destroys something, its size and its shortcut. A null handler disables any of them unless it is busy; on a split button it disables only the main half. For an on/off setting, use a [Toggle](/docs/components/toggle); for several actions in a row, a [Toolbar](/docs/components/toolbar).

Primary and secondary buttons lie a hair above their surface and a little higher under the pointer. Pressed, a button loses its shadow, its corners tighten and its content moves down a pixel, so that a press shows in its shape and not in its color alone. The focus ring lies a gap apart from every button.

Javadoc: [`Button`](/api/com/rethinkj/ui/kit/Button.html), [`Button.Options`](/api/com/rethinkj/ui/kit/Button.Options.html).

## Options

```java snippet="button-options"
```

| Option | |
| --- | --- |
| `icon(symbol)` | An icon before the text, muted beside the text of a secondary or ghost button. Not for `Button.icon`, whose symbol is a parameter |
| `state(READY)` | Takes a press, if it has a handler: the default |
| `state(BUSY)` | While its action runs. A spinner replaces the icon, or covers the text where there is no icon, so the button keeps its width. It ignores presses, Enter and Space, but keeps its colors, its Tab stop and the focus. A button is busy also without a handler |
| `state(DISABLED)` | Off while the view keeps its handler, exactly as a null handler: no focus, the disabled colors, `disabled` in the tree. A press on it still leaves the focus where it was. `El.disabled(true)` on the result changes only the tree, not the button |
| `busyText(text)` | The text a busy button shows after its spinner, such as `Saving…`; the tree keeps the button's own text as its label. The button is as wide as the wider of both texts, busy or not |
| `tone(Tone.DANGER)` | For an action that destroys something. `PRIMARY` is filled red, for the confirmation in a dialog; `SECONDARY` has red text and a red edge; `GHOST` red text alone, for a toolbar or a row |
| `size(Size.SMALL)`, `size(Size.LARGE)` | 20 or 32 high instead of 24, with narrower or wider padding: small for a dense row, large for the one action of an empty view |
| `shortcut(modifiers, key)` | The keys that run the action elsewhere, shown after the label in the tooltip as a menu writes them: `shortcut(Key.CONTROL \| Key.SHIFT, "C")` shows `Ctrl+Shift+C`. It only shows: the app binds the keys where it binds its others |

The options go to `button(variant, text, onPress, options)`, `icon(variant, symbol, label, onPress, options)`, `split(variant, text, onPress, menuState, items, options)` and `menu(variant, text, menuState, items, options)`. The forms below are these with plain options.

On a split button, a null handler or `BUSY` affects the main half only: its chevron still opens the menu. `DISABLED` disables both halves. A menu button is off without an enabled item, and opens nothing while busy or off.

## Variants and forms

| Call | |
| --- | --- |
| `button(variant, text, onPress)` | Text alone |
| `button(variant, icon, text, onPress)` | An icon before the text |
| `icon(variant, symbol, label, onPress)` | The icon alone; the label shows in a tooltip and the tree |
| `toggle(icon, text, on, onToggle)`, `toggleIcon(icon, label, on, onToggle)` | A button that stays on: the selection's tint and the icon in the accent while on |
| `split(variant, icon, text, onPress, menuState, items)` | A main action and a chevron that opens a [Menu](/docs/components/menu) |
| `menu(variant, text, menuState, items)` | A button with a chevron that opens a [Menu](/docs/components/menu), and no action of its own |

| Variant | |
| --- | --- |
| `PRIMARY` | The accent fill; one per view |
| `SECONDARY` | The raised surface with an edge |
| `GHOST` | Shows its surface only under the pointer |

The result is an `El`: chain `.key("save")` or a width onto it.

## Copy buttons

`Button.copy(clipboard, text, label, copied)` is a quiet square button with the copy icon. It writes `text` to the clipboard and shows the label in the tree and in a tooltip: `label="Copy host"` beside a value, say. `copied` is a `Button.Copied` in the app's state, one for all its copy buttons. After a copy, the button shows a check mark and the tooltip Copied for `motion().confirm()` seconds, then goes back by itself. Pass null to show no confirmation. Two buttons with the same label and text confirm together. [Properties](/docs/components/properties) and the code blocks of [Markdown](/docs/components/markdown) use it.

## Keyboard

Tab reaches the button; Enter and Space press it and show it pressed while the key is held. A press with the pointer leaves the keyboard focus where it was, such as in the editor or grid the button acts on, also on a button that is off. On a split button's chevron and on a menu button, Down and Up open the menu with the first or the last enabled item highlighted.
