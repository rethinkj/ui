title: HuePicker
description: Color swatch selector for the theme's ten accent hues, with an optional "no color" choice.
---

`HuePicker.huePicker` displays a row of circular swatches for the theme's ten hues (plus an optional "none" choice). Use it whenever users pick a color tag, such as marking a production connection or a colored tab (`Tab.hue`). For custom non-color swatches, see [Radio.swatches](/docs/components/radio#swatches).

Javadoc: [`HuePicker`](/api/com/rethinkj/ui/kit/HuePicker.html).

## Example

```java snippet="hue-picker"
```

| Method | Description |
| --- | --- |
| `huePicker(selected, onSelect)` | The 10 theme hues (`selected` may be `null`) |
| `huePicker(selected, none, onSelect)` | Adds a leading "no color" option labeled `none` (selects `null`) |
| `huePicker(prop, none)` | Binds to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) (`none` may be `null` to omit) |
| `HuePicker.swatch(hue)` | Renders a single swatch dot (for menu items or lists) |
| `HuePicker.name(hue)` | Human-readable hue name (`"Red"`, `"Violet"`, …) |

Passing a `null` handler disables the picker. Each swatch shows its name in a tooltip on hover.

## Keyboard

One Tab stop. **Arrow keys** move between hues (wrapping around), **Home/End** jump to first/last, and **Space** selects the first option when none is selected.
