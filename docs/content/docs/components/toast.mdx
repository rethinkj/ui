title: Toast

`Toast.toast` displays a single neutral notification banner at the bottom center of the window that dismisses itself automatically without stealing keyboard focus. For apps that report several events or background work at once, `Toasts` manages a stack of notifications with `Callout.Kind` icons and colors, a close button, pause on hover, a queue, and progress toasts. For messages requiring a decision, use [Dialog](/docs/components/dialog).

Javadoc: [`Toast`](/api/com/rethinkj/ui/kit/Toast.html), [`Toasts`](/api/com/rethinkj/ui/kit/Toasts.html).

## Single toast

```java snippet="toast"
```

Attach the toast as an overlay on your root element while your state holds a message, and clear it in `onClose`.

| Parameter | Description |
| --- | --- |
| `message` | Notification text and accessibility label |
| `action`, `onAction` | Optional action button text and handler (`null` for none) |
| `onClose` | Called when the toast auto-dismisses (default 5 seconds), after its action runs, or on Escape while focused |
| `above` | Optional bottom offset (for example, `StatusBar.height()` or `Card.footerHeight()`) |

## Toast stack

Keep a `Toasts` instance in your app state, add notifications from any handler on the app's thread (including `App.background` callbacks), and attach `toasts.view()` (or `toasts.view(above)`) as an overlay on the root element. Up to three toasts show at once with the newest nearest the bottom edge; additional toasts wait in a queue and appear as visible ones close.

| Method | Description |
| --- | --- |
| `show(message)` | Shows a neutral toast without an icon |
| `show(kind, message)` | Shows a toast styled with `Callout.Kind` (`INFO`, `WARNING`, `DANGER`, `SUCCESS`, or `null` for neutral) |
| `show(kind, message, action, onAction)` | Adds a ghost action button before the close button |
| `progress(message)` / `progress(message, fraction)` | Shows a toast with a `Progress` bar that stays until finished or closed, returning a `Toasts.Handle` |
| `Handle.progress(fraction)` / `Handle.message(text)` | Updates the fraction (`0..1`, or `Double.NaN` for indeterminate) and message while running |
| `Handle.finish(kind, message)` | Turns a running progress toast into a result toast that then auto-dismisses normally |
| `Handle.close()` | Removes the toast immediately, whether visible or queued |
| `view()` / `view(above)` | Returns the bottom-center overlay, or `null` when nothing is visible |

Each toast in the stack has a close button, closes on **Escape** while focused inside it, keeps keyboard focus where it was, and pauses its auto-dismiss timer while the pointer hovers over it.
