---
title: Toast
description: Temporary bottom-edge notification banner with an optional action button like Undo.
---

`Toast.toast` displays a brief notification banner at the bottom center of the window that dismisses itself automatically without stealing keyboard focus. Ideal for confirmations with an optional **Undo** button. For messages requiring a decision, use [Dialog](/docs/components/dialog).

Javadoc: [`Toast`](/api/com/rethinkj/ui/kit/Toast.html).

<Shot src="kit/toast-{theme}-2x-shown" alt="A toast saying a table was dropped, with an Undo button" />

## Example

```java snippet="toast"
```

Attach the toast as an overlay on your root element while your state holds a message, and clear it in `onClose`.

| Parameter | Description |
| --- | --- |
| `message` | Notification text and accessibility label |
| `action`, `onAction` | Optional action button text and handler (`null` for none) |
| `onClose` | Called when the toast auto-dismisses (default 5 seconds), after its action runs, or on Escape while focused |
| `above` | Optional bottom offset (for example, `StatusBar.height()` or `Card.footerHeight()`) |
