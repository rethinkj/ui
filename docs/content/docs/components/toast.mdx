---
title: Toast
description: A short message at the bottom of the window that goes by itself, with an optional action such as Undo.
---

`Toast.toast` shows a message at the bottom of the window, in the middle, with an optional action button. It closes itself after a few seconds of the app's clock. Use it to confirm what just happened and to offer Undo. It leaves the keyboard focus where it is, so typing goes on. For something the user must answer, use a [Dialog](/docs/components/dialog).


`s.dropped` is the name of the dropped table in the app's state, null while there is no toast. The root attaches the toast while there is one, and `onClose` clears it.

| Parameter | |
| --- | --- |
| `message` | The text, and the toast's label |
| `action`, `onAction` | The button's text and handler, or null for none |
| `onClose` | Called when the toast closes: after `motion().toast()` seconds (5), after its action, or on Escape while the focus is in the toast |
| `above` | In the form with this parameter, the toast lies that much higher, clear of a status bar (`StatusBar.height(t)`) or a card's footer (`Card.footerHeight(t)`) |

## Keyboard

A press elsewhere leaves the toast. Tab reaches its action last; when the toast closes from there, the focus goes back to where it was.
