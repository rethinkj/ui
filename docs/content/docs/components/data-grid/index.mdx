title: DataGrid
description: High-performance data table for ten rows or a million, with selection, sorting, filtering, and inline editing.
---

`DataGrid.dataGrid` displays rows and columns in a compact desktop table. It builds only the visible rows and columns, so a million rows render just as fast as ten. Your app owns all data and state; the grid renders them and reports user actions back to your handlers.

For a short list of choices, use [NavList](/docs/components/nav-list) or [Select](/docs/components/select). For hierarchical data, use [Tree](/docs/components/tree). See the [DataBrowser](/docs/examples/data-browser) example for a complete million-row demo.

Javadoc: [`DataGrid`](/api/com/rethinkj/ui/kit/DataGrid.html), [`DataGrid.Column`](/api/com/rethinkj/ui/kit/DataGrid.Column.html), [`DataGrid.Options`](/api/com/rethinkj/ui/kit/DataGrid.Options.html).

- Store `DataGrid.Selection` and `DataGrid.Commands` in your app state.
- Each `Column` takes a title, width, `DataType`, and cell text function (`null` renders as muted `NULL`).
- `DataType` sets default alignment, font, and header icon (`INTEGER`, `DECIMAL`, `TEXT`, `BOOLEAN`, `DATE`, `TIME`, `DATE_TIME`, `INTERVAL`, `UUID`, `JSON`, `BINARY`, `ARRAY`, `ENUM`, `GEOMETRY`, `OTHER`).
- Cell functions run on every frame for visible cells only — keep them fast (e.g., list/array lookup, never a database call).
- Give the grid a fixed height or `grow(1)`. `DataGrid` has no outer border, so wrap it in `Card.flush(grid)`.

## Columns

| Feature | Method |
| --- | --- |
| Basic column | `new Column(title, width, DataType, cell)` or `new Column(title, width, Align, mono, cell)` |
| Type subtitle in header | `.typeName("bigint")` |
| Custom header icon | `.icon(Symbol)` or `.icon(Symbol, Icon.Variant)` |
| Cell icons | `.cellIcon(row -> CellIcon)` using `CellIcon.before(...)` or `CellIcon.instead(...)` with optional `.tooltip(...)` |
| Secondary text in cell | `.detail(row -> text)` (see [Details](#details)) |
| Tooltip of a cell | `.cellTooltip(row -> text)` (see [Tooltips](#tooltips)) |
| Sorting | `.sortable(boolean)` |
| Inline editing | `.editable()`, `.editable(rows)`, `.nullable()`, `.choices(list)`, `.editor(...)` (see [Editing](/docs/components/data-grid/editing)) |

For rows stored as Java records or POJOs, use `DataGrid.table(rows)` (see [Rows of records](/docs/components/data-grid/typed)).

Line breaks and tabs inside cells display as `⏎` and `⇥`. Overflowing text truncates with `…` and shows the full value in a tooltip on hover.

## Details

`column.detail(row -> text)` adds short muted metadata beside a cell's value (such as units, counts, or byte sizes). Left-aligned columns show the detail after the value; right-aligned columns show it before the value so numbers stay aligned. Copying and editing use only the main value.

## Tooltips

`column.cellTooltip(row -> text)` shows a tooltip when you hover over a cell. For example, a cell can display local time while the tooltip shows the timestamp returned by the database. Copying and editing still use the cell's text.

```java snippet="grid-tooltip"
```

A cell combines all applicable parts into one tooltip, one line each, in this order: a failed cell's error, the icon's tooltip, the column's tooltip, and the full text when the cell is truncated.

## Options

Enable features with `DataGrid.options()` (all features are off by default):

| Option | Description |
| --- | --- |
| `select(Selection)` | Enables cursor and selection (required by most other features). See [Selection](/docs/components/data-grid/selection) |
| `onSelect(Runnable)` | Called whenever the selection changes |
| `onActivate(row -> …)` | Opens a row on Enter or double-click. See [Opening a row](#opening-a-row) |
| `rowKey(row -> …)` | Gives each row a stable `long` key so the selection follows moved rows without scrolling back and the viewport stays anchored. See [Selection](/docs/components/data-grid/selection#selection-api) |
| `rowNumbers()` | Adds a row-number gutter column that selects whole rows |
| `frozen(int columns)` | Keeps the first `N` columns fixed while scrolling horizontally |
| `copy(Clipboard)`, `nullText(String)`, `copyLimit(cells)`, `onLargeCopy(handler)` | Enables Ctrl+C tab-separated copy. See [Copying](/docs/components/data-grid/selection#copying) |
| `commands(Commands)` | Lets external menus trigger Copy, Paste, and Select All. See [Commands](/docs/components/data-grid/selection#commands-from-an-external-menu) |
| `contextMenu(Menu.State, items)` | Right-click menu with built-in Copy, Paste, Set NULL, Insert/Delete row, column actions, plus your custom items |
| `sort(keys, onSort)` | Header sorting indicators and click handling. See [Sorting and columns](/docs/components/data-grid/sorting-and-columns) |
| `onResize((column, width) -> …)` | Drag column edges to resize; double-click to auto-fit |
| `fitColumns(Fit)` | Auto-fits all column widths once per result. See [Fitting columns](/docs/components/data-grid/sorting-and-columns#fitting-columns) |
| `columns(Layout)`, `onFreeze(count -> …)` | Reorder, hide, show, and freeze columns |
| `loading(loaded, onRows)` | Shows `…` for unloaded rows and notifies you when visible rows need loading |
| `onRowsInView((first, last) -> …)` | Notifies you when the first or last row fully in view changes. See [Selection API](/docs/components/data-grid/selection#selection-api) |
| `filters(filters, onFilter)`, `filterable(columns)` | Per-column filter popovers. See [Filters](/docs/components/data-grid/filters) |
| `footer(totals)` | Pinned bottom row for app-supplied column totals. See [Totals and summary](/docs/components/data-grid/totals) |
| `empty(El view)` | View centered under the header when no rows are shown. See [Empty state](#empty-state) |
| `changes(GridChanges)` | Full inline editing with pending changes and undo/redo. See [Editing](/docs/components/data-grid/editing) |
| `onEdit`, `onCommit`, `onPaste`, `onInsertRow`, `onDeleteRows`, `status`, `errors`, `history`, `appendRow()` | Lower-level editing hooks |

## Opening a row

`onActivate(row -> …)` runs when the user presses **Enter** on a row or double-clicks a cell or row number. Use it, for example, to show a row in full or choose an entry in a picker dialog.

It requires `select(...)`. If **Enter** or a double-click edits the cell (`onCommit`, `onEdit`), the grid edits the cell instead. Unloaded rows do not trigger `onActivate`.

## Empty state

`options().empty(view)` displays `view` centered in the visible area under the header whenever the grid shows no rows at all — typically an [EmptyState](/docs/components/empty-state) with an action such as **Clear filters**. The header, column menu, sorting, and filter popovers remain usable, and any button in the empty view is reachable by pointer and **Tab**.

With `appendRow()`, the grid still shows its append row when `rowCount` is `0` rather than the empty view.

## Lazy-loaded rows

For paginated or remote datasets, pass `loading(loaded, onRows)`. Unloaded rows display `…` without calling cell functions, and `onRows` reports the currently visible row range so you can fetch them in the background ([Work off the app's thread](/docs/concepts/background-work)).

## Keyboard

The grid is a single Tab stop:

| Key | Action |
| --- | --- |
| Arrow keys | Move cursor |
| Page Up, Page Down | Jump by the number of rows that fit above the horizontal scrollbar |
| Home, End (with Ctrl) | First/last cell in row (or in entire grid with Ctrl) |
| Shift + navigation | Extend selection |
| Ctrl+A | Select all |
| Ctrl+C, Ctrl+Insert | Copy selection |
| Enter, F2, typing | Start editing active cell |
| Enter | Open the cursor's row when Enter does not edit the cell (`onActivate`) |
| Menu key, Shift+F10 | Open context menu at cursor |

## In a tree dump

`role=grid`. Headers are `role=columnheader` (`#column-<index>`, `pos`, `sort=`), resize handles are `role=separator` (`#resize-<index>`), rows are `role=row` (`#row-<index>`), cells are `role=gridcell` (`#cell-<row>-<column>`), and row numbers are `role=rowheader` (`#number-<row>`). Keys are 0-based; `pos` is 1-based.
