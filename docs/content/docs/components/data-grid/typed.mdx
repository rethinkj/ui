Use `DataGrid.table(rows)` to build a `GridTable<T>` directly over Java records or POJOs instead of raw strings. Each column uses a getter, a [Format](/docs/components/format), and an optional wither/setter (or [`Part`](/docs/concepts/editing#declare-the-fields)) to format, validate, sort, filter, and write back typed values automatically.

Javadoc: [`GridTable`](/api/com/rethinkj/ui/kit/GridTable.html), [`GridTable.Cells`](/api/com/rethinkj/ui/kit/GridTable.Cells.html).

- `DataGrid.table(rows)` accepts an `IntFunction<T>` (such as `state.orders::get`). Return `null` for unloaded rows and pair with `.loading(table::loaded, onRows)`.
- `table.column(title, width, format, getter)` creates a read-only column. Add a wither (`Order::withAmount`), setter (`Account::setBalance`), or pass a [`Part`](/docs/concepts/editing#declare-the-fields) (`Order.AMOUNT`) to make it editable.
- Alignment, monospace font, header icon, editor type, and nullability (`optional()`) are configured automatically from `Format`.
- Returns a standard `Column`, so `.typeName`, `.icon`, `.detail`, and `.sortable` chain normally.

## Inline editing

Pass `options().onCommit(table, (row, value) -> error)` to enable typed editing, pasting, and clearing:
- Input is validated by `Format` first (including `.where(...)` constraints).
- **Records:** The wither creates a new record passed to your handler (typically `rows.set(row, value)`).
- **POJOs:** The setter mutates the object; if your handler returns an error message, the grid automatically reverts the previous value.
- Return `null` to accept, or an error string to reject and display below the editor.

## Typed sorting and filtering

| Helper | Description |
| --- | --- |
| `table.comparator(columns, keys)` | Builds a typed `Comparator<T>` (numbers numerically, dates chronologically, enums by order; `null` first ascending, last descending) |
| `table.filter(columns, filters)` | Builds a typed `Predicate<T>` matching header filters |
| `filter.matches(value, format)` | Tests a single typed value against one filter |

## Accessing typed values from custom commands

For columns created by `table.column(...)`, `column.cells()` returns a `GridTable.Cells<T, V>` (cast to your row/value types) with `value(row)` and `write(row, value)` for custom commands like "Set selected cells to 0". See [`GridTable.Cells` Javadoc](/api/com/rethinkj/ui/kit/GridTable.Cells.html).
