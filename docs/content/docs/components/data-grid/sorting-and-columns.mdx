`DataGrid` provides UI controls for sorting, resizing, auto-fitting, reordering, hiding, and freezing columns. Your app owns the sort order, widths, and layout so sorting can run either in memory or in SQL (`ORDER BY`).

Javadoc: [`DataGrid.SortKey`](/api/com/rethinkj/ui/kit/DataGrid.SortKey.html), [`DataGrid.Layout`](/api/com/rethinkj/ui/kit/DataGrid.Layout.html), [`DataGrid.Fit`](/api/com/rethinkj/ui/kit/DataGrid.Fit.html).

## Sorting

Pass `options().sort(keys, onSort)` with a list of `SortKey(column, descending)`. Clicking a sortable header cycles ascending → descending → unsorted; **Shift+click** adds a secondary sort column. Sort arrows require `rethinkj-ui-icons`.

## Resizing columns

Pass `options().onResize((column, width) -> …)` to let users drag column header edges to resize, or double-click an edge to fit the column to its content. Widths clamp to `theme.grid().minColumn()` and `maxColumn()`.

## Fitting columns

Pass `options().fitColumns(fit)` (storing a `DataGrid.Fit` in your state alongside `onResize`) to auto-size all columns to fit their headers and loaded values once per dataset. Call `fit.reset()` when loading new results.


- Auto-fitting runs on the first frame with loaded rows and updates widths on the next frame (so headless scripts need one extra `frame` before `snap`).
- Columns the user manually resized are left untouched; hidden columns auto-fit when first shown.

## Reordering, hiding, and choosing columns

Store a `DataGrid.Layout` (initialized with all column titles) in your state and pass `options().columns(layout)` to enable:
- Drag-and-drop column reordering
- Header context menu (Sort, Filter, Hide, Freeze up to here, Fit width, Columns…)
- `DataGrid.columnsButton(layout)` — a toolbar button opening a searchable column chooser popover (Alt+Up/Down reorders columns)

## Freezing columns

Pass `options().frozen(count)` to pin the first `count` columns (plus row numbers) to the left edge while scrolling horizontally. Add `onFreeze(count -> …)` to let users change frozen columns from the header menu.

## Column index mapping

When using `DataGrid.Layout`, keep the two index spaces in mind:
- **All-column indexes:** Used by `sort`, `filters`, `onResize`, `onFreeze`, and `GridChanges`.
- **Visible-column indexes:** Used by `Selection` (`column()`, `ranges()`) and tree dump keys (`#column-<i>`, `#cell-<row>-<i>`).

Convert from visible index to all-column index with `layout.shownColumns()[selection.column()]`. Call `layout.toggleChooser()` to open/close the column chooser programmatically.
