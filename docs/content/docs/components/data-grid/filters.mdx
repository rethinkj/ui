title: Filters
description: Per-column filter popovers and a removable filter badge bar for DataGrid.

`options().filters(filters, onFilter)` adds a filter icon to each column header that opens a popover matched to the column type (text contains/starts with/equals/regex, numeric/date ranges, boolean/choice checkboxes, and `IS NULL` / `NOT NULL`).

`DataGrid` does not filter data itself: it passes updated `DataGrid.Filter` records to `onFilter` so your app can filter in SQL or in memory with `filter.matches(...)`.

Javadoc: [`DataGrid.Filter`](/api/com/rethinkj/ui/kit/DataGrid.Filter.html).

Store `List<DataGrid.Filter>` in your app state.

Call `DataGrid.filterBar(columns, filters, onFilter)` to render a row of removable filter badges with a **Clear all** button above the grid (returns `null` when no filters are active).

## `Filter` API

| Method | Description |
| --- | --- |
| `Filter.of(column, Kind, value)` | `CONTAINS`, `STARTS_WITH`, `EQUALS`, `MATCHES` (case-insensitive regex), `IS_NULL`, `NOT_NULL` |
| `Filter.between(column, from, to)` | Range filter (leave either end empty for open-ended bounds) |
| `Filter.oneOf(column, values)` | Keep rows matching any listed value |
| `filter.matches(cell)` | Returns `true` if a cell's text matches (for in-memory filtering) |
| `filter.describe(title)` | Human-readable summary used on filter badges |

Use `options().filterable(column -> …)` to enable filters only on specific columns. Press **Alt+ArrowDown** to open the filter popover for the active column.
