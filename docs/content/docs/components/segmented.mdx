title: Segmented
description: Pill-shaped track for choosing one of two to five views or modes.
---

`Segmented.segmented` displays two to five options in a rounded track; the selected one sits on a raised pill that slides to the next selection. Use it to switch between 2–5 modes (such as Dark / Light / System, or Rows / Cells). For longer option text, use [Radio](/docs/components/radio).

Javadoc: [`Segmented`](/api/com/rethinkj/ui/kit/Segmented.html).

Call `Segmented.segmented(choices, selected, onSelect)`. Passing a `null` handler disables it.

## Sizes

By default it is as high as a button or a text field, so it fits a toolbar or a form row. Pass `Segmented.Size.LARGE` as the last argument for a control that stands on its own, such as on a settings page: it is as high as a large button, with more room around the pill.

## Keyboard

One Tab stop. **Arrow keys** move selection (wrapping around), **Home/End** jump to first/last, and **Space** selects the first option when none is selected.

## With a Prop

`segmented(values, prop, text)` binds directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.
