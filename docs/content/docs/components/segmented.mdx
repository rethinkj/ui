`Segmented.segmented` is a frame of joined choices, the chosen one filled with the accent. Use it to switch between two to four views or modes: rows or cells, light, dark or system. For choices that need room to be read, use [Radio](/docs/components/radio).

## Values instead of indexes

`Segmented.segmented(t, values, selected, text, onSelect)` chooses among values of any type, as [Select](/docs/components/select#values-instead-of-indexes) does:

```java snippet="segmented-typed"
```

The selected value is found by `equals`, a null among the values too; null where the list has none, or a value not in the list, selects nothing. Equal values show once, so that the keys go on from the selected value to the next one that differs. The handler gets the value; a null handler disables it. For an enum, pass `List.of(E.values())`.

## Keyboard

One stop for Tab; the arrows choose around the ends, Home and End the first and the last, and Space the first while none is chosen.

## With a Prop

`segmented(t, values, prop, text)` takes a `Prop` in place of the value and its handler, such as a field of an [Editing](/docs/concepts/editing) of a record: it writes the prop back, shows its field's error, and is disabled when the prop cannot be written.
