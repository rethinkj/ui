title: Segmented

---

`Segmented.segmented` is a frame of joined choices, the chosen one filled with the accent. Use it to switch between two to four views or modes: rows or cells; light, dark or system. For choices that need room to be read, use [Radio](/docs/components/radio).

Javadoc: [`Segmented`](/api/com/rethinkj/ui/kit/Segmented.html).

## Values instead of indexes

`Segmented.segmented(values, selected, text, onSelect)` chooses among values of any type. The value is found as on [Select](/docs/components/select#values-instead-of-indexes).

## Keyboard

One stop for Tab. The arrows choose the next and the previous choice, around the ends. Home and End choose the first and the last. Space chooses the first while none is chosen.

## With a Prop

`segmented(values, prop, text)` takes a [`Prop`](/docs/concepts/editing#components-that-take-a-prop), such as a field of an `Editing`, in place of the value and its handler.
