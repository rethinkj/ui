`Tabs.tabs` renders a tab bar above the active tab's content (only the active tab's content is built). Your app owns the tab list and active index.

For split tab groups and tabs that tear off into separate windows, use [TabGroups](/docs/components/tab-groups). For a compact 2–3 option toggle, use [Segmented](/docs/components/segmented).

Javadoc: [`Tabs`](/api/com/rethinkj/ui/kit/Tabs.html), [`Tabs.Tab`](/api/com/rethinkj/ui/kit/Tabs.Tab.html), [`Tabs.Options`](/api/com/rethinkj/ui/kit/Tabs.Options.html), [`Tabs.Overflow`](/api/com/rethinkj/ui/kit/Tabs.Overflow.html).

| `Tabs.Tab` | Description |
| --- | --- |
| `new Tabs.Tab(title, closable, modified)` | Title, close button flag, and unsaved dot (in the close slot, turning into the cross on hover at the tab's right end) |
| `.icon(Symbol)` | Leading icon |
| `.hue(Theme.Hue.RED)` | Colored leading tick (for example, marking production connections; appears as `value="red"` in tree dumps) |
| `.busy(true)` | Replaces icon with a loading spinner (visible even on inactive tabs) |
| `.tooltip(text)` | Tooltip while the pointer rests on the tab, such as a file's whole path |

Passing `null` for `onSelect` disables the bar; `null` for `onClose` hides close buttons.

## Options

| Option | Description |
| --- | --- |
| `onAdd(state::addTab)` | Shows a `+` button after the last tab (pinned at the bar's end on overflow, and shown in an empty bar) and binds Ctrl+T |
| `overflow(state.overflow)` | Shows an overflow button at the bar's end while tabs do not fit, opening a dropdown of all tabs |
| `onMove((from, to) -> …)` | Enables tab reordering (`Tabs.move(list, active, from, to)` helper updates your list and returns the new active index) |
| `drag(Tabs.Dragging)`, `onTearOff(...)`, `id(...)`, `onDock(...)` | Low-level drag-and-drop and cross-bar docking (handled automatically by [TabGroups](/docs/components/tab-groups)) |
| `contextMenu(menuState, items)` | Right-click / Menu-key context menu on tabs |
| `variant(Tabs.Variant.LINE)` | Compact underline style instead of default `CARD` |
| `active(false)` | Omits the top accent mark in `CARD` and uses `Theme.Accent.edgeMuted` in `LINE` (for inactive split groups) |
| `switchKeys(false)` | Lets Ctrl+Tab / Ctrl+PageUp/Down bubble to an outer `Tabs` bar when nesting tabs |

To list all tabs when a bar overflows, keep one `Tabs.Overflow` instance per bar in your state and pass it to `Tabs.options().overflow(state.overflow)`. While the tabs do not fit, a button at the bar's end opens a dropdown listing every tab in bar order with its icon and the active tab checked; choosing a tab selects it and scrolls it into view, including when it is already active and scrolled off-screen.

## Keyboard

| Key | Action |
| --- | --- |
| Left, Right, Home, End | Switch tabs while the tab bar is focused |
| Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+PageDown, Ctrl+PageUp | Next / previous tab |
| Ctrl+W, Ctrl+F4 | Close active tab |
| Ctrl+T | Add a tab (when `onAdd` is set, also in an empty bar) |
| Ctrl+Shift+PageUp, Ctrl+Shift+PageDown | Reorder active tab (when `onMove` is set) |
| Menu key, Shift+F10 | Open tab context menu |

Give each tab's content a unique `.key(...)` so focus is remembered per tab when switching. Attach `root.onKey(tabs.onKey())` if you want Ctrl+Tab shortcuts to work from anywhere in the window.
