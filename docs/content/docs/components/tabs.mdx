title: Tabs
description: Tab bar over active tab content in card style or compact underline style.
---

`Tabs.tabs` renders a tab bar above the active tab's content (only the active tab's content is built). Your app owns the tab list and active index.

For tabs that tear off into separate windows, use [TabGroups](/docs/components/tab-groups). For a compact 2–3 option toggle, use [Segmented](/docs/components/segmented).

Javadoc: [`Tabs`](/api/com/rethinkj/ui/kit/Tabs.html), [`Tabs.Tab`](/api/com/rethinkj/ui/kit/Tabs.Tab.html), [`Tabs.Options`](/api/com/rethinkj/ui/kit/Tabs.Options.html).

| `Tabs.Tab` | Description |
| --- | --- |
| `new Tabs.Tab(title, closable, modified)` | Title, close button flag, and unsaved dot indicator |
| `.icon(Symbol)` | Leading icon |
| `.hue(Theme.Hue.RED)` | Colored top accent bar (for example, marking production connections; appears as `value="red"` in tree dumps) |
| `.busy(true)` | Replaces icon with a loading spinner (visible even on inactive tabs) |

Passing `null` for `onSelect` disables the bar; `null` for `onClose` hides close buttons.

## Underline style (`Variant.LINE`)

For nested tabs inside a card or pane (such as Result / Messages below a query), use `Tabs.options().variant(Tabs.Variant.LINE)` to omit the outer card frame and draw a sliding underline under the active tab:

## Options

| Option | Description |
| --- | --- |
| `onMove((from, to) -> …)` | Enables tab reordering (`Tabs.move(list, active, from, to)` helper updates your list and returns the new active index) |
| `drag(Tabs.Dragging)`, `onTearOff(...)`, `id(...)`, `onDock(...)` | Low-level drag-and-drop and cross-bar docking (handled automatically by [TabGroups](/docs/components/tab-groups)) |
| `contextMenu(menuState, items)` | Right-click / Menu-key context menu on tabs |
| `variant(Tabs.Variant.LINE)` | Compact underline style instead of default `CARD` |
| `switchKeys(false)` | Lets Ctrl+Tab / Ctrl+PageUp/Down bubble to an outer `Tabs` bar when nesting tabs |

## Keyboard

| Key | Action |
| --- | --- |
| Left, Right, Home, End | Switch tabs while the tab bar is focused |
| Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+PageDown, Ctrl+PageUp | Next / previous tab |
| Ctrl+W, Ctrl+F4 | Close active tab |
| Ctrl+Shift+PageUp, Ctrl+Shift+PageDown | Reorder active tab (when `onMove` is set) |
| Menu key, Shift+F10 | Open tab context menu |

Give each tab's content a unique `.key(...)` so focus is remembered per tab when switching. Attach `root.onKey(tabs.onKey())` if you want Ctrl+Tab shortcuts to work from anywhere in the window.
