`Tabs.tabs` is a card whose first row is a bar of tabs. Below it, the content of the active tab fills the card edge to edge. Use it for open documents, queries or tables. The app owns the list and the active index; the content is built for the active tab only. To let tabs move between windows, use [TabGroups](/docs/components/tab-groups); for a choice of two or three views, a [Segmented](/docs/components/segmented) control.

Javadoc: [`Tabs`](/api/com/rethinkj/ui/kit/Tabs.html), [`Tabs.Tab`](/api/com/rethinkj/ui/kit/Tabs.Tab.html), [`Tabs.Options`](/api/com/rethinkj/ui/kit/Tabs.Options.html).

`state.tabs` is a list of `Tabs.Tab` and `state.tab` the active index, both in the app's state.

| `Tabs.Tab` | |
| --- | --- |
| `new Tabs.Tab(title, closable, modified)` | A title, whether it can be closed, and whether it is modified (a dot before the title) |
| `.icon(Symbol)` | An icon before the title |
| `.hue(Theme.Hue.RED)` | A line in that color along the tab's top, to mark the tabs of a group, such as those of a connection to production. The tab says `value="red"` in a tree dump |
| `.busy(true)` | A spinner in place of the icon while the tab's content works, such as a running query; it shows while another tab is active too |

`onSelect` and `onClose` get the index. Closing is the app's job: it removes the tab and picks the next active one.

## Options

`Tabs.tabs(tabs, active, onSelect, onClose, content, Tabs.options()…)`:

| Option | What it does |
| --- | --- |
| `onMove((from, to) -> …)` | Control+Shift+Page Up and Page Down move the active tab; `Tabs.move(list, active, from, to)` moves an element and returns the new active index |
| `drag(Tabs.Dragging)` | Tabs can be dragged along the bar, with a marker where they go |
| `onTearOff(handler)`, `tearOffAtStart(boolean)` | Told when a tab is dragged out of the bar |
| `id(object)`, `onDock((fromBar, from, at) -> …)` | Lets a bar take a tab from another bar with the same `Dragging` |
| `contextMenu(menuState, items)` | A menu for a tab, at a secondary press or the Menu key |
| `switchKeys(false)` | Leaves Control+Tab, Control+Shift+Tab, Control+Page Down and Control+Page Up to what encloses the bar, for tabs nested in the content of other tabs |

[TabGroups](/docs/components/tab-groups) wires all of these for you.

The app keeps one [`Tabs.Dragging`](/api/com/rethinkj/ui/kit/Tabs.Dragging.html) for all bars that trade tabs. It says what a drag is doing, so that a view can hide things meanwhile, such as a tooltip or a drop hint: `isActive()` says whether a tab is being dragged, and `isTorn()` whether it has left its bar (`onTearOff`).

## Keyboard

| Keys | Action |
| --- | --- |
| Left, Right, Home, End | Choose a tab, while the bar has the focus |
| Control+Tab, Control+Shift+Tab; Control+Page Down, Control+Page Up | Next and previous tab, from the bar or the content |
| Control+W, Control+F4 | Close the active tab |
| Control+Shift+Page Up, Page Down | Move the active tab, with `onMove` |

When the active tab changes while the focus is in the content, the focus goes into the new content: to where it was last there, else to its `defaultFocus()` element. The focus is remembered by the elements' identities, so give each tab's content a key of its own, such as the query's id; [TabGroups](/docs/components/tab-groups) does it for you.

The bar is one stop for Tab. For the shortcuts to work while the focus is elsewhere, give the root the same handler: `root.onKey(tabs.onKey())`.

Keys go up from the focused element to the nearest tabs. When tabs sit inside the content of other tabs, such as a result and its messages inside a query tab, give the inner ones `switchKeys(false)`: the keys that choose a tab then reach the outer ones, while Left, Right, Home and End on the inner bar still choose its own tabs.

## In a tree dump

Each tab is `role=tab` with its title as label and the key `tab-<index>`; the active one is `selected`, a busy one `busy`, a modified one `modified`, and one being dragged `grabbed`. A close button is `role=button` with `label="Close <title>"` and the key `close-<index>`.
