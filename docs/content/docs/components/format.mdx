title: Format and ValueField
description: Locale-independent typed formatting and validated input fields for numbers, dates, enums, and custom types.
---

`Format<T>` defines how a Java type (such as `BigDecimal`, `LocalDate`, an enum, or your own type) converts to and from text. `ValueField.valueField` is a text input built on `Format<T>`: it passes typed values to your handler and stores invalid input as a draft with an error message.

[DataGrid](/docs/components/data-grid) typed columns reuse the same `Format` objects for alignment, icons, and editors. For stepping integers with arrows and +/- buttons, use [NumberField](/docs/components/number-field).

Javadoc: [`Format`](/api/com/rethinkj/ui/kit/Format.html), [`ValueField`](/api/com/rethinkj/ui/kit/ValueField.html).

## Built-in formats

| Format | Java type | Text format |
| --- | --- | --- |
| `TEXT` | `String` | Plain text (empty input is `""`) |
| `INTEGER`, `LONG`, `BIG_INTEGER` | `Integer`, `Long`, `BigInteger` | Signed integers (`-12`, `+7`); rejects out-of-range values |
| `DECIMAL` | `BigDecimal` | `12.50`, `-.5`, `1e3` (formatted without scientific notation; rejects huge exponents > 4096 zeros) |
| `DATE` | `LocalDate` | ISO 8601 (`2026-11-13`) |
| `TIME` | `LocalTime` | `14:30`, `14:30:15` |
| `DATE_TIME` | `LocalDateTime` | `2026-11-13 14:30` (also accepts `T`) |
| `OFFSET_DATE_TIME` | `OffsetDateTime` | `2026-11-13 14:30+01:00` |
| `BYTES` | `Long` | Decimal units (`817 B`, `1.2 MB`, `12 MB`); parses plain bytes, SI (`KB`–`EB`), and binary (`KiB`–`EiB`); rejects negatives |
| `BOOLEAN` | `Boolean` | `true`/`false` (also parses `t`, `1`, `yes`, `on` and opposites) |
| `choice(values, label)` | Any (e.g., enum) | Matches values by unique display label (`Format.choice(List.of(Status.values()), Status::label)`) |
| `of(text, parse, message)` | Any custom type | Custom formatter/parser (`Format.of(UUID::toString, UUID::fromString, "Expected a UUID")`) |

Numbers always use `.` as decimal separator (no thousands separators) and dates use ISO 8601 regardless of OS locale.

| Modifier | Effect |
| --- | --- |
| `.optional()` | Treats empty text as `null` (without it, empty text fails with `"A value is required"` except for `TEXT`) |
| `.where(test, message)` | Adds a validation predicate (e.g., `Format.INTEGER.where(p -> p >= 1 && p <= 65535, "1 to 65535")`) |

Store formats in `static final` constants. Use `format.text(value)` and `format.parse(text)` directly when needed.

## Fixed-precision time formats

To align timestamps in tables with consistent length (e.g., always showing seconds or milliseconds):

```java snippet="format-precision"
```

| Factory | Example output |
| --- | --- |
| `Format.time(precision)` | `09:00:00` (`0`), `09:00:05.120` (`3`), up to `9` fractional digits |
| `Format.dateTime(precision)` | `2026-01-01 09:00:00` |
| `Format.offsetDateTime(precision, offset)` | Formats offset as `Z` (`Z`, `+05:30`), `COLONS` (`+00:00`), or `SHORT` (`+00`) |

Extra fractional digits are truncated in display text without modifying the underlying value.

## Field behavior

- **Live updates:** `onChange` runs on every edit that parses to a valid value, so Save buttons work without pressing Enter first.
- **Drafts & errors:** Unparsed text (like `12e`) stays in `ValueField.Draft`, showing a danger border and error message in [Form](/docs/components/form). Your state keeps the last valid value; check `draft.error() == null` before saving.
- **External updates:** If your state value changes externally (such as a reset), the field updates automatically. Call `draft.clear()` to reset a draft explicitly.
- **Hidden initial errors:** Invalid initial values (such as `null` in a required field) set `draft.error()` immediately for Save validation, but stay visually hidden until edited or until you call `draft.showError()` (or `editing.showErrors()`).

## With a Prop

`valueField(format, prop[, placeholder])` binds to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record (which manages the draft automatically — `Prop.of` throws `IllegalStateException`).
