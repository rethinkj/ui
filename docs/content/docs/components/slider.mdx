title: Slider

`Slider.slider` displays a horizontal track and draggable knob for picking an integer value in a range (such as font size or zoom). For exact numeric entry, use [NumberField](/docs/components/number-field).

Javadoc: [`Slider`](/api/com/rethinkj/ui/kit/Slider.html).

<Shot src="kit/gallery-{theme}-2x" rows="slider" alt="A slider in each state" />

## Example

```java snippet="slider"
```

Call `Slider.slider(value, min, max, step, onChange)`. Users can drag the knob or click anywhere on the track. Passing a `null` handler disables it. Values snap to `min + k * step` within `[min, max]`.

## Keyboard

**Arrow keys** move by `step`; **Page Up/Down** move by ~10% of the range; **Home/End** jump to the ends.

## With a Prop

`slider(prop, min, max, step)` binds directly to a [`Prop`](/docs/concepts/editing#components-that-take-a-prop) from an `Editing` record.
