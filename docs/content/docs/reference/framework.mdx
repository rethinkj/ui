This site is for people who build apps with rethinkj UI. The rules for changing the framework itself are in [`AGENTS.md`](https://github.com/rethinkj/ui/blob/main/AGENTS.md) at the root of the repository.

## In short

- `core` and `kit` depend on `java.base` only; no reflection, no JNI.
- Changes come as pull requests against `main`.
- A change of output is checked against stored images: `mvn -pl core -am test -Dgolden.update=true` rewrites them; look at them before committing.
- A change that users notice gets a file under `changelog/unreleased` and updates the page of this site it concerns.

## This site

The site lives in `docs/` of the repository, as a Fumadocs app built to static files. Its images are the stored images of the tests, and its code comes from compiled examples in `examples/src/test/java/com/rethinkj/ui/examples/docs`, which the build runs.
