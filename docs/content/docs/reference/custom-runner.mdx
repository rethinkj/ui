---
title: Custom runner
description: App methods for integrating rethinkj UI into your own event loop or another window toolkit.
---

By default, `WindowLoop` runs your app in an SDL window. If you want to embed rethinkj UI inside a custom event loop or another toolkit, feed input using the methods in [Driving it from Java](/docs/concepts/app#driving-it-from-java) (see [`App` Javadoc](/api/com/rethinkj/ui/App.html#method-summary)), call `frame()`, display the pixels from `GpuRenderer.render(scene(), …)` or `render()`, and use the lifecycle methods below:

| `App` method | Purpose |
| --- | --- |
| `advance(seconds)` | Advances the app clock by the elapsed time since the last frame. Call once per frame. |
| `isMoving()` | Returns `true` while an animation is active and the next frame needs to render even without input. |
| `cursor()` | Returns the mouse cursor shape requested by the hovered element so you can update the OS cursor after each frame. |
| `clipboard(clipboard)`, `dialogs(dialogs)`, `windows(windows)` | Connects system clipboard, file dialogs, message boxes, and multi-window support. Without them, the app uses an in-memory clipboard and `Dialogs.NONE`, and opening new windows throws an exception. |
| `nextChange()` | Returns the time until the next scheduled visual change (cursor blink, hover delay, or `after` timer), or positive infinity when idle so your loop can sleep until input arrives. |
| `onPost(wake)` | Registers a callback invoked on the posting thread whenever a background task posts work; use it to wake your event loop. |
| `handlersWaiting()` | Returns `true` if queued handlers (such as `onResize` after layout) need another frame immediately. |
| `invalidate()` | Marks the view dirty when state changed outside this app's handlers (for example, call this on sibling windows sharing the same state when `ranHandlers()` is `true`). |
| `inputArea()` | Returns `InputArea(x, y, width, height, cursor, password)` in logical pixels for the focused text field (or `null`), used to position IME windows and toggle text input. |
| `windowActive(boolean)`, `windowMaximized(boolean)` | Updates `WindowState.CURRENT` and rebuilds the view (for example, to dim inactive title bars or toggle the maximize/restore button). |
| `systemFonts(boolean)` | Enables fallback to OS fonts for characters missing from bundled fonts. Off by default for deterministic tests; `WindowLoop` turns it on. |
| `textRendering(rendering)`, `imageMemory(bytes)` | Configures text hinting mode and GPU image cache size. |

Call all `App` methods from the app's thread. Only the `wake` callback passed to `onPost` runs on the posting thread.
