rethinkj UI is a native, GPU-rendered UI framework for Java 25 on Windows and Linux. It draws everything itself, from text to a data grid of a million rows, and it runs without a window too: a script drives the app, and images and element trees come out, so that an agent or a test can see and use what it builds. It is early: version 0.1.0-SNAPSHOT, SNAPSHOTs on Maven Central and no release yet, and the API still changes.

## What is in it

- **core** (`com.rethinkj.ui`): elements and flexbox layout, text, springs, scrolling, virtual lists, overlays, focus and keyboard, text editors, several windows, scripts, and a GPU renderer with a CPU twin for rendering without a window.
- **kit** (`com.rethinkj.ui.kit`): a dark and a light theme and the components of a data tool: a data grid, a tree, tabs, a code editor, menus, a command palette, dialogs, forms, and more.
- `core` and `kit` depend on `java.base` only.

## For agents

Every page of this site is also Markdown: add `.md` to its address (`/docs/components/button.md`), or use the Copy Markdown button. [/llms.txt](/llms.txt) lists all pages with a line each, and [/llms-full.txt](/llms-full.txt) holds them all in one file. Each component's page ends with what it shows in a tree dump, so that a script can find it.

The Java on this site is compiled with the project's tests, and most of it runs there under a script; the pictures are the images those tests store.
