rethinkj UI is a native, GPU-rendered desktop UI framework for Java 25 on Windows 11+ and Linux (x64). It renders everything itself, from text to large data grids. It can also run without a window so automated tests and AI agents can drive your app with scripts and inspect screenshots and element trees.

> **Early preview:** rethinkj UI is currently at version `0.1.0-SNAPSHOT` on Maven Central Snapshots. The API may still change before the first stable release.

## What is included

- **core** (`com.rethinkj.ui`): Elements, flexbox layout, text rendering, spring animations, scrolling, virtual lists, overlays, focus and keyboard handling, text editors, multi-window support, headless scripting, and GPU/CPU rendering.
- **kit** (`com.rethinkj.ui.kit`): Dark and light themes plus ready-made components for desktop apps and data tools: data grid, tree, tabs, code editor, menus, command palette, dialogs, forms, and more.
- **Minimal dependencies:** Both `core` and `kit` depend only on `java.base`.
