Every element can carry semantic metadata: a **role** (what it is, such as `button`, `switch`, `textbox`, `grid`, `treeitem`), a **label** (its name), and **states** (such as `checked`, `selected`, `expanded`, `disabled`).

States follow WAI-ARIA naming. They do not change styling or input handling by themselves — they describe the UI in [tree dumps](/docs/testing/tree-dump) so [selectors](/docs/testing/selectors) can target elements like `role=switch label="Lamp"` and verify `checked` without inspecting colors.

## Methods on `El`

All methods are on [`El`](/api/com/rethinkj/ui/El.html):

| Method | Tree dump output |
| --- | --- |
| `role(name)`, `label(text)` | `role=…`, `label="…"` |
| `disabled(boolean)` | `disabled` |
| `invalid(boolean)` | `invalid` |
| `busy(boolean)` | `busy` |
| `selected(boolean)` | `selected` |
| `current(boolean)` | `current` (active cursor row/cell or highlighted menu item) |
| `grabbed(boolean)` | `grabbed` (currently being dragged) |
| `modified(boolean)` | `modified` (has unsaved changes) |
| `checked(boolean)`, `checkedMixed()` | `checked`, `checked=false`, `checked=mixed` |
| `expanded(boolean)` | `expanded`, `expanded=false` |
| `level(n)` | `level=<n>` (1-based tree depth) |
| `position(n, size)` | `pos=<n>/<size>` (1-based position and total count) |
| `sortAscending()`, `sortDescending()` | `sort=ascending`, `sort=descending` |
| `value(text)` | `value="…"` |
| `errorMessage(text)` | `error="…"` (shown after states) |
| `warningMessage(text)` | `warning="…"` (shown after error, for non-blocking warnings) |

Text fields automatically set `disabled`, `readonly`, `password`, and `revealed` based on their configuration.

## Guidelines for custom components

- **Mirror visual states semantically.** If a background color indicates selection, also call `selected(true)`. All kit components follow this rule.
- **Label icon-only controls.** Give every icon button a clear `.label(...)` on the clickable element.
- **Mark the active item.** Set `current(true)` (or `selected(true)` for single-select lists) so the **Menu** key opens context menus on the right item.
