`El.text(value).editable(onEdit)` makes a text field, and `.multiline()` a multi-line editor that handles 100 000 lines. The string belongs to the app: the view builds the field with the current value, and every edit passes the new string to `onEdit`, which stores it. The kit's [TextField](/docs/components/text-field) and [CodeEditor](/docs/components/code-editor) are built on these; use them unless you need your own look.

## Refuse or change an edit

`onEdit` may refuse an edit (store nothing) or change it, for example keep only digits; the field then shows the app's string, with the caret where it fits. When the app changes the value itself, the caret stays near its text and the undo history ends.

## Keep caret and undo across tabs

The app keeps a field's caret, selection, scroll offset, undo history (100 steps) and input method composition by the field's identity, and drops them when the field leaves the tree, for example in a tab that is not active. To keep them, pass a `FieldState` from your state to `.fieldState(...)`: the editor then comes back as it was, also in another window. Only a composition ends when the field leaves.

## Options

| Call | |
| --- | --- |
| `multiline()`, `lines(n)`, `fitLines()` | Several lines; `n` lines high; as high as all its lines |
| `wrapText()` | Break lines at the width instead of scrolling sideways; a word longer than a row breaks inside it |
| `readOnly()`, `editable(null)` | Select and copy only; disabled |
| `maxLength(n)` | At most `n` code points |
| `masked()`, `maskCharacter(c)` | A password field |
| `revealed(boolean)` | A masked field that draws its string; the tree still sees the mask |
| `placeholder(text, argb)`, `caretColor(argb)`, `selectionColor(argb)` | The look |
| `tabIndents(spaces)`, `tabSize(n)` | Tab indents in a multi-line field |
| `codeWords()` | Words are runs of letters, digits and `_`, for Control+Arrow and double clicks |
| `onSelect((caret, anchor) -> …)` | Called when the caret or selection moves |
| `highlight(key, highlighter)` | Colours, fonts, backgrounds, underlines per range |
| `decorate(decorator)` | Backgrounds and underlines for the lines in view: the caret's line, matches, errors |
| `gutter((line, caret) -> cell)` | An element per line at the left: line numbers |

From handlers, `app.edit(field, from, to, text, caret)` replaces a range as one undo step, `app.select(field, caret, anchor)` selects, and `app.undo(field)` and `app.redo(field)` step through the history, for an Edit menu.

## Find the word at the caret

For completion or rename, `CodeWords.start(text, index)` and `CodeWords.end(text, index)` return where the code word around an index begins and ends (letters, digits and `_`, as for `codeWords()`). Both return the index itself when no word touches it.

## Links in a paragraph

- In a tree dump the child's rectangle is the bounding box of its rows, but it takes presses and draws its fill and focus ring only on the text it covers, one rectangle per row. `rangeBoxes()` returns those rectangles after layout, as `Text.Box(x, y, width, height)` relative to the child.
- It takes presses, the cursor, hover looks and, with `focusable()`, the focus, like any element; a press on it does not reach the field. Enter presses it while it has the focus.
- `fitLines()` makes the field as high as its text, so it never scrolls, and `skipTab()` on the field lets Tab go from link to link.

[Markdown](/docs/components/markdown) builds its links this way.

## Keys and pointer

Arrows, Home, End, Page Up and Down, with Shift to select and Control to move by words; Backspace and Delete; Control+A, C, X, V, Z, Y and Control+Shift+Z. A double click selects a word, a triple click a line or everything. The caret never stops inside an emoji or between a letter and its accent. In a multi-line field Enter breaks the line, and Control+Enter goes to the app's handlers.

Input methods compose in place, underlined; the composition shows in the tree as `composing "…"`.
