`El.text("…")` makes a text element, sized by its text. Text is shaped with HarfBuzz (kerning, ligatures, joining scripts) and rasterised with FreeType, so it looks the same on Windows and Linux. The kit's `Label` applies the theme's text styles; use `El.text` for anything else.

| Call | |
| --- | --- |
| `font(Font)`, `fontSize(px)`, `color(argb)` | The look; the default is [`Font.sans()`](/api/com/rethinkj/ui/text/Font.html), 14, black |
| `wrapText()` | Break lines at the element's width; a word, path or URL wider than the whole width breaks inside |
| `ellipsis()` | End a line that does not fit in `…`; give the element a width or `minSize(0, 0)` |
| `maxLines(n)` | Show at most `n` lines of a wrapped text; with `ellipsis()` the last ends in `…` where the text goes on |
| `textAlign(Style.Align.CENTER)` | Each line centred (or `END`) in its box |
| `fontFeatures("+calt")` | OpenType features in HarfBuzz's syntax |
| `textBackground(argb)` | The color behind the text when it is not the fill of the element or an ancestor, such as an image or a sibling below; glyph edges are drawn for that color |

A line feed always starts a new line. Wrapped text breaks between words; a word wider than the whole box, such as a file path or a URL, starts its own line and breaks between characters, as with CSS's `overflow-wrap: break-word`. In a row, layout still gives a text room for its longest word; only a narrower box breaks it.

After layout, `el.text()` returns the element's [`Text`](/api/com/rethinkj/ui/Text.html). `shortened()` says whether a line was cut with `…`, for a tooltip with the whole text (the kit's `Tooltip.whenShortened` uses it). `lines()` holds a `GlyphRun` per drawn line, with its width and baseline in physical pixels.

## Fonts

| Font | |
| --- | --- |
| `Font.sans()`, `sansMedium()`, `sansSemibold()`, `sansBold()`, `sansItalic()`, `sansBoldItalic()` | Inter 4.1 |
| `Font.mono()`, `monoBold()` | JetBrains Mono 2.304 |
| `Font.icons()` | Fluent UI System Icons, for the kit's `Icon` |
| `Font.of(bytes)`, `Font.resource(owner, name)` | Your own TrueType or OpenType font; `close()` frees it |

The default fonts come in `rethinkj-ui-fonts`, the icons in `rethinkj-ui-icons`.

## Characters a font lacks

`font.withFallback(other...)` falls back to other fonts in order, keeping the first font's line height. `font.withSystemFonts()` then falls back to the fonts installed on the system (Noto and DejaVu on Linux, Segoe UI and the CJK fonts on Windows, chosen by script and locale). In a window, all text falls back to the system's fonts; under a script it does not, so images are the same on every machine. `app.systemFonts(boolean)` switches it; `WindowLoop` turns it on unless `loop.systemFonts(false)`.

Right-to-left text is shaped right to left, but mixed-direction lines are not reordered (no full bidirectional algorithm). Color emoji show as outlines in the text color where the font has them.

## Text rendering

`app.textRendering(TextRendering.LINUX)` or `WINDOWS` chooses how glyphs are hinted and blended; the default is the platform's. Pin one in [image tests](/docs/testing/stored-images) so they pass on both platforms.
