Create text elements with `El.text("…")`. Text is shaped with HarfBuzz (supporting kerning, ligatures, and complex scripts) and rendered with FreeType so it looks consistent across Windows and Linux. For standard themed typography, use the kit's [Label](/docs/components/label) component.

| Method | Description |
| --- | --- |
| `font(Font)`, `fontSize(px)`, `color(argb)` | Font, size, and color (default: [`Font.sans()`](/api/com/rethinkj/ui/text/Font.html), 14 px, black) |
| `lineHeight(multiple)` | Line height as a multiple of the font size, inherited by descendant text elements (default: the font's own height) |
| `wrapText()` | Wraps lines to fit width; breaks long unbreakable words (like URLs or file paths) between characters |
| `ellipsis()` | Truncates overflowing text with `…`, or shows nothing if even `…` does not fit (set a width or `minSize(0, 0)` in flex layouts). Any `underline(from, to)` covers only the characters still shown |
| `maxLines(n)` | Limits wrapped text to `n` lines (adds `…` on the last line when combined with `ellipsis()`) |
| `textAlign(Style.Align.CENTER)` | Horizontal line alignment (`START`, `CENTER`, `END`) for plain text and wrapping multi-line fields |
| `fontFeatures("+calt")` | Enables or disables OpenType features using HarfBuzz syntax |
| `textBackground(argb)` | Hints the background color for crisp glyph blending when text sits over an image or sibling |

After layout, `el.text()` returns a [`Text`](/api/com/rethinkj/ui/Text.html) object. `el.text().shortened()` tells you whether text was truncated with `…` (used by `Tooltip.whenShortened`).

## Line height

`lineHeight(multiple)` sets the height of one line as a multiple of the font size (as CSS's unitless `line-height`). It can be set on any element and is inherited by descendant text elements and fields; overlays start fresh. The difference from the font's own height is split evenly above and below the glyphs, and the caret, selection, wrapping, gutter, and row scrolling follow it.

## Bundled and custom fonts

| Font | Source |
| --- | --- |
| `Font.sans()`, `sansMedium()`, `sansSemibold()`, `sansBold()`, `sansItalic()`, `sansBoldItalic()` | Inter 4.1 (`rethinkj-ui-fonts`) |
| `Font.mono()`, `monoBold()` | JetBrains Mono 2.304 (`rethinkj-ui-fonts`) |
| `Font.icons()` | Fluent UI System Icons (`rethinkj-ui-icons`) |
| `Font.of(bytes)`, `Font.resource(owner, name)` | Load your own TrueType or OpenType font (call `close()` to free) |
| `Font.installedFamilies()`, `Font.installed(family, weight, italic)` | List and load the fonts installed on the system (Windows, Linux); `installed(family, style)` for a style the list gives, `Family.monospaced()` for code editors |

## Fallback fonts

- `font.withFallback(other...)` adds fallback fonts for missing characters while keeping the primary font's line height.
- `font.withSystemFonts()` falls back to installed OS fonts (Noto/DejaVu on Linux, Segoe UI and CJK fonts on Windows).
- In desktop windows, `WindowLoop` enables system font fallback globally by default (disable with `loop.systemFonts(false)`). In headless scripts, it is off by default for deterministic screenshots across machines.

Note: Right-to-left text is shaped right-to-left, but full bidirectional reordering for mixed-direction lines is not supported yet. Color emoji are drawn in color from COLR version 0 fonts (such as Segoe UI Emoji on Windows) and CBDT bitmap fonts (such as Noto Color Emoji on Linux); COLR version 1 fonts are not supported yet and still render as single-color outlines or are left out.

## Text rendering

By default, text is rendered unhinted (`TextRendering.Hinting.NONE`) with subtle stem darkening, quarter-pixel glyph positioning at every scale (icons stay on whole pixels), and coverage correction (2.0 for dark text, 1.5 for light text). The bundled Inter faces also apply Inter's size-dependent tracking so headings tighten while body text stays balanced.

`TextRendering.LINUX` and `TextRendering.WINDOWS` use this same unhinted rendering, so text looks identical across Linux and Windows. Apps that prefer platform hinting can pass a custom `TextRendering` with `Hinting.LIGHT` or `Hinting.NATIVE` to `app.textRendering(...)`.
