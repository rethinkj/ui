Create text elements with `El.text("…")`. Text is shaped with HarfBuzz (supporting kerning, ligatures, and complex scripts) and rendered with FreeType so it looks consistent across Windows and Linux. For standard themed typography, use the kit's [Label](/docs/components/label) component.

| Method | Description |
| --- | --- |
| `font(Font)`, `fontSize(px)`, `color(argb)` | Font, size, and color (default: [`Font.sans()`](/api/com/rethinkj/ui/text/Font.html), 14 px, black) |
| `wrapText()` | Wraps lines to fit width; breaks long unbreakable words (like URLs or file paths) between characters |
| `ellipsis()` | Truncates overflowing text with `…`, or shows nothing where not even `…` fits (set a width or `minSize(0, 0)` in flex layouts) |
| `maxLines(n)` | Limits wrapped text to `n` lines (adds `…` on the last line when combined with `ellipsis()`) |
| `textAlign(Style.Align.CENTER)` | Horizontal line alignment (`START`, `CENTER`, `END`) |
| `fontFeatures("+calt")` | Enables or disables OpenType features using HarfBuzz syntax |
| `textBackground(argb)` | Hints the background color for crisp glyph blending when text sits over an image or sibling |

After layout, `el.text()` returns a [`Text`](/api/com/rethinkj/ui/Text.html) object. `el.text().shortened()` tells you whether text was truncated with `…` (used by `Tooltip.whenShortened`).

## Bundled and custom fonts

| Font | Source |
| --- | --- |
| `Font.sans()`, `sansMedium()`, `sansSemibold()`, `sansBold()`, `sansItalic()`, `sansBoldItalic()` | Inter 4.1 (`rethinkj-ui-fonts`) |
| `Font.mono()`, `monoBold()` | JetBrains Mono 2.304 (`rethinkj-ui-fonts`) |
| `Font.icons()` | Fluent UI System Icons (`rethinkj-ui-icons`) |
| `Font.of(bytes)`, `Font.resource(owner, name)` | Load your own TrueType or OpenType font (call `close()` to free) |

## Fallback fonts

- `font.withFallback(other...)` adds fallback fonts for missing characters while keeping the primary font's line height.
- `font.withSystemFonts()` falls back to installed OS fonts (Noto/DejaVu on Linux, Segoe UI and CJK fonts on Windows).
- In desktop windows, `WindowLoop` enables system font fallback globally by default (disable with `loop.systemFonts(false)`). In headless scripts, it is off by default for deterministic screenshots across machines.

Note: Right-to-left text is shaped right-to-left, but full bidirectional reordering for mixed-direction lines is not supported yet. Color emoji render as monochrome outlines in the text color.

## Platform text rendering

`app.textRendering(TextRendering.LINUX)` or `TextRendering.WINDOWS` selects glyph hinting and blending style (defaults to the current OS). Pin one in [stored image tests](/docs/testing/stored-images) so screenshots match on both platforms.
