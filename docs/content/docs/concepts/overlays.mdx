title: Overlays

Overlays float above all other elements and are not clipped by parent scroll containers. Attach an overlay to its anchor element with [`anchor.overlay(menu)`](/api/com/rethinkj/ui/El.html#overlay(com.rethinkj.ui.El)) — passing `null` closes it (`button.overlay(state.open ? menu : null)`).

Kit components like [Menu](/docs/components/menu), [Tooltip](/docs/components/tooltip), [Dialog](/docs/components/dialog), [Drawer](/docs/components/drawer), [Popover](/docs/components/popover), and [Toast](/docs/components/toast) use overlays internally. Use this API when building custom floating UI.

## Placement

| Method | Description |
| --- | --- |
| `side(Side, Style.Align, gap)` | Places next to the anchor: `BOTTOM` (default), `TOP`, `LEFT`, `RIGHT`, aligned `START`, `CENTER`, `END`, or `STRETCH` |
| `atPoint(x, y)` | Places at window coordinates (for context menus) |
| `atCaret()` | Places at the anchor text field's cursor (for autocomplete popups) |
| `centerInWindow()` | Centers in the window (for dialogs) |
| `atWindowEdge(side, align, gap)` | Places along a window edge (for toasts and drawers; `STRETCH` fills the edge less `gap` at both ends) |

Overlays are automatically constrained to fit inside the window (respecting margins and edge gaps). If an anchored overlay does not fit on its preferred side, it flips to the opposite side and shifts into view. It also follows its anchor during scrolling and hides temporarily if the anchor scrolls out of view.

## Behavior

| Method | Description |
| --- | --- |
| `onDismiss(handler)` | Called when clicking outside. For a non-modal overlay, it also runs when scrolling outside or when pressing Tab or Shift+Tab moves focus out of the overlay. Non-modal overlays without `onDismiss` pass outside clicks through |
| `modal()` | Blocks input outside the overlay and traps Tab navigation inside |
| `scrim(argb)` | Draws a dimmed backdrop behind the overlay |
| `keepFocus()` | Opens without stealing keyboard focus (for toasts) |
| `inert()` | Display-only overlay (for tooltips): ignores clicks and Tab navigation |
| `dismissGroup(group)` | Prevents clicks on elements in the same group from dismissing this overlay (used by menu bars) |
| `onShownFor(seconds, handler)` | Runs once after being visible for the specified duration (works on overlays and elements inside them, such as toasts) |
| `pauseShownOnHover()` | Pauses an element's `onShownFor` timer while the pointer is over it or its children |

**Focus and keyboard:** Opening an overlay focuses its first focusable element, and closing it restores previous focus. Unhandled keys bubble from the overlay to its anchor (unless `modal()` is set, which stops bubbling at the overlay root). Pressing **Escape** does not close an overlay automatically — handle `Escape` in `onKey` to update your state.
