A menu, tooltip, dropdown or dialog lies above everything else and is not clipped by its anchor's scroll area. The view declares it on the element it belongs to, [`anchor.overlay(menu)`](/api/com/rethinkj/ui/El.html#overlay(com.rethinkj.ui.El)), and the state says whether it is open: `button.overlay(state.open ? menu : null)`. The kit's [Menu](/docs/components/menu), [Tooltip](/docs/components/tooltip), [Dialog](/docs/components/dialog), [Popover](/docs/components/popover) and [Toast](/docs/components/toast) are built this way; this page is for your own.

## Placement

| Call | |
| --- | --- |
| `side(Side, Style.Align, gap)` | Beside the anchor: `BOTTOM` (default), `TOP`, `LEFT`, `RIGHT`, aligned `START`, `CENTER`, `END` or `STRETCH` |
| `atPoint(x, y)` | At a point of the window, as a context menu at the pointer |
| `atCaret()` | At the caret of the anchor, a text field, as completions |
| `centerInWindow()` | In the middle, as a dialog |
| `atWindowEdge(side, align, gap)` | Against an edge of the window, as a toast |

An overlay is at most as large as the window minus its margins, and one at the window's edge also minus its gap from that edge, so `margin(16)` keeps a dialog 16 pixels from the window's edges; if it has a scroll area that can shrink, that area scrolls. Where it does not fit, it flips to the other side, then moves into the window. It follows its anchor as it scrolls, and hides (staying open) while the anchor is out of view.

## Behavior

| Call | |
| --- | --- |
| `onDismiss(handler)` | A press outside, or the wheel outside a non-modal overlay. Non-modal overlays without one let presses outside them through. |
| `modal()` | Input outside reaches nothing; Tab stays inside |
| `scrim(argb)` | A color over the window below it |
| `keepFocus()` | Opens without taking the focus, as a toast |
| `inert()` | Only shows, as a tooltip: presses inside it and the pointer go to what lies beneath, and Tab passes what is inside by |
| `dismissGroup(group)` | Presses on elements of the same group do not dismiss it: a menu bar's titles |
| `onShownFor(seconds, handler)` | Runs once it has been open that long: a toast closes itself |

An overlay moves the focus to its first focusable element when it opens, and back when it closes. Keys go from the focused element up to the overlay's root and then to its anchor, so the owner of a menu sees Escape. Escape closes nothing by itself: handle it in `onKey` and change the state.
