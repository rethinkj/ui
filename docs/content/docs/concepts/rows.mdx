---
title: Lists of many rows
description: Render lists of up to a million rows efficiently using virtual scrolling.
---

[`El.rows(count, rowHeight, row)`](/api/com/rethinkj/ui/El.html#rows(int,float,java.util.function.IntFunction)) turns a scrollable element into a virtual list. It only builds the visible rows (plus a small buffer), so rendering a million rows is just as fast as rendering twenty, and scrolling builds little more than the rows that come into view. [DataGrid](/docs/components/data-grid), [Tree](/docs/components/tree), and [Markdown](/docs/components/markdown) all use this mechanism.

## Variants and options

| Method | Description |
| --- | --- |
| `rows(count, rowHeight, index -> row)` | Fixed-height rows |
| `rows(count, rowHeight, (index, from, to) -> row)` | Fixed-height rows with horizontal viewport range `(from, to)` for very wide tables |
| `rows(count, RowHeights, index -> row)` | Variable-height rows measured automatically using a `RowHeights` object in your state |

| Helper | Description |
| --- | --- |
| `revealRow(index)` | Scrolls to keep `index` visible whenever it changes |
| `reveal(key, x, y, w, h)` | Scrolls to keep a rectangle visible whenever `key` changes |
| `onRowsBuilt((first, last) -> …)` | Notifies you which row indices were built (useful for lazy data loading) |
| `scrollState(ScrollState)` | Preserves scroll position across view switches |
| `scrollbars(theme.scrollbars())` | Adds draggable scrollbars |
| `app.scrollToRow(list, row)` | Programmatically scrolls to a row from a handler |

Give the list a height (or `grow(1)`) and give each row a key (such as `row-<index>`). In headless scripts, scroll to a row before clicking it (`scroll #rows row 765432`), since only built rows appear in the tree.

## Variable-height rows

For items with different heights (like log entries, wrapping text, or Markdown blocks), use `rows(count, heights, row)` without a fixed row height. Store a `RowHeights` instance in your app state to cache measured heights and estimate unmeasured ones:


- Pass an estimate function (`IntToDoubleFunction`, > 0 logical pixels) based on what you know before layout (such as text length). Closer estimates reduce scrollbar thumb jumping.
- Scrolling stays smooth even with a million variable-height rows, and scroll positions auto-adjust when rows above the viewport are measured.
- `app.scrollToRow(list, row)` keeps tracking the target row as earlier rows are measured until the user scrolls or clicks.
- Create a new `RowHeights` whenever you insert, delete, sort, or reorder rows (appending to the end is fine).

See [`RowHeights` Javadoc](/api/com/rethinkj/ui/RowHeights.html) for helper methods to query row heights and offsets.
