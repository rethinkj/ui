---
title: Languages
description: Show built-in kit text in English, German, or your own language.
---

Kit components include built-in text such as find bar buttons, data grid menus and filters, "Loading…", labels like "Show password", [`Format`](/api/com/rethinkj/ui/kit/Format.html) messages, and shortcut key names. Components read this text from [`Texts`](/api/com/rethinkj/ui/kit/Texts.html)`.CURRENT`, which defaults to English unless your app provides different text. Text you pass to a component, such as a button label or field placeholder, stays unchanged.

```java snippet="languages"
```

- `Texts.ENGLISH` is the default. [`GermanTexts`](/api/com/rethinkj/ui/kit/GermanTexts.html) provides German text, using German keyboard key names (`Strg+C`, `Umschalt+Eingabe`).
- Call `app.provide(Texts.CURRENT, state -> texts)`, just like setting a theme. Changing the language in a handler rebuilds the view immediately.
- **Customize specific strings:** Override a method (such as `noResults()`) in a subclass of `GermanTexts` or an anonymous `Texts` implementation.
- **Add another language:** Implement `Texts`. Every method defaults to English, so any method you leave out falls back to English. Methods with parameters, such as `match(3, "17")`, return the full phrase so each language can use its own word order.
- `Format` messages and `Menu.shortcutText` use the active `Texts` where they are called. Built-in kit handlers use their view's `Texts`. If your own handler calls `format.parse`, read `Texts.CURRENT.get()` in the view and call `parse` inside `Texts.CURRENT.with(texts, …)`.

Numbers and dates are not localized. `Format` always uses a period as the decimal separator and writes dates in ISO 8601. For another style, create your own format with `Format.of`.
