AgentChat puts the kit's chat building blocks together in a three-pane layout: collapsible project groups of sessions on the left, a virtual transcript that streams Markdown and collapsible tool calls above a growing composer in the middle, and a toggleable changes panel with unified diffs on the right. No network is used; a simulated agent drives replies deterministically on the app's clock.

**Demonstrates:** [Chat](/docs/components/chat), [NavList](/docs/components/nav-list), [Avatar](/docs/components/avatar), [Markdown](/docs/components/markdown), [Split](/docs/components/split), [DiffView](/docs/components/diff-view), [Popover](/docs/components/popover), [FilterList](/docs/components/filter-list), [Rail](/docs/components/rail), and [Segmented](/docs/components/segmented).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=AgentChat
```

## What to try

- Send a prompt from the composer (**Enter** sends, **Shift+Enter** adds a line) and watch tool calls run and Markdown stream into the transcript.
- Click the model button in the composer to open the model picker popover above it: filter by provider on the left rail, search models in the middle, adjust reasoning level on the right, or toggle speed at the bottom.
- Press **Stop** while an answer is streaming, or click any tool call row to expand its output.
- Drag across paragraphs in the transcript to select across messages.
- Collapse and expand project groups in the sidebar, pin a session on hover, start a **New session**, or toggle the **Changes** panel from the chat toolbar.

## How it works

### Sessions grouped by project

The sidebar builds a [NavList](/docs/components/nav-list) from `NavList.group` project headers with rounded-square [Avatar](/docs/components/avatar) marks, counts, per-project **New session** actions, and collapse toggles, leaving closed projects' sessions out of the list. Each indented session row puts its relative age (and a spinner while streaming) in `.meta(...)`, pairs its machine on the left with change, check, and provider status chips on the right in `.detail(start, end)`, and keeps a hover pin action:

### Transcript, tool calls, and composer

The middle card pairs `Chat.transcript` with `Chat.composer`. Each agent message composes `Chat.tool` rows, a `Markdown.fragment` for the growing document, and `Chat.working` while active:

```java snippet="agent-chat-transcript"
```

### Model picker popover

The composer's trailing button shows the provider's symbol, the model name, and the reasoning level as a muted inline subtitle (`Button.options().subtitle(...)`). Clicking it opens a `Popover.flush` above the button combining a provider [Rail](/docs/components/rail), a searchable [FilterList](/docs/components/filter-list) with shortcuts and a check mark on the active model, a [NavList](/docs/components/nav-list) of reasoning levels, and a [Segmented](/docs/components/segmented) speed toggle separated by full-bleed dividers:

### Deterministic streaming on the app's clock

Sending a message starts a scripted sequence scheduled with `app.after`. Each tick advances a tool call, appends a Markdown chunk via `MarkdownDocument.next`, or adds a file diff to the right panel. A run counter lets `stop` cancel any remaining ticks without extra threads:
