AgentChat puts the kit's chat building blocks together in a three-pane layout: collapsible project groups of sessions on the left, a virtual transcript that streams Markdown and collapsible tool calls above a growing composer in the middle, and a toggleable changes panel with unified diffs on the right. No network is used; a simulated agent drives replies deterministically on the app's clock.

**Demonstrates:** [Chat](/docs/components/chat), [NavList](/docs/components/nav-list), [Markdown](/docs/components/markdown), [Split](/docs/components/split), and [DiffView](/docs/components/diff-view).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=AgentChat
```

## What to try

- Send a prompt from the composer (**Enter** sends, **Shift+Enter** adds a line) and watch tool calls run and Markdown stream into the transcript.
- Press **Stop** while an answer is streaming, or click any tool call row to expand its output.
- Drag across paragraphs in the transcript to select across messages.
- Collapse and expand project groups in the sidebar, pin a session on hover, start a **New session**, or toggle the **Changes** panel from the chat toolbar.

## How it works

### Sessions grouped by project

The sidebar builds a [NavList](/docs/components/nav-list) from project headings with counts and collapse handlers, leaving closed projects' sessions out of the list. Each session row carries its branch on a second line, a relative age formatted from the app's clock (or a spinner while streaming), and a hover pin action:

### Transcript, tool calls, and composer

The middle card pairs `Chat.transcript` with `Chat.composer`. Each agent message composes `Chat.tool` rows, a `Markdown.fragment` for the growing document, and `Chat.working` while active:

### Deterministic streaming on the app's clock

Sending a message starts a scripted sequence scheduled with `app.after`. Each tick advances a tool call, appends a Markdown chunk via `MarkdownDocument.next`, or adds a file diff to the right panel. A run counter lets `stop` cancel any remaining ticks without extra threads:
