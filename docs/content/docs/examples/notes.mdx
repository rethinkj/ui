Notes shows three notes as cards in a row that reorder, tear off into windows of their own and dock again. It does by hand what [TabGroups](/docs/components/tab-groups) does for tabs.

<Shot src="examples/notes-torn" alt="A note torn off into its own window beside the row" />

<Shot src="examples/groceries-notes-torn" alt="The window of the torn note Groceries: its title above a field with its text" caption="The torn note's own window." />

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Notes
```

## What to try

- Drag a card's title along the row to reorder the notes.
- Drag it out of the window: the note gets a window of its own that follows the pointer.
- Edit the note in its window: the muted card in the row shows the text at once.
- Drag the title back over the row to dock the note, or close its window.

## How it works

### The drag

A card's title carries the note as its drag payload and reports each step of the drag ([Input](/docs/concepts/input)).


`drag` remembers where the pointer holds the title. Once `Drag.outside()` says the pointer has left the window, it tears the note off; after that, each step moves the note's window.


### A window of its own

`tearOff` opens a window through `app.windows()` with a new `App` over the same state, placed so that the pointer holds the title where it held it in the card. The window is no drop target while it follows the pointer, so the row below it gets the drop ([Several windows](/docs/concepts/windows)).


### Docking

The row takes drops with `onDrop`. While a note is over it, a marker shows where it would go; a drop puts the note there and closes its window.
