Notes displays three note cards in a row. You can drag cards to reorder them, pull a card outside the window to detach it into its own window, and drag it back to dock it again. It demonstrates the low-level multi-window drag-and-drop pattern that [TabGroups](/docs/components/tab-groups) uses internally.

**Demonstrates:** [Drag and drop](/docs/concepts/input), [Several windows](/docs/concepts/windows), and [Card](/docs/components/card).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Notes
```

## What to try

- Drag a card's title left or right along the row to reorder the notes.
- Drag a card outside the window to tear it off into its own floating window.
- Edit the note inside the detached window: the card in the main window updates live.
- Drag the title back over the row to dock the note again, or close its window.
