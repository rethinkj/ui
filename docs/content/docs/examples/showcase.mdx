Showcase is an interactive gallery of every component in `rethinkj-ui-kit`, organized into sections: buttons, inputs, menus and dialogs, data grid, tree, tabs and split panes, code editor, progress indicators, text styles, theme colors, and icons.

**Demonstrates:** All [Components](/docs/components), [NavList](/docs/components/nav-list), [Select](/docs/components/select), [CommandPalette](/docs/components/command-palette), and [Themes](/docs/concepts/themes).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Showcase
```

## What to try

- Pick any section from the sidebar on the left.
- In **Text fields**, press **Ctrl+Alt+L** in the JSON editor to format the document.
- Switch between **Dark**, **Light**, and **System** themes using the dropdown at the bottom left.
- Press **Ctrl+Shift+P** to open the command palette and run demo actions (such as renaming a query or selecting a schema).
