The `examples` module contains complete, runnable desktop apps showing how to build real interfaces with rethinkj UI.

## How to run the examples

You need **JDK 25**, **Maven 3.9+**, and a C/C++ toolchain for the first build (see [Build from source](/docs/get-started/from-source) for setup details).

Clone the repository and run any example from the root folder:

```sh
git clone https://github.com/rethinkj/ui.git
cd ui
mvn -q -pl examples -am compile exec:exec -Dexample=Workbench
```

Replace `Workbench` with any example name below. To run an example headless with a script instead of opening a window, add `-Dargs="--script <file> --out <folder>"` (see [Run the examples](/docs/get-started/from-source#run-the-examples)).
