---
title: Examples
description: Runnable apps in the repository's examples module, written the way a user of the library writes them.
---

The `examples` module holds apps that open a window, written as an app of your own would be. Each runs under a script too, and its tests compare the snaps with stored images, which are the pictures on these pages. Start one from the repository's root:

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Workbench
```

With `-Dargs="--script <file> --out <folder>"` it runs a script instead of opening the window ([Run an example](/docs/get-started/run-examples)).
