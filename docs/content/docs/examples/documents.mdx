Documents opens five sample documents in tabs that can be reordered, torn off into separate windows, and docked back together. It also supports native Open/Save dialogs, drag-and-drop from your OS file manager, and an in-editor find bar.

**Demonstrates:** [TabGroups](/docs/components/tab-groups), [Several windows](/docs/concepts/windows), [File dialogs and drops](/docs/concepts/platform), and [Find](/docs/components/find).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Documents
```

## What to try

- Drag a tab along the tab bar, pull it outside the window to create a new window, and drag it onto another window's tab bar to dock it.
- Use **File › Open…** (**Ctrl+O**) and **File › Save As…** (**Ctrl+Shift+S**).
- Drag files from your file manager onto the window to open each file in a new tab.
- Press **Ctrl+F** inside any document to open the find bar.

## How it works

### Shared TabGroups across windows

All windows share one `TabGroups` instance. Its second argument is a callback that opens a new window whenever a tab is torn off or moved to a new window:

```java snippet="documents-groups"
```

The callback creates a new window with its own `App` sharing the same state ([Several windows](/docs/concepts/windows)):

```java snippet="documents-window"
```

Each window renders its frame's tabs, content, or an empty state when no tabs remain:

```java snippet="documents-tabs"
```

### Native file dialogs

**File › Open…** opens the OS file picker via `App.fileDialog`. Its callback receives the selected paths and reads them on a background thread ([Platform](/docs/concepts/platform)):

```java snippet="documents-open"
```

### Drag-and-drop from other apps

The root element accepts external drops with `onFileDrop`. While dragging over the window, the tab card highlights as a drop target. Dropped files open as new tabs, and dropped text opens in a new tab unless dropped directly into an editor (which pastes it there instead).

