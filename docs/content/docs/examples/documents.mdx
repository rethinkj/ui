Documents is five documents in tabs that move and tear off into windows of their own ([TabGroups](/docs/components/tab-groups)). It opens and saves files through the system's file dialogs and opens files dropped from a file manager.

mvn -q -pl examples -am compile exec:exec -Dexample=Documents
```

## What to try

- Drag a tab along the bar, out of the window, and over the bar of another window.
- File › Open… and File › Save As… (Control+O, Control+Shift+S).
- Drag files from a file manager onto a window: each opens in a new tab.
- Control+F in a document opens its find bar.

## How it works

### One TabGroups for every window

The documents are the tabs of one `TabGroups`. Its second argument is the opener, which it calls for the window of a new group: a tab torn off, or moved to a new window from its menu.

The opener opens a window with a new `App` over the same state, whose view shows that group ([Several windows](/docs/concepts/windows)):

Every window's view asks the groups for its tabs: how a document shows in the bar, and its content, or an empty state for a group without tabs.

### File dialogs

File › Open… shows the system's file dialog through `App.fileDialog`; its handler gets the chosen paths, which `read` reads off the app's thread ([Platform](/docs/concepts/platform)).

```

### Drops from other applications

Each window's root takes drops with `onFileDrop`. While a drag is over the window, its tabs' card shows that it takes it; a drop of files reads them into new tabs, a drop of text becomes a tab of its own.
