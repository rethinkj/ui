LightSwitch is the simplest example app: a lamp and a toggle switch inside a card, wrapped in a frameless window with a custom [TitleBar](/docs/components/title-bar). It builds on [The first app](/docs/get-started/first-app) by adding a window icon and title bar.

**Demonstrates:** [TitleBar](/docs/components/title-bar), [Card](/docs/components/card), [Toggle](/docs/components/toggle), [Motion](/docs/concepts/motion), and [Platform](/docs/concepts/platform).

<Shot src="examples/light-switch-on" alt="The lamp lit above the switch" />

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec
```

## What to try

- Click the toggle switch (or press **Tab** and **Space**) to turn the lamp on and off.
- Drag the title bar to move the window.

## How it works

`main` creates the `App` and calls `Script.handle` first so it can run headless when given `--script`. Otherwise, it opens a frameless window with a custom icon ([Platform](/docs/concepts/platform)):

```java snippet="light-switch-window"
```

The view places the title bar above a card containing the lamp and switch. When `state.on` changes, `.motion(...)` smoothly animates the lamp's color ([Motion](/docs/concepts/motion)):

```java snippet="light-switch-view"
```

You can also run it headless with its test script:

```text file="examples/src/test/resources/scripts/light-switch.txt"
```

Full source: [`LightSwitch.java`](https://github.com/rethinkj/ui/blob/main/examples/src/main/java/com/rethinkj/ui/examples/LightSwitch.java).
