LightSwitch is a lamp and a switch in a card, in a frameless window with the kit's [TitleBar](/docs/components/title-bar). It is the app of [The first app](/docs/get-started/first-app) with an identity, an icon and a title bar.

<Shot src="examples/light-switch-on" alt="The lamp lit above the switch" />

```sh
mvn -q -pl examples -am compile exec:exec
```

## What to try

- Press the switch, or Tab to it and press Space.
- Drag the title bar to move the window.

## How it works

`main` builds the app and hands it to `Script.handle`, which runs a script when the arguments name one. Otherwise it opens a frameless window with an icon ([Platform](/docs/concepts/platform)).

```java snippet="light-switch-window"
```

The view is the title bar over a card with the lamp and the switch. The lamp's fill changes with the state, and `motion` animates the change ([Motion](/docs/concepts/motion)).

```java snippet="light-switch-view"
```
