Manual reads Markdown documents: a navigation list of documents with the headings of the chosen one, and the document in a card. Its own manual shows every form the kit's [Markdown](/docs/components/markdown) supports; Markdown files given as arguments open too.

<Shot src="examples/manual-{theme}-2x-top" alt="The Manual: a list of documents and headings beside a Markdown document" />

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Manual -Dargs="README.md"
```

## What to try

- Choose a heading under "On this page": the document scrolls there.
- Press a link: one to a heading scrolls there, any other shows its address in a toast.
- Control+A in the document selects all of it, Control+C copies it.

## How it works

### The document

Each document is parsed once with `Markdown.parse`. The view shows it with options: what a link does, the clipboard to copy to, the selection, and where its images come from.

### Images read in the background

`image` returns the image for an address, or null while it is not there yet; until then the document shows a placeholder. The first call reads the image with `App.background`, and the view is built again when it has arrived ([Images](/docs/concepts/images)).

### Links and headings

A link to `#id` scrolls the document to that heading: `Markdown.rowOf` finds the heading's block, and `App.scrollToRow` brings it to the top of the document's list.
