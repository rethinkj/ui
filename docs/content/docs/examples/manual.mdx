Manual is a Markdown document viewer with a sidebar listing documents and headings on the left, and the formatted document inside a card on the right. It displays every Markdown feature supported by [Markdown](/docs/components/markdown) and can also open local Markdown files passed as command-line arguments.

**Demonstrates:** [Markdown](/docs/components/markdown), [NavList](/docs/components/nav-list), [Images](/docs/concepts/images), and [Background work](/docs/concepts/background-work).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Manual -Dargs="README.md"
```

## What to try

- Click any heading under **On this page** to scroll directly to that section.
- Click a link: heading links scroll smoothly to the target, while web links open in the system's browser.
- Press **Ctrl+A** to select the document and **Ctrl+C** to copy it.

### Following links

Clicking a `#id` link finds the heading's block index with `Markdown.rowOf` and scrolls it to the top using `App.scrollToRow`. Any other link goes to `App.openUri`, which opens web addresses in the system's browser:
