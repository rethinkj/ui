DataBrowser displays one million sample orders in a [DataGrid](/docs/components/data-grid) inside a card with a search filter in the toolbar and a status footer. You can edit cells, review pending changes, and commit or revert them.

**Demonstrates:** [DataGrid](/docs/components/data-grid), [Typed rows](/docs/components/data-grid/typed), [Editing and changes](/docs/components/data-grid/editing), [Filters](/docs/components/data-grid/filters), and [Format](/docs/components/format).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=DataBrowser
```

## What to try

- Type keywords into the **Filter** box to show only rows matching every word.
- Double-click a cell to edit it. Click **Commit** (or press **Ctrl+S**) to save pending changes, or click **Revert** to discard them.
- Click the `id` column header to sort, click any text-column header to filter, and use **Columns** to show or hide columns.

### Tracking pending changes

Edits are stored in a `GridChanges` object. Its `Rows` view assigns each row a stable key (the order number), so pending edits stay attached to the right order even when you sort or filter the grid ([Editing and changes](/docs/components/data-grid/editing)).
