Settings is the settings window of a database tool: a navigation list of pages at the left and the chosen page at the right, built from [Section and page](/docs/components/section), [Group](/docs/components/group) rows, [Cards](/docs/components/card) and a [Form](/docs/components/form) in a dialog. The theme and the accent change the whole window.

<Shot dark="examples/settings-2x-appearance" light="examples/settings-light-2x-appearance" alt="The Appearance page with switches, a segmented theme choice and a slider" />

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Settings
```

## What to try

- Appearance: switch the theme between Light, Dark and System, and choose another accent color.
- Connections: filter the cards, open a card's menu, and add a connection in the dialog.

## How it works

### The pages

The view is a [NavList](/docs/components/nav-list) of the pages beside the chosen page, in a frameless window with the kit's [TitleBar](/docs/components/title-bar). A switch picks the page's method.

```java snippet="settings-pages"
```

### A page

Each page is one expression: a `page` of `section`s, each with a `group` of rows. A row has a title, an optional description and a control. `switchRow` is a row that is a switch, `linkRow` one that leads to another page.

```

### Theme and accent

The theme comes from the state on every build of the view: the light or dark theme, System as the window loop reports the system's appearance, and `withAccent` for an accent other than blue ([Themes](/docs/concepts/themes)).

```
