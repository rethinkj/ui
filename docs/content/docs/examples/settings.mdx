Settings is a complete settings window with a navigation sidebar on the left and structured settings pages on the right. Changing the theme or accent color updates the entire window immediately.

**Demonstrates:** [NavList](/docs/components/nav-list), [TitleBar](/docs/components/title-bar), [Section and page](/docs/components/section), [Group](/docs/components/group), [Cards](/docs/components/card), [Form](/docs/components/form), and [Themes](/docs/concepts/themes).

## Run it

From the cloned repository root (see [Build from source](/docs/get-started/from-source)):

```sh
mvn -q -pl examples -am compile exec:exec -Dexample=Settings
```

## What to try

- Open **Appearance** to switch between **Light**, **Dark**, and **System** themes, and pick a different accent color.
- Open **Connections** to filter connection cards, open a card's menu, and add a new connection in a dialog.

## How it works

### Page navigation

The view places a [NavList](/docs/components/nav-list) next to the active page inside a frameless window with a [TitleBar](/docs/components/title-bar). A `switch` selects which page method to render:

```java snippet="settings-pages"
```

### Building a settings page

Each page is composed of a `page` containing `section`s and `group`s of rows. Each row has a title, optional description, and control — such as `switchRow` for a toggle or `linkRow` to navigate to another page:

```java snippet="settings-general"
```

### Live theme and accent switching

The app provides its current theme dynamically via `app.provide(Theme.CURRENT, Settings::theme)`. It supports Light, Dark, and System (following OS appearance), plus `withAccent` for custom accent colors ([Themes](/docs/concepts/themes)):

```java snippet="settings-theme"
```
