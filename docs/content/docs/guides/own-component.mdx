The kit covers the common controls, but an app soon needs one of its own. This guide builds a tag input step by step: the tags as [badges](/docs/components/badge) with a cross that removes each, and a field after them in which Enter adds a tag. It follows the rules the kit's components follow, so it fits beside them in a form and a script can drive it.

## 1. The shape

## 4. Keyboard and focus

An editable field is focusable, so Tab reaches the input without more code: first each tag's cross, then the field. `onKey` on the field sees each key before the field edits with it; return true to take the key, false to let the field have it.

```java snippet="tag-keys"
```

Enter adds the typed tag and empties the field; Backspace in an empty field removes the last tag. A press on a cross leaves the focus where it was, so typing goes on in the field: `Badge` makes its cross `keepFocus()`. See [Input, focus and keys](/docs/concepts/input#keyboard-and-focus) for the order in which handlers see a key, and [Text fields and editors](/docs/concepts/text-fields) for the field itself.

## 5. Roles, labels and states

Say in words what the component is, so that a [tree dump](/docs/testing/tree-dump), a [selector](/docs/testing/selectors) and assistive tools can use it. The frame is `role("group")` with the tags as its `value`, and `disabled` when there is no handler; the caller's `.label("Tags")` names it, as a [Form](/docs/components/form) field does with its label. The field has the placeholder as its label, and each cross is a button labelled `Remove <tag>`. Key the parts that repeat by what they show, `tag-orders`, `tag-daily`: a key identifies an element among its siblings across builds, so when a tag goes, the ones after it stay themselves and only the removed one fades out. Two siblings must never share a key (the frame throws), so the tags must be distinct: Enter refuses a tag that is already there, and an app that loads tags from elsewhere drops repeats first, for example through a `LinkedHashSet`. [States and roles](/docs/concepts/states) lists every state.
