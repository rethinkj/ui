---
title: Frame times
description: Measure frame times in a real window, including drawing, by sending input like the system does.
---

A script runs your app without a window, so `app.frame()` measures input, build, and layout, but not drawing. To check your frame budget with drawing included, run your app in a real window, send it input, and read each frame's times with `WindowLoop.frames`:

```java snippet="frame-times"
```

- The listener receives a [`WindowLoop.Frame`](/api/com/rethinkj/ui/window/WindowLoop.Frame.html) on the window's thread for each frame a window displays. All times are in nanoseconds:
  - `input` — handling the input and tasks that arrived, with their handlers and the layout that runs before each next one
  - `build` — running the view and row functions
  - `layout` — the rest of `app.frame()` after input, including handlers the frame runs on its own (such as `onResize` or `onHoverFor`)
  - `draw` — building the scene and drawing it
  - `present` — showing the frame
  - `interval` — time since the window's previous frame began
- `window.post(event)` sends a `WindowEvent` to the window as if the system reported it. The loop treats it like real input: events that arrive faster than the display refresh rate are drawn once per refresh, and a wheel step builds only the list's rows instead of the whole view. Posting `app.wheel(…)` as a task with `app.post` instead rebuilds the whole view on every step, as all tasks do.
- Call `window.post` on the window's thread, just as the listener does. If a frame changes nothing, it is not drawn and the listener is not called. Send input that changes something (such as scrolling a list that has room to scroll), or the loop will wait.
- The listener also receives frames the window requests on its own, such as when it is uncovered. The example checks the list's scroll offset to skip those frames so each recorded time measures one step.
- Leave `present` out of your frame budget because it includes waiting for the display's next refresh.
- Without a window, `app.timing()` returns the `input`, `build`, and `layout` times from the last `app.frame()`.
