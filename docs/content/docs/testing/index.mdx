Every rethinkj UI app can run headless (without opening a window). A text script sends user actions, and each `snap` command saves a PNG screenshot and a text dump of the element tree. Use this for fast JUnit UI tests or to let AI agents inspect and interact with what they build.

## One line in `main`

Add `Script.handle(args, app)` at the start of `main` (as in [The first app](/docs/get-started/first-app)):

```java snippet="lights-main" title="Lights.java"
```

[`Script.handle(args, app)`](/api/com/rethinkj/ui/Script.html) checks for `--script <file> --out <folder>` in `args`. If found, it runs the script, prints the output file paths, and returns `true` so `main` exits without opening a window. Otherwise it returns `false` and your app opens normally.

Your real app, view, and handlers run with no mocking. If a script step fails, it throws `Script.Failure` with the line number and a helpful suggestion.

To run a script directly from Java (for example, inside JUnit), call `Script.run(text, app, folder)`.

## Why both trees and screenshots?

- **Screenshots (`.png`)** show the visual layout, colors, spacing, and text rendering.
- **Element trees (`.tree.txt`)** expose roles, labels, bounds, and states (`checked`, `selected`, `focused`, `disabled`, `busy`, `invalid`, etc.) as plain text so tests and AI agents can assert UI state directly without reading pixels.
