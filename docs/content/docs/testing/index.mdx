Every rethinkj UI app can run without a window: a script drives it, and each `snap` writes a PNG of the frame and the element tree as text. Use it to test views in JUnit, and to let an agent see what it built.

## One line in `main`

The `main` of the [first app](/docs/get-started/first-app):

```java snippet="lights-main" title="Lights.java"
```

`Script.handle(args, app)` looks for `--script <file> --out <folder>`. If they are there, it runs the script, prints the files it wrote and returns true; otherwise it returns false and `main` opens the window. The app, view and handlers are the same; nothing is mocked. On an error it throws `Script.Failure`, which names the line and says what to write instead; uncaught, the program exits with status 1.

From Java, `Script.run(text, app, folder)` does the same and returns the files it wrote.

## Why trees as well as images

An image shows what a person sees. The tree says it in text that a test or an agent can match without reading pixels: each element's key, role, label, rectangle and states (`checked`, `selected`, `focused`, `disabled`, `busy`, `invalid` and more). A selector such as `role=switch label="Lamp"` finds an element the way a person would describe it.
