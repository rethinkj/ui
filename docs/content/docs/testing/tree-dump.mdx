title: The tree dump
description: How to read .tree.txt files, including element states, overlays, virtual lists, and text fields.
---

Every `snap` command saves `<name>.tree.txt` next to the PNG screenshot. Each line represents one element, with children indented by two spaces. Tree dumps let tests and AI agents inspect UI state in plain text using the same roles, labels, and states that script selectors match.

## Reading a line

```text file="examples/src/test/resources/golden/docs/menu/open.tree.txt" start="#item-1" count="1"
```

Fields appear in this order:

1. **Type:** `el` (container), `text`, or `image`.
2. **Key:** `#key` if `.key(...)` was set.
3. **Role and label:** `role=...` and `label="..."` if set (kit components set both), then a text field's `placeholder="..."` unless it is empty or the label too.
4. **Text content:** Quoted string for `text` elements (`\n`, `\r`, `\t`, and private-use icon code points like `\u{E305}`). Strings over 200 characters show the first 100 and last 40 characters plus total length.
5. **Window chrome:** `window=<part>` for custom title bar parts (`drag`, `minimize`, `maximize`, `close`, `control`, or `content`).
6. **Bounds:** `x,y widthxheight` in window coordinates (accounting for parent scroll offsets).
7. **States:** Active states in fixed order (table below), followed by `value="<text>"`, `error="<message>"` (`El.errorMessage`), and `warning="<message>"` (`El.warningMessage`).
8. **Extra details:** Scroll offsets, virtual row ranges, or text editor line counts (see below).
9. **Interaction flags:** `hovered` (under mouse), `focused` (keyboard focus, plus cursor/selection for text fields), and `exiting` (fading out after removal).

## States

States follow WAI-ARIA naming. They are semantic metadata — setting a state does not change styling or input handling by itself (kit components set them automatically; see [States and roles](/docs/concepts/states)).

| State | Meaning | How to set |
| --- | --- | --- |
| `disabled` | Control is disabled | `disabled(true)` (or `editable(null)` on text fields) |
| `readonly` | Text field can be selected and copied, but not edited | `readOnly()` |
| `password` | Masked text field (tree always shows `•`) | `masked()` |
| `revealed` | Masked field currently showing plain text on screen (tree still masks it) | `revealed(true)` |
| `invalid` | Input failed validation | `invalid(true)` |
| `busy` | Action is currently running | `busy(true)` |
| `selected` | Item is selected | `selected(true)` |
| `current` | Active cursor cell/row or highlighted menu item | `current(true)` |
| `grabbed` | Element is currently being dragged | `grabbed(true)` |
| `modified` | Has unsaved changes (for example, an edited document tab) | `modified(true)` |
| `checked`, `checked=false`, `checked=mixed` | Switch, checkbox, radio, or toggle button state | `checked(boolean)`, `checkedMixed()` |
| `expanded`, `expanded=false` | Expandable section, tree node, or dropdown | `expanded(boolean)` |
| `level=<n>` | Nesting depth in a tree (1-based) | `level(n)` |
| `pos=<n>/<size>` | 1-based position and total count in a set | `position(n, size)` |
| `sort=ascending`, `sort=descending` | Sorted table column | `sortAscending()`, `sortDescending()` |
| `value="<text>"` | Current value (such as a slider value or changed row status) | `value(text)` |

## Scroll areas and virtual lists

Scrollable containers include their scroll offset and scrollbar thumb positions; virtual lists also include their built row range and total row count:

```text file="examples/src/test/resources/golden/docs/rows/far.tree.txt" start="#rows" count="1"
```

Here, `rows 765429-765442/1000000` shows which rows are currently built out of one million, `scroll 0,18370368` is the scroll offset, and `thumb-y` is the vertical scrollbar thumb. An empty built range appears as `rows -/<count>`.

## Text fields

A focused text field shows its `caret` index, optional selection `anchor`, and active IME `composing` text:

```text
text #name role=textbox label="Table name" "SELECT name FROM customers" 40,26 160x28 focused caret 17 anchor 26 composing "ni"
```

A multi-line editor adds visible line numbers (`lines 1-3/3`), any underlined diagnostic ranges (`underline <from>-<to>` from [`El.decorate`](/api/com/rethinkj/ui/El.html#decorate(com.rethinkj.ui.Decorator))), and `(line:column)` after the caret:

```text
text #query role=textbox label="Query" "SELECT *\nFROM orders\nLIMIT 20;" 253,44 455x82 lines 1-3/3 focused caret 29 (3:9)
```

A field in a form is labeled by the form, so its placeholder follows the label:

```text file="examples/src/test/resources/golden/connection-empty.tree.txt" start="#user" count="1"
```

A masked password field always replaces characters with `•` and includes `password` (plus `revealed` when visible on screen):
